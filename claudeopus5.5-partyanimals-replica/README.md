# 毛绒派对 · 动物派对玩法复刻(Claude Opus 5.5)

用 Three.js + Rapier 复刻 *Party Animals*（动物派对，Recreate Games）的玩法：毛茸茸的动物靠物理布娃娃互殴，先把对手打晕，再抓起来扔出场外，最后站着的动物赢下回合。

**复刻范围说明**：操作（沿用原作 PC 默认键位）、主动布娃娃手感、击晕—抓举—投掷的核心循环、回合 / 比分 / 突然死亡规则和模式结构，都按原作玩法复刻。原作的角色形象、名字、地图美术与音乐受版权保护，所以 8 种动物都是通用物种的原创造型，5 张地图是原创场景（机关思路参考原作 Last Stand 地图）。**画面、音效、音乐全部由代码程序化生成，没有任何外部美术或音频资源。**

## 运行

- 常规：仓库根目录 `npm run dev`，访问 `http://localhost:3000/claudeopus5.5-partyanimals-replica/`
- 单独调试：根目录 `npm run dev:one -- claudeopus5.5-partyanimals-replica`（端口 3072）
- 构建：本目录 `npm run build`（使用根目录 vite）
- 快速开局：地址后加 `?quick&map=rooftop&bots=5&mode=ffa`（map 可选 `rooftop` / `trawler` / `icefloe` / `windfactory` / `bridge` / `random`）

## 规则

- **意识值**：每次挨打都会降低意识值（打头 ×1.3，打四肢 ×0.7），降到 0 就晕倒，头上转星星、眼睛变成蚊香圈。晕倒约 5 秒，之后每多晕一次多 1.4 秒；挨打会延长晕倒时间，连按动作键可以缩短。1.6 秒没挨打就开始回复意识。
- **抓与扔**：晕倒或被冻住的动物被抓住后会被自动举过头顶，这时扔得最远。清醒的动物也能抓，但它会挣扎消耗你的握力，扔也扔不远。握力会被悬挂和抓人消耗，耗尽就会松手。
- **淘汰**：掉出场外、落水，或在毒雾里晕倒超过 2.5 秒都会出局。
- **回合**：每回合最后存活的个人或队伍得 1 分，先拿到设定分数（1 / 3 / 5）的一方获胜。90 秒后进入**突然死亡**，各地图的机关会全面升级；240 秒仍未分出胜负记为平局。

## 模式

- **个人混战**：1–7 名电脑对手。
- **团队对抗**：红队对蓝队，人数会自动凑成偶数；队友之间不会互相伤害。
- **练习场**：3 个木桩不会还手，掉下去会自动复活，适合练习操作。

电脑有简单、普通、困难三档，差别在于反应间隔、攻击频率、挣扎速度，以及把对手推下边缘的积极程度。

## 道具

球棒、平底锅、大锤（蓄力较慢但很重）、棒棒糖、冰冻枪（5 发，命中把对手冻成冰块约 4 秒，冰块很滑）、炸弹（拾起后开始约 3.2 秒倒计时，可以扔出去，爆炸会范围击飞）。另有木箱、油桶、沙滩球可以推、举、扔。武器会定时从空中掉落。

## 技术要点

- **主动布娃娃**（`src/creature.js`）：每只动物由躯干、头、双臂、双腿 6 个刚体和球关节组成。躯干由向下射线（落空时用小球扫掠兜底）检测地面，再用悬浮弹簧托住；姿态通过角冲量速度伺服保持；手脚末端按目标点做速度伺服。走路摆臂、出拳、踢、抓、举都只是在改末端的目标点，所以受击、被拽、撞墙时都会自然地晃动。手抓住东西时，伺服的反作用力会全部还给躯干，保证动量守恒。
- **抓取**：手掌与目标之间动态创建 Rapier 球关节（目标可以是动物部件、道具、场景固定体或运动学体）。武器用固定关节焊在右手上；冻结状态则用固定关节把全身锁成一个刚体。
- **毛绒**：shell 壳层渲染（`src/fur.js`）。基础网格沿法线复制 7–12 层，片元按物体空间三维格点哈希挖出毛丝；物种配色烘焙进顶点色；表情是可切换的贴花（睁眼、眨眼、生气、受伤、蚊香眼、笑眼）。
- **地图**：天台和车间是静态场景；渔船是运动学刚体；浮冰是带浮力采样、软锚和扶正力矩的动态刚体；吊桥是关节链。水面用顶点着色器做波浪，CPU 端用同一个波形函数判定入水。
- **AI**（`src/ai.js`）：和玩家一样只通过 intent 操作。12 方向探测最近的悬崖，抓人时只抓瞄准的目标，前方没有落脚处会刹车，地图会提供机关规避提示（毒雾、大浪、狂风、浮冰沉没）。
- **音频**（`src/audio.js`）：WebAudio 合成，42 种音效、8 种动物 × 6 种情境的叫声、4 首前瞻调度的循环配乐和 6 种环境声。
