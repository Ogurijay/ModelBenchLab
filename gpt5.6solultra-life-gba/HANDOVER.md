# 交接文档

## 当前状态

项目已形成完整可玩闭环：开始画面、角色八方向移动、家具碰撞、九类互动、五维需求、金钱、时间/跨天、每日目标、暂停、声音、自动存档与触控按键均已实现。

## 技术方案

- `src/main.js`：游戏输入、Canvas 2D 绘制、碰撞、互动、音效与主循环。
- `src/sim.js`：可单元测试的纯状态逻辑，包括时间、需求衰减、互动结算和心情。
- `src/styles.css`：GBA 掌机机身、响应式布局和可点击实体按键。
- 内部画布为 240×160，CSS 使用 `image-rendering: pixelated` 保持像素边缘。
- 存档键名为 `pocket-life-save-v1`。

## 已知边界

- 当前为单房间垂直切片（vertical slice，能完整体验核心循环的小型版本），尚无城镇地图、角色创建和长期职业线。
- 中文 Canvas 字形由系统字体回退提供，不同操作系统的细节可能略有差异。
- 音效由 Web Audio（网页音频接口）实时合成，首次用户操作前浏览器不会播放声音。

## 后续建议

优先扩展室外街区、NPC 关系等级和家具购买/摆放；之后再增加角色外观与多存档位，避免过早扩大内容面。
