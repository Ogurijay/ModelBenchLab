## 2026-07-17 多维审查修复轮(6 维并行审查 + 双怀疑者对抗验证,16 条原始发现确认 8 条)

- **裂谷防作弊失效(高)**:原 3.5m 裂谷口算把玩家当质点,漏了 AABB 半宽 ±0.32 与土狼时间 0.4m,普通跑跳即可越过、C4/C5 核心飞跃谜题可整体绕过(验证者用真实物理逐子步仿真复现)→ 裂谷加宽至 **4.5m** + `JUMP_V` 5.2→4.8 + **台阶助爬仅限着地状态**(空中无落点救援);修后极限跳(助跑+土狼)实测坠落重生,飞跃全面板带(门心 y 5.6~7.8)实测落点 z −3.0~−5.1 全部安全
- **已嵌入实体的碰撞推出可瞬移 7m(高)**:穿透窗口逐步切换留下"嵌在墙里"状态时,moveEntity 按速度符号把玩家钳到墙盒对侧(第 3 关贴地门斜蹭可被甩出地图)→ 新增 `expelFromSolids` 子步前最小平移轴温和脱嵌,实测斜蹭门边零瞬移
- **门背面可步行穿墙(中)**:穿透窗口 |l₂|<1.4 双侧生效而背→正穿越不触发传送 → 窗口改**方向敏感**(正面 −0.05~1.2;背侧仅限 v·N<0 穿越中),实测背面走墙被挡(z 停在 −0.62)、正面穿越/坠入地门不受影响
- **过场计时器竞态(高)**:fadeTransition 的 setTimeout 不可取消,过渡窗口内 R/选关会被排队回调覆盖 → 计时器句柄登记 + `cancelTransition`(loadChamber 内置调用)+ `restart()`/选关 chip 增加 mode 门禁
- **门内画面偏暗(中)**:three 渲到 RenderTarget 存线性值,门面 shader 原样输出被当 sRGB 显示 → 采样后手动 linear→sRGB(精确分段式),门内亮度与直视一致
- **通关画面不释放指针锁(低)**:showComplete 增加 exitPointerLock(可直接点「重新开始」),restart 的 mode 门禁同时封掉遮罩下盲玩
- 驳回 8 条(双怀疑者一致):carried 悬挂(物理上不可达)、localStorage NaN(仅自毁可达且不瘫痪)、共享材质误 dispose(clone 链正确)、DPR/性能/英文引语(规格自带台词)等
- 全量回归:自测 10/10、五关链路(C2 高台/C3 方块按钮/C4·C5 飞跃)、背面封堵、侧滑零瞬移、坠落重生、R 重置、控制台 0 错误

### 浏览器实测修复(Playwright 无头驱动 `__bench` 五关全通)

- **嵌入式窗格 0×0 初始化**:renderer/RT 拿到零尺寸导致首帧崩溃(`rt.texture` null)→ 每帧 `syncSize()` + `ensureRT` 零尺寸跳过
- **半空门走入卡进高台**:门底高于脚仍可穿墙、出口与高台重叠 → 墙面门穿透窗口按实体身高收紧(需跳入,与原作一致)+ 传送后沿出口 U/N/−U `depenetrate` 脱困

- **同一物理步内消解栅清门后穿越循环空引用崩溃** → 循环内 `placed` 防护
