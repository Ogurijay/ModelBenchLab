## 2026-10-15 · Three.js r186 升级

按用户本轮授权，当前 Three.js 依赖已从 0.185.x 升级并固定为 **0.186.1**。历史条目中的旧版本与验收结果保留原记录；它们不代表 r186 的运行验收。
已核对官方迁移指南和安装版源码：r186 的 WebGLShadowMap 也已移除 PCFSoftShadowMap，遇到旧值会警告并自动回退 PCFShadowMap。六个旧项目已显式改用 PCFShadowMap，消除该警告；其他已扫描的迁移项未发现需调整的使用。
构建、已有单元测试、仓库检查和运行抽查结果统一记录在仓库临时报告 `tmp/three186-migration/report.json`；未进行全部场景的视觉与性能回归。
本项目已显式使用 PCFShadowMap；效果与 r186 原先的自动回退结果一致。

## 2026-07-10 初版实现

- 自写 Verlet 积分 + 结构/剪切距离约束求解器(Float32Array,固定 1/120 子步累加器,无任何物理库)
- 风场系统:风向/风力滑杆实时生效,三层正弦阵风包络 + 空间非均匀扰动,面片法线投影受力 `F = n·dot(n, wind−v)·area`
- 鼠标 raycast 抓取任意布点、相机平面拖拽、松手自然恢复;抓取时自动禁用轨道相机
- 固定点模式切换:整边固定(旗帜)/ 两角固定(晾布,联动晾布绳+木桩显隐)
- 法线逐帧重算、DoubleSide 双面受光、程序化「乘风」旗面 canvas 纹理(旭日/波浪饰带/织物经纬)
- 自写轻量参数面板(中文,无 lil-gui):分辨率(重建)/迭代次数(刚度)/重力/阻尼/风向/风力/阵风/撕裂阈值 + 重置 + 运行统计
- L4 加分:超应力撕裂(断约束 + 面片破洞,可恢复)、旗杆圆柱碰撞、地面碰撞摩擦
- 场景氛围:渐变天空穹顶 shader(太阳光晕)、雾、远山剪影、程序化草地、金属旗杆+石基座、石板圆台、飘尘粒子、ACES 色调映射 + PCFSoft 阴影
- 工程:`window.__bench = { ready, stepFrame(n), getState() }` 调试钩子;Vite 端口 3025;`node --check` 全部源码通过
- 浏览器冒烟验证通过:`__bench` 三钩子、固定模式切换、分辨率重建(32×21→48×32)、撕裂与重置恢复、鼠标拖拽释放、极限压力(48×32 网格 + 15 迭代 + 15m/s 风)数值稳定无 NaN,控制台零报错,FPS 60
- 视觉调优:气动系数 0.85(默认风力下旗帜自然飘扬而非下垂)、远山压低推远成雾中剪影、飘尘减淡
