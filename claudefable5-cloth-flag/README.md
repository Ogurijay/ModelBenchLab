# claudefable5-cloth-flag — 旗帜布料模拟

Three.js 实现的挂旗布料模拟(ModelBenchLab · mission=cloth · Claude Fable 5)。
布料物理**完全自写**:Verlet 积分 + 结构 / 剪切距离约束迭代求解,不依赖任何物理库。
所有纹理程序化生成(canvas),零外部资产。

## 特性

- Verlet 积分,固定 1/120s 子步(累加器),约束迭代次数即刚度
- 风场:风向 / 风力滑杆实时生效,多层正弦阵风包络 + 空间非均匀扰动,
  风力按面片法线投影施加:`F = n · dot(n, wind − v) · area`(自带气动阻尼)
- 鼠标抓取:raycast 命中旗面 → 最近粒子钉在相机平面投影点,松手自然恢复
- 固定点模式:整边固定(旗帜)/ 仅两角固定(晾布绳 + 木桩场景联动)
- 法线逐帧重算、双面渲染受光、程序化「乘风」旗面图案
- L4:超应力撕裂(断约束 + 面片破洞)、旗杆圆柱碰撞、地面碰撞摩擦
- 场景氛围:渐变天空穹顶 + 太阳光晕、雾、远山剪影、草地、金属旗杆、飘尘粒子
- `window.__bench = { ready, stepFrame(n), getState() }` 评测钩子

## 启动

依赖由仓库主会话统一安装(根 node_modules 提升)。

```bash
npm run dev   # http://localhost:3028/
```

## 操作说明

| 操作 | 效果 |
|---|---|
| 左键拖拽旗面 | 抓取布料任意点,松手释放 |
| 空白处左键拖拽 | 旋转视角(OrbitControls) |
| 右键拖拽 | 平移视角 |
| 滚轮 | 缩放 |
| 右侧面板 | 分辨率(重建)/ 迭代次数 / 重力 / 阻尼 / 风向 / 风力 / 阵风 / 撕裂 / 固定模式 / 重置 |

## 验收要点自测

- 抓住旗角猛拽:布料被约束求解拉住,呈真实张力传播,不是正弦假波动
- 迭代次数调到 1:布料明显松弛发"糊";调到 15:明显硬挺
- 启用撕裂后猛拽:约束超应力断开,旗面出现破洞
