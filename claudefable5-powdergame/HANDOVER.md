# 交接文档 — claudefable5-powdergame（粉末实验室）

## 项目概况

- **任务**：复刻「落沙类」（falling-sand）物理沙盒玩法，做成全中文版本，元素名称附带化学式/符号，并尽可能塞入丰富的物理规律。
- **实现方式**：完全原创实现（未参考任何兄弟目录源码、未复制任何现成游戏代码/素材），纯原生 JavaScript + Canvas 2D，无运行时第三方依赖，仅用 Vite 做开发服务器。
- **端口**：`3020`（3018/3019 预留给磁盘上已存在但尚未注册端口的 `gpt5.5-powdergame`、`doubao2.1-ocean-weather`，避免并发会话端口冲突；RULES.md 允许端口留空不回收）。
- **启动**：根目录 `npm run dev:fable-powder`，或 `.claude/launch.json` 里的 `fable-powder` 配置。

## 技术架构

| 文件 | 职责 |
|------|------|
| `src/const.js` | 网格尺寸（360×240，CSS 放大 3 倍）、物态/标志位常量 |
| `src/elements.js` | **62 种元素**的声明式定义表（中文名、化学式、密度、导热率、电导、相变点、燃点、爆炸参数、颜色、说明），构建成类型化数组供热路径使用 |
| `src/engine.js` | 模拟核心：元胞自动机移动（粉/液/气/能量）+ 全部化学反应 + 温度场 + 风/气压场 + 爆炸 + 电路 + RLE 存档 |
| `src/render.js` | ImageData 渲染（1 细胞=1 像素），常规/温度/气压三视图，高温辉光 |
| `src/ui.js` | 工具栏（8 种工具）、元素面板（按分类分组的芯片）、指针交互、快捷键、状态栏、localStorage 存档 |
| `src/demo.js` | 示例场景（湖泊+油膜、铀矿地热、种子发芽、木屋蜡烛、盐水电解、岩浆房、克隆云降雪、风扇） |
| `src/main.js` | 主循环（RAF，支持 1×/2×/4× 与暂停/单步）+ `window.__pg` 调试钩子 |

### 数据结构（`engine.js`）

- `cells: Uint8Array` 元素 id；`temp: Float32Array` 摄氏温度；`life: Int16Array` 通用计数器（火焰寿命/阴燃进度/病毒衰减/导体放电不应期为负值）；`aux: Uint8Array` 复用字节（克隆记忆的元素 id / 火花底下的导体 id / 风扇朝向 / `0x80` 阴燃标志 / `0x40` 硝化甘油坠落标志 / `0x01` 液体流向记忆）；`stamp: Uint8Array` 帧标记防止一帧内重复更新。
- 风场：90×60 粗网格（每 4×4 细胞一格）`avx/avy/ap`，压强扩散 + 速度←压差 + 压强←散度，爆炸注入冲击波。
- 网格外圈是一整圈**不可擦除的墙**，因此内部循环不需要越界判断（性能关键设计）。
- 温度传导用**成对交换**式（右邻+下邻各交换一次），能量守恒且不振荡；相变带滞回区间（如水 -2°C 结冰 / 冰 +2°C 融化）防止边界抖动。

## 调试钩子（自动化验证用）

页面暴露 `window.__pg`：

```js
__pg.ready            // true 表示引擎就绪
__pg.step(n)          // 手动步进 n 帧并重绘（配合 pause 用，规避隐藏标签页 RAF 停摆）
__pg.pause(bool)      // 暂停/继续
__pg.paint(x, y, 'WATER', r) // 用元素 key 或 id 画圆
__pg.read(x, y)       // { key, name, sym, temp, life, aux }
__pg.count('SAND')    // 某元素粒子数；无参 = 总粒子数
__pg.pixel(x, y)      // 画布该点 RGB（截图不可用时的替代验证）
__pg.demo() / __pg.clear()
```

## 已知限制 / 注意点

- 化学做了游戏化简化：酸统一产物「盐水」、熔融金属不区分 Fe/Au/Pb、硫燃烧未单独建模 SO₂（并入烟）。
- 温度视图下依然计算完整模拟；4× 速度 + 满屏液体时帧率可能降到 ~40fps（网格 86,400 细胞，纯 JS 单线程）。
- 存档只有一个 localStorage 槽位，且不保存风场（读档后风场清零）。
- 病毒对大面积墙体结构无效（设计如此，防止无解局面）。
