# 子午冠球场

`grok4.7-stadium-worldcup` · three.js 0.185 / WebGL / Vite 8

一座按世界杯赛事条件从零原创的露天专业足球场。场地保持露天，看台有遮雨顶棚，不设跑道，也不放人物。容量按实际落下的座位统计，当前为 **85,682**。

单端口访问：`http://localhost:3000/grok4.7-stadium-worldcup/`\
单独调试：`npm run dev`（端口 3047）

## 造型

圆角矩形三层碗。屋盖是一圈径向钢桁架，内圈受拉、外圈受压，四角抬高、四边中点压低，形成冠顶。桅柱落在看台后缘，陶瓷鳍片挂在水平腰梁上。西看台为靛蓝座席，东看台为沙色，南北为赤陶，中线一排铜黄色，作为这条球场自己的图形，不是任何现成队徽。

## 赛事逻辑

- 球场 105 × 68 m，四边首排离边线 / 球门线 12 m
- 视线按 Green Guide 的 C 值逐排起坡，三层最小 C 值均为 90 mm
- 座宽 500 mm（俱乐部 540，包厢 560），径向通道约 1.35 m，每跨不超过 22 座
- 上层踏步超过 450 mm，通道按需设栏
- 16 座楼梯核合计约 165 m 出口宽度，按 66 人/分钟·米估算疏散约 7.9 分钟
- 轮椅位分散在横向通道和指定排

## 能走进去的空间

南广场楼梯进入下层环廊，环廊经径向通道走上看台。四座主楼梯继续连到俱乐部层和上层环廊。西侧包厢朝向场地。西看台下方有球员通道、主客队更衣室和新闻发布厅，通道在中线洞口通向场地。

## 视图

透视、俯视、南立面、西立面、横剖、纵剖、第一人称漫游。材质 / 白模 / X-ray，爆炸滑杆，时刻滑杆（白天到比赛夜灯）。左侧可隐藏或对焦各个部位。

周边餐饮、交通站、停车楼、转播用房以半透明白体块表示。训练场、广场铺装和水渠是场地本身，不是体块。
