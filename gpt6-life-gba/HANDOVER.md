# 交接 · 晴日小镇

更新日期：2026-09-05

## 请求与范围

用户原始请求：`复刻一个GBA风格的模拟人生游戏`。

实现为 ModelBenchLab 中独立的 `gpt6-life-gba/` 项目。使用原创代码像素画和生活模拟玩法，未改动已有同题游戏。根目录只为门户接入追加项目：`benchmark/registry.json`、`package.json` workspaces、`package-lock.json`。已有未提交修改保留，未提交或推送 Git，未发布到外部站点。

## 当前状态

两张可游玩的场景、22 个可到达互动目标、六项需求、即时和长行动、社交好感、挣钱/消费循环、四件家具升级、三个一次性心愿、昼夜、手账、自动/手动存档、中文帮助、确认重开、可选合成音乐、鼠标/键盘/手机屏上操作均已实现。

入口：<http://localhost:3000/gpt6-life-gba/>。交付时使用仓库原有的 Vite 3000 服务，没有终止或另起用户服务。下次环境未运行时，从根目录执行 `npm run dev`。

## 状态与时间约定

- `state` 是可序列化存档；短暂状态（按键、暂停、菜单、行走路线、行动进度）不持久化。
- 完成行动才结算时间、费用和效果；取消与刷新均不会留下半次扣费。
- 菜单、显式暂停、隐藏标签页均冻结模拟。帧间隔上限 50ms，避免回来时追赶时间。
- localStorage 键：`pocket-days-gpt6-v1`；读档必须走 `readSave`。不可信文本通过 `textContent` 显示。
- `window.__bench.getState()` 返回克隆的只读快照，`shot()` 返回游戏画布 PNG；不暴露任意改写进度的运行钩子。

## 已知边界与接手顺序

当前是浏览器生活模拟原型；不是 GBA ROM。地图为固定布局，家具购买后自动放到固定位置，没有自由建筑/拆墙。暂时只有一位可聊天邻居、一种兼职、三个搬家心愿，没有职业树、婚恋/家庭或季节天气系统。手机输入经过桌面浏览器窄屏与真实指针事件验证，未在物理手机设备实测。音乐确认了 WebAudio 开关和无运行错误，听感由使用者判断。

后续优先：先实际体验小屋与镇中心 → 根据反馈调整行走/时间和 UI 尺寸 → 再拓展 NPC、日常心愿、工作类型和家具摆放。修改场景布局时同步检查 `isWall` / 物件 footprint 与画面，重新跑路径与浏览器检查。
