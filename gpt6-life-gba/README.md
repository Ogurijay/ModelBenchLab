# 晴日小镇 · Pocket Days

一个可以直接游玩的 GBA 像素风生活模拟小游戏。你扮演刚搬到梧桐巷的小满，照顾自己、结识小葵、赚取零花钱，为小屋添置喜欢的家具。

原生 JavaScript + Canvas 2D，480 × 320 逻辑画布，像素画、场景、角色和音乐均由本项目代码生成。无需外部素材、账号或 API。它是原创美术的浏览器生活模拟作品，不是原版《模拟人生》的资源移植或可烧录的 GBA ROM。

## 开始游玩

在 ModelBenchLab 根目录执行：

```powershell
npm run dev
```

打开 <http://localhost:3000/gpt6-life-gba/>。项目也已登记到根门户的 Life Sim 分区。仓库统一使用端口 3000。

## 操作

| 操作 | 键盘 / 鼠标 / 触屏 |
| --- | --- |
| 走动 | WASD、方向键、点击地面、屏上方向键 |
| 家具或居民互动 | 点击对象自动走过去，或靠近后按 E / 空格 / Z / J / A 按钮 |
| 取消 | Esc；进行中的行动也可点击底部「取消行动」 |
| 暂停 / 继续 | P，或画面下方暂停按钮 |
| 调整速度 | 1× / 2× / 3× 按钮 |
| 前往另一场景 | 小屋门口 / 镇中心回家标牌，或「小镇地图」 |
| 家具商店 | 「家居小铺」或镇中心的杂货店 |
| 保存 | 自动保存，也可点「保存进度」 |
| 音乐 | 右上角声音按钮；默认关闭 |

菜单打开或浏览器标签页隐藏时，模拟时间暂停。切换回来不会补算后台时间。正常速度下，现实 1 秒相当于游戏 3 分钟；行动通过短进度条完成，在完成时统一结算时间、需求、花费和奖励。取消行动不结算。

## 可以做什么

- **照顾六项需求**：饱腹、精力、清洁、如厕、娱乐、社交；需求逐渐降低，角色头顶菱形随心情变化。精力耗尽会就地休息，如厕归零会降低清洁值。
- **探索两张地图**：带卧室、厨房、浴室、客厅和小院的小屋；含咖啡店、杂货店、邻居、猫、花圃和池塘的镇中心。
- **日常互动**：做饭、吃麦片、洗澡、上厕所、看电视、阅读、写信、浇花、睡觉；与小葵聊天送礼、摸橘猫、钓鱼。
- **生活经济**：开局 §500。每天可做一次 4 小时咖啡店兼职（§180，08:00–16:00 开始，精力至少 20）；照料花圃赚 §45，每日刷新。钓鱼赚 §20，完成后间隔 1 个游戏小时才能再钓。
- **不会没钱吃饭**：冰箱的麦片免费，适合重新积攒零钱。
- **三个搬家心愿**：吃饭、认识邻居、赚第一笔钱，各奖励 §30，奖励不会重复领取。
- **四件家具升级**：绿植、格纹地毯、落地灯、云朵床。购买后立即改变小屋外观；地毯减缓娱乐衰减，灯在新一天恢复额外精力，升级床提升小睡效果。
- **昼夜与存档**：夜晚场景变暗，睡觉到次日 07:00；生活手账保留最近 50 件事件。浏览器 localStorage 每 15 秒和重要行动后保存。

存档只属于当前浏览器、当前访问源。`localhost` 与 `127.0.0.1` 的存档彼此独立。浏览器禁用存储时会明确提示；仍可玩当前一局。帮助里的「重新开始生活」需要在游戏对话框再次确认。

## 检查与构建

```powershell
# 在仓库根目录执行
npm test --workspace gpt6-life-gba
npm run test:browser --workspace gpt6-life-gba
npm run build --workspace gpt6-life-gba
npm run sync:check
```

浏览器检查使用仓库已安装的 Playwright；优先使用其 Chromium，缺少时使用标准路径下的本机 Google Chrome。运行前需启动根端口 3000 服务。可通过 `POCKET_DAYS_URL` 指向其他已启动的同一作品地址。

生产构建输出到本目录 `dist/`，可交给静态 HTTP 服务，资源均使用相对路径。运行时没有外部网络依赖。`tests/capture.mjs` 可生成桌面、小镇和手机截图。测试截图、报告及本轮改动前快照都放在 Git 忽略的 `tmp/`。

本轮已通过 **33 项逻辑测试、19 项浏览器检查、生产构建和仓库同步检查**。真实浏览器验证覆盖鼠标寻路、键盘/屏上按键、需求恢复、兼职、购买、读档、物理门口转场、睡觉换日、暂停、低需求后果；控制台无报错。视觉检查覆盖 1440px 桌面和 390px 手机布局。游戏手感及与原作的相似程度仍由使用者实际体验评价。
