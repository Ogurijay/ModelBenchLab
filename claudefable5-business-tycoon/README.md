# 像素大亨 — 商业模拟养成（Claude Fable 5）

> 任务书：[`benchmark/tasks/code-to-ui/business-tycoon.md`](../benchmark/tasks/code-to-ui/business-tycoon.md)

原生 JavaScript + Canvas2D，零依赖、零素材（美术全程序化）、零服务端。localStorage 存档，桌面/移动端均可玩。

## 15 项机制 → 结算落点（`src/sim.js` 的 `calcBiz` / `dayTick`）

| # | 机制 | 结算变量 |
| --- | --- | --- |
| 1 | 选址与地价 | `distT`（城区客流×开发度）、`aff`（行业亲和）、地价随占地数 +12%/块 |
| 2 | 供需定价 | `qPrice = price^(-行业弹性)`，60%~160% 滑杆 |
| 3 | 供应品质 | 低价/标准/优质三档：材料成本 ×0.8/1/1.25，声望 -0.18/0/+0.22 每日 |
| 4 | 供应链协同 | 自有上游→下游材料 ×0.85（2 家 ×0.75，科技加深至 0.68）；上游获销路客量 ×1.1 |
| 5 | 雇员养成 | `staffM×skillM×moraleM`：人数/技能/士气/三档薪酬 |
| 6 | 升级扩建 | 容量 +32%/级、品质 +7%/级、物业 +40%/级，建筑外观长高 |
| 7 | 科技研发 | 28 项 eff 聚合进 `techEff()`（营收/工资/物业/解锁/折扣…） |
| 8 | 营销与品牌 | 活动挂 `fx` 持续效果；品牌值 → 全城需求 ×(1+brand/250) |
| 9 | 数字化经营 | 外卖(触达1.25/佣金8%)、小程序(1.18/2%)、自动化(工资×0.7) |
| 10 | 银行信贷 | 额度=3万+净资产×0.6；日息随信用分 400~850 浮动；月度信用结算 |
| 11 | 股票投资 | 日行情=宏观漂移+个股波动；季度分红；牌照/手续费科技 |
| 12 | 城市事件 | 28 种按季节/条件加权掷出，效果直接改写 `fx` 乘数；抉择事件暂停待选 |
| 13 | 竞争对手 AI | 同区同业份额 `share=w/(w+0.42×对手数)`；对手月度拿地开店/升级，可溢价收购 |
| 14 | 声望系统 | 门店 0~100 声望 → 需求 ×(0.75+rep/200)，由供应/人效/事件驱动 |
| 15 | 经济周期与四季 | 繁荣/平稳/衰退马尔可夫月度切换（econ.idx 0.65~1.35）；季节需求曲线 |

## 玩法循环

买地 → 开店（121 选 1）→ 雇人 → 五策略调参（定价/供应/薪酬/数字化/促销）→ 逐日结算盈亏（账本可查）→ 研发/营销/信贷/股票 → 跨区连锁扩张 & 收购对手 → 17 步目标链直至净资产 ¥1000 万。现金连续 15 天低于 -¥5 万破产清算。

## 像素街景（`src/render.js`）

440×280 内部分辨率整数倍放大（`image-rendering: pixelated`）。建筑按行业 12 套配色程序化生成：楼高随等级、窗灯随昼夜、招牌含 8×8 位图行业图标与店名、餐饮零售条纹雨棚、科技天线、工厂烟囱。昼夜 120s 循环（日月/窗灯/路灯光晕/车灯），四季变装（樱花/骄阳/红叶/落雪），台风事件下雨幕。行人车流密度联动城区客流。月度结算时门店头顶飘出盈亏金额。

## 架构

```
index.html        布局 + 像素主题 CSS（响应式，≤1020px 面板下移）
src/data.js       静态数据单一事实源（121 业态/28 科技/28 事件/…）
src/sim.js        纯逻辑引擎：xorshift32 确定性随机、calcBiz 日结算、dayTick 世界推进
src/game.js       玩家动作层（全部返回 {ok,msg}）+ localStorage 存读档
src/render.js     程序化像素街景渲染器（点击拾取/悬停提示/飘字）
src/ui.js         7 面板（经营/图鉴/科技/金融/营销/账本/目标）+ 弹窗 + 提示
src/selftest.js   16 项确定性自测（?selftest=1）
src/main.js       主循环/速度控制/自动存档/__TYCOON__ 调试接口
```

- 一切游戏随机数经可序列化 xorshift32（`state.rngS`）——同种子完全确定，存读档后推进结果逐字节一致（自测 #11）。
- 装饰性动画（云/行人/雪）用 `Math.random`，不污染逻辑随机流。
- 页面隐藏时 rAF 挂起，由 250ms interval 兜底继续模拟；后台现金转负自动暂停防挂机破产；`beforeunload` 落盘存档。
- 调试接口：`__TYCOON__.ff(n)` 快进 n 天、`.setVt(v)` 调昼夜相位、`.setDist(id)` 切城区、`.getState()`。
