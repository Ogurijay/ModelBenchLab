# 沧澜 · PELAGIC STORM — 写实全天候海洋模拟 (Gemini 4)

ModelBenchLab 海洋任务（`code3d-ocean-001` v1，mission `ocean`，variant `realistic`）的 Gemini 4 实现。融合**写实海洋光学渲染（`realistic`）**与**全天候极端气象风暴系统（`weather` / `storm`）**。

- **统一门户访问**：根目录运行 `npm run dev`，访问 **http://localhost:3000/gemini4-ocean-realistic/**
- **独立并行调试**：根目录运行 `npm run dev:one -- gemini4-ocean-realistic`（或子目录 `vite --port 3073 --strictPort`），访问 `http://localhost:3073/`

## 核心特性

1. **JONSWAP 定向风浪谱 + 双簇远洋涌浪（CPU/GPU 严格同源）**：
   - 24 组确定性 Gerstner 波分量（18 组 JONSWAP 定向风浪 + 6 组远洋交叉长涌），幅度严格归一化至合成有效波高 $H_s = 4\sqrt{\sum a_i^2 / 2}$，总陡度受限防折叠。
   - 相机跟随的无缝指数径向网格（近场高密度解析细浪，远场延展至 14 km 地平线并按距离平滑衰减短波）。
   - CPU 端使用 3 步不动点逆映射反求水平拉格朗日位移，输出与 GPU 顶点完全一致的高度、法线、雅可比行列式与水质点轨道速度。
2. **写实海面光学与多源泡沫**：
   - 顶点解析法线 + 片元多频 FBM 微波纹法线 + 暴雨同心涟漪法线（按距离平滑抗锯齿过滤）。
   - Schlick 菲涅尔反射（与天穹共用同一套瑞利/米氏大气散射与双层体积感云层函数）。
   - GGX 微表面太阳高光长路 + 浪尖逆光翡翠色次表面散射（SSS）。
   - 五重泡沫合成：雅可比行列式 $J$ 浪尖破碎白沫、强风朗缪尔风成白沫条带、科考船螺旋桨尾流、灯塔礁石拍岸浪花、水龙卷底部旋涡泡沫环，经多孔气泡噪声调制。
3. **6 档全天候海况与极端风暴系统**：
   - `1 玻璃晨海` · `2 晴朗信风` · `3 落日熔金` · `4 浓雾孤航` · `5 暴雨狂风` · `6 雷暴龙卷`，支持 1.15 秒平滑插值切换。
   - **程序化 3D 分叉闪电**：含主干与多级分叉、双脉冲回击闪烁、云海同步高光照明与距离延迟滚雷声。
   - **远海 3D 水龙卷（Waterspout）**：蜿蜒旋转的漏斗云柱 + 底部螺旋吸升水雾粒子 + 海面低压涌升与漏斗旋涡变形 + 对周围浮体的切向气旋牵引。
   - **动态斜雨幕**：3200 条随风向倾斜的 GPU 雨丝与海面雨滴涟漪联动。
4. **多点阿基米德浮力与丰富交互**：
   - **远洋科考拖网船**：6 点浮力采样、旋转雷达、夜航红绿舷灯、探照灯光束，支持自动巡航或 `WASD` / 方向键手动驾船。
   - **红绿双航标与实时波高计**：系泊锚链弹性约束，1 号航标实时采集并绘制最近 30 秒海面波高曲线。
   - **远景玄武岩灯塔岛**：红白灯塔与双道旋转引航光束。
   - **点击投放与拖拽抛掷**：支持木箱、油桶、救生圈、探测球四类浮体点击海面投放或拖拽抛投，入水触发水花环与水花声。
   - **双轨界面**：毛玻璃气象遥测 HUD + `lil-gui` 全参数调试面板（含法线 / 雅可比泡沫 / 菲涅尔 / SSS 调试视图）。

## 快捷键与操作

| 操作 | 功能 |
|---|---|
| 鼠标左键拖拽 / 滚轮 / 右键 | 旋转视角 / 缩放 / 平移（相机受局部波面高度安全托举，不穿水底） |
| 点击海面 | 在点击处投放当前选中的浮体（木箱 / 油桶 / 救生圈 / 探测球） |
| 按住浮体拖拽并松手 | 提起浮体并按鼠标速度抛投出舱 |
| `1` – `6` | 切换 6 档全天候海况预设 |
| `W` `A` `S` `D` / 方向键 | 手动驾驶科考船前进、后退、转向 |
| `L` | 立即劈下一道 3D 分叉闪电 |
| `T` | 切换远海 3D 水龙卷开关 |
| `F` | 切换自由远眺 / 随船航行机位 |
| `C` | 清空动态投放的浮体 |
| `Space` | 暂停 / 继续模拟 |
| `H` / `Esc` | 切换纯净观海模式（隐藏全部 UI） |
