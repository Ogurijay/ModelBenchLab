# 改动记录 — gemini4-ocean-realistic

## 2026-11-09

- **新建项目**：根据用户要求创建 `gemini4-ocean-realistic`（模型：`Gemini 4`，调试端口：`3073`），同时实现写实海洋渲染（`realistic`）与全天候风暴系统（`weather` / `storm`）。
- **核心海面与大气**：实现 32 分量宽频无理数间隔 Gerstner 波谱、CPU/GPU 同源波群空间包络与波脊相位扭曲、6 层非周期域扭曲尖脊细浪法线（消除固定宽度与固定间距条纹感）、瑞利/米氏大气散射与体积感云层、双瓣 GGX 太阳光路、次表面散射（SSS）及五源多孔泡沫。
- **天气与风暴**：实现 6 档海况平滑过渡（玻璃晨海 / 晴朗信风 / 落日熔金 / 浓雾孤航 / 暴雨狂风 / 雷暴龙卷）、GPU 斜雨幕与海面雨滴涟漪、3D 分叉闪电与合成滚雷、3D 远海水龙卷漏斗云与旋涡力场。
- **浮体与交互**：实现多点浮力科考拖网船（支持自动巡航与 `WASD` 驾船）、红绿双系泊航标与 30s 实时波高计、远海玄武岩灯塔岛、4 类可点击投放与拖拽抛掷浮体、合成海浪风雨雷暴音效，以及 HUD + `lil-gui` 双轨控制面板。
- **验证与登记**：编写并通过 5 项波谱与物理单元测试，完成 `benchmark/registry.json`、`package.json`、`package-lock.json` 登记并通过 `npm run sync:check`。
