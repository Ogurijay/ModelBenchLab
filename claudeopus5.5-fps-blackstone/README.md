# 黑石行动 BLACKSTONE（Claude Opus 5.5）

基于 Three.js 的第一人称射击游戏。2087 年，自律兵器工厂“黑石前哨站”的中枢 AI VEGA 失控，玩家扮演唯一潜入的“幽灵-1”。

任务：`code3d-fps-001` v1（mission `fps`），题面见 [`benchmark/tasks/code-to-3d/fps.md`](../benchmark/tasks/code-to-3d/fps.md)。原始 prompt 只有一句「做一个基于three.js的fps游戏」。

## 内容

- **剧情任务**（约 8–12 分钟）：南侧峡谷渗透 → 骇入闸门（按住 E）→ 穿过庭院到 C2 机房 → 守住数据下载（离开机房会断线暂停，五批增援）→ 反应堆大厅三座冷却塔安放炸药 → 90 秒倒计时内赶到东北停机坪登上直升机。
- **生存模式**：无尽波次，第 2 波起出现猎犬、第 3 波起出现无人机、每 5 波出现主宰者；波间补给、得分与最高纪录（localStorage）。
- **武器**：AR-7 步枪（全自动）、P9 手枪、M12 泵动霰弹（逐发装填可打断）、L-50 栓动狙击（开镜、穿透）；手雷（弹跳 + 引信）、枪托近战。后坐回正、移动/空中/蹲伏散布、开镜放大、动态准星、弹壳抛出、曳光。
- **敌人**：哨兵（步枪点射、走位找射击位）、猎犬（之字冲锋扑咬）、黄蜂无人机（环绕飞行、等离子弹）、主宰者（转管机枪预热扫射 + 追踪火箭，头部弱点可打出硬直）。敌方弹丸可见可躲避，掠过有呼啸声；感知分视锥 + 视线 + 警觉累积，枪声与爆炸会惊动附近敌人；死亡时按部件解体飞散。
- **关卡**：外围墙、庭院集装箱、A1 仓库（上层环形走廊 + 军械库）、C2 控制中心（四个房间多入口）、R 反应堆大厅（北侧高架走廊）、燃料库、停机坪；可引爆油桶、补给箱、三道动态门。
- **表现**：全部贴图程序化生成（混凝土、瓦楞集装箱、警示条纹、标识文字等），黄昏天空与云、阴影、泛光、受伤/低血后期；音效与音乐全部 WebAudio 合成（枪声、换弹拟音、脚步按地面材质、HRTF 空间化、室内混响、动态战斗音乐）。
- **HUD**：雷达、指南针、目标面板、世界航点、受击方向、命中/爆头/击杀标记、击杀信息、无线电字幕、交互读条、狙击镜。

## 技术

- Three.js `^0.185.1` + Vite 8，无运行时外部资源。
- 碰撞：自写轴对齐盒 + 楔形坡道 + 2D 网格加速（`src/world/collision.js`），角色为竖直圆柱分轴解算，带台阶抬升与下坡贴地。
- 导航：按 1 m 网格对碰撞世界采样所有可站立表面（含走廊、坡道层），A* + 视线拉直（`src/world/nav.js`）。
- 第一人称武器使用独立场景与相机渲染，避免穿墙。
- `window.__bench` 提供无头驱动接口（start/step/hold/tap/aimAt/teleport/state/snapshot/perf）。
