# 暴风王都全景 · 内外可穿行 — Claude Opus 5

`claudeopus5-stormwind-interiors` · three.js 0.185 / WebGL / Vite 8 · 单端口访问 `http://localhost:3000/claudeopus5-stormwind-interiors/`

一座**完全程序化生成**的奇幻人类王都(暴风城风格:灰白砌石 + 青蓝鱼鳞瓦 + 半木构民居 + 运河与大教堂)。
与常见"城市外壳"演示的关键差别是:**这座城是空心的**——80 余栋民居 / 店铺 / 酒馆 / 铁匠铺 / 仓库,
每一栋都有真实内景:推开门走进去、上二楼、看壁炉与炉火、从窗内往街上看。

> 全部几何与贴图在运行时由代码生成,零外部二进制资产(无模型、无图片、无音频)。
> 建筑形制为原创设计,不含任何第三方美术资源。

## 一句话技术主张

**"能进屋"不是额外做的开关,而是几何本身的结果。**
墙体由带门窗洞的 `Shape` 拉伸而成,同一套洞口切分同时产出几何与碰撞盒 —— 门洞处天然没有碰撞体,
于是"推门进屋"与"墙挡住人"来自同一份数据,不可能出现"看得见走不进去"的错位。

## 玩法

| 操作 | 说明 |
| --- | --- |
| 点击画面 | 锁定鼠标进入第一人称;`ESC` 退出 |
| `W` `A` `S` `D` | 行走 · `⇧` 疾跑 · `空格` 跳 |
| `F` | 行走 ⇄ 自由飞行(飞行时滚轮调速,`空格`/`C` 升降) |
| `R` | 掀屋顶(剖视全城内景) |
| `M` | 回到全景巡游 |
| 右侧面板 | 10 处传送点 + "随机进一户人家" + 时辰滑杆 + 昼夜自动 + 画质 |

## 城市构成

- **城墙**:八边形棱堡(400 × 390 m),8 座角楼、雉堞、马道 —— 马道可沿四处登城楼梯走上去绕城一圈
- **狮王之门**:双塔门楼、半升起的闸门、门楼火盆
- **运河区**:东西贯通的主运河穿两侧水门,支渠通向大教堂;6 座石拱桥(英雄桥为三孔大桥)
- **交易广场**:直径 92 m 圆形广场、多层喷泉与英雄铜像、市集摊位、货车、长桌
- **圣光大教堂**:42 × 70 m,双塔 44 m + 尖顶,玫瑰窗、彩窗、**可进入的中殿**(柱列 / 筒形拱顶 / 长椅 / 祭坛 / 吊灯)
- **王座城堡**:9 m 高台地 + 30 级大台阶,四角塔与 46 m 主塔,**可进入的王座厅**(御座 / 红毯 / 火盆 / 旗幔)
- **西港码头**:港池、两条帆船、栈桥、吊车、灯塔、仓库
- **王家花园**:起伏草地、凉亭、水池、绿篱、长椅、树林
- **熔炉工坊区 / 旧城民居 / 城根巷**:成片沿街立面,半木构 + 出挑二层 + 老虎窗 + 店招 + 雨棚

## 运行

```bash
npm run dev
```

浏览器打开 `http://localhost:3000/claudeopus5-stormwind-interiors/`。
单独调试可用 `npm run dev:one claudeopus5-stormwind-interiors`（端口 3046）。

## 评测钩子

`window.__BENCH__` 暴露:`stats()` / `teleport(name)` / `setMode` / `setTime(h)` / `setXray(b)` /
`setView(pos,target)` / `setSize(w,h)` / `renderNow()` / `step(dt)` / `key(code,down)` / `probe(x,z)` / `lights()`。

其中 `renderNow()` 与 `setSize()` 是为"标签页隐藏时 rAF 停摆"准备的取证接口;
`step()` + `key()` 可以跑端到端行为验证(例如"传送进屋后脚底标高是否等于室内地坪")。

技术细节与已知问题见 [HANDOVER.md](HANDOVER.md)。
