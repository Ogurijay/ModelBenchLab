# 交接文档 — claudeopus5-stormwind-interiors

最后更新:2026-07-27 · 状态:可运行,主体功能完成

## 1. 项目目标

用 three.js 生成一座**内外都能看**的奇幻王都全景。评判这个项目是否成立,只看一件事:
**随便走到一栋房子门口,能不能推门进去、上二楼、再从窗户看回街上。**
外观再漂亮,如果建筑是实心壳子,这个项目就是失败的。

## 3. 三条贯穿全局的约定(改代码前必须知道)

### 3.1 UV 一律是「米」

`geom.js` 里所有构件的 UV 都换算成世界米(`uvMeters` / `uvMetersRadial`),
材质则设 `repeat = 1 / 该贴图代表的物理尺寸`。好处是城墙、屋瓦、地面的贴图密度天然一致,
**新增构件不需要单独调 repeat**;代价是不能直接用 `BoxGeometry` 原始 UV,必须走 `geom.js` 的包装。

### 3.2 几何与碰撞盒同源

`wallWithOpenings({width,height,thickness,openings})` 返回 `{geo, boxes}`:
- `geo` 是带洞的拉伸体(门/窗/拱洞,`arch:true` 走半圆券)
- `boxes` 是同一套洞口切分出来的实体条带 —— **洞口处不产生碰撞盒**

所以"能走进门"和"墙能挡人"用的是同一份数据。任何新墙体都必须走这个函数,
不要自己拼 `BoxGeometry` 再手写碰撞盒。

### 3.3 局部坐标 → placer

`interior.js` 的 `placer(collector, x, y, z, ry)` 负责把局部构件搬到世界坐标。
**`p.emit({x,y,z})` 里的坐标是局部坐标**,会被 placer 再变换一次。
(踩过的坑:路灯写成 `L.emit({x, z})` 把光源甩到了两倍坐标处,灯罩发亮但地面不亮。)

同理,几何要"先在原点建好,再 rotate,最后 translate"。先平移后旋转会绕世界原点甩飞构件。

## 4. 性能结构

| 手段 | 说明 |
| --- | --- |
| 外壳分区合并 | 建筑外壳按 `材质#分区`(135 m 网格)合并,既省 drawcall 又保住视锥/阴影剔除 |
| 屋顶独立成组 | `roofGroup` 单独一组,`R` 键整体隐藏即"掀屋顶" |
| 室内按建筑分组 | 每栋一个 `Group`,默认 `visible=false`,相机 30 m 内才打开(剖视模式 150 m) |
| 光源池 | 全城 500+ 处火光/路灯只用 10 盏 `PointLight`,每 0.22 s 按距离改派 |
| 实例化 | 树木与市民用 `InstancedMesh`(市民 5 个 mesh 撑起全城人流) |

实测(1600×900,街面视角):单帧约 4 ms,约 143 万三角形、360 drawcall。

**注意:three r155 之后点光源是物理单位(坎德拉,1/d² 衰减)。** 各处 `emit` 只写相对亮度,
统一增益在 `effects.js` 的 `LIGHT_GAIN`(当前 9.5),要整体调亮改这一个常量。

## 5. 地面分层(容易改坏的地方)

从下到上:
1. 城外地形网格 —— **城区矩形范围内的格子被整片挖空**。不挖空的话,这张 2800 m 的大平面
   会从运河的挖洞里顶出来,把水面盖成一条草地。
2. 城内地坪:横向条带 × 矩形差集(`subtractRects`)减去所有水域。**不要改用 Shape+holes**,
   运河交汇处的三角化不稳定。
3. 街道铺装 / 广场 / 花园草地(y ≈ 0.02~0.12)
4. 运河:渠底(-4.1~-3.4,有碰撞盒) → 驳岸 → 压顶石(兼护栏)→ 水面(-0.42)

`makeHeightField` 同时是**玩家的地面高度回落值**,城内恒为 0;真正的站立高度取
`max(碰撞盒顶, 地形高度)`。

## 6. 已知问题 / 后续可做

- **贴图重复感**:石墙与草地在大面积上能看出规则网格。可加一层低频噪声叠加或做贴图变体。
- **市民不进屋**:NPC 只沿街道折返,不会开门进店;也没有与玩家的避让。
- **无声音**:仓库规则禁止外部音频资产,程序化音效尚未做。
- **水面无实时反射**:菲涅尔混天空色 + 高光,靠色彩演;要真反射需加一个反射通道(性能代价大)。
- **室内二层家具较套路**:床/箱/桌的组合变化有限,可按 kind 再细分。
- **城墙外侧地形起伏偏弱**,远山靠 FBM 抬升,没有独立山体建模。
- 花园区的东支渠在早期版本会被草地盖住,已删除该支渠;若要恢复需同时在 `terrain.js` 的
  花园草地平面里挖洞。

__BENCH__.step(dt)         // 手动推进一帧(标签页隐藏时 rAF 停摆)

__BENCH__.setSize(w, h)    // 预览面板未显示时窗口是 0,取证前先定分辨率
