- 新增玩家和立方体的位置、朝向、速度传送变换与防抖冷却。
- 新增第一人称 WASD、鼠标视角、跳跃、奔跑、立方体拾取 / 放下和完整重置。
- 新增 `1 / 120s` 固定时间步、自写 AABB 碰撞与后台恢复保护。
- 新增中文引导页、HUD、动态目标、交互提示和通关统计。
- 新增程序化面板 / 地板 / 标识 / 微粒和 Web Audio 合成音效。
- 新增 `window.__bench` 五项接口与 Node 内置测试套件。
