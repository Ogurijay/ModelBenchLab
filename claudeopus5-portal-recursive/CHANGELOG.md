# CHANGELOG — claudeopus5-portal-recursive

## 2026-07-24 多维审查修复轮(6 维并行审查 + 双怀疑者对抗验证,73 个 agent)

审查产出 22 条发现,以下为确认并已修复的:

**渲染**
- 合并几何 ±X/±Y 四类面**绕序反了**(u×v 得到的是 −n):FrontSide 材质把近侧面剔掉、露出盒子的远侧面,
  且法线朝里导致这些面几乎不吃光 → 修正 FACES 的面内轴配对(X 用 y×z、Y 用 z×x)
- 贴近门面时的「顶出」没有上限,眼睛距门面 <0.21m 时门盘会落进近裁剪面之内甚至翻到相机背后,
  **门内画面在临穿越前整段消失** → 顶出量夹在 `along − 0.11` 以内,门盘改 DoubleSide
- 递归第二层被 **sRGB 编码两次**(渲进 RT 那一遍也在编码)→ 新增 `uEncode`,只有最终写画布才转换
- `setDepth(2→1)` 后高层 RT 既不释放也不再跟随窗口尺寸 → 重建循环覆盖全部层级并置 null
- HUD 的「N 次绘制」只统计了主通道(three 每次 render 都会重置统计)→ `info.autoReset=false` + 每帧手动重置

**穿门数学**
- `onTeleport` 近竖直分支的 yaw **反了 180°**:从地面门弹出后视线正对来路,按住 W 会用 22m/s² 的空中
  操控把飞跃刹停 → 改为 `atan2(up.x, up.z)`,两分支在分界处连续
- 穿门滚转**符号取反**,视角误差是「完全不滚转」的两倍 → 改为 `atan2(−up·right, up·camUp)`

**碰撞与开孔**
- 单扇门也会开孔,而未配对的门不触发传送 → 墙里出现「进得去、不传送、出不来」的空腔,
  地面门口更会把玩家弹成无限上下抖动 → **只有配对时才开孔**
- 开孔深度探针取「所有相交盒的最深点」,一块掠过边缘的地板就能把开孔挖到墙背后的虚空 →
  改为沿 −N 逐点步进,只挖穿与门面连续的材料
- 内角处门口有一部分埋进相邻垂直墙,从该门出来会被挤出地图或永久冻结 → 新增 `apertureClear` 校验
- `overlapping` 用对方的坐标轴量自己的门口且不对称,两扇朝向不同的地面门真相交也会放行 →
  改用世界 AABB 的 `aperturesOverlap`
- 换门位置会把旧洞的墙补回来,玩家若正在洞里会被永久冻结(推出距离超过两个上限)→ 新增 `unstick`
  兜底链:温和推 → 六向挤 → 送回出生点

## 2026-07-24 初版实现

mission `portal` 的 Claude Opus 5 作答(variant: recursive),与同题其它作答完全独立实现。

### 架构

- **门口布尔开孔**:放门时把门口棱柱从墙体真减掉(`core/boxes.js` 的 6 块补集减法),
  碰撞与可通行区域天然一致;门背面用「只对背面实体生效」的背板封住,不会变成双向免费通道
- **两层递归门景**(L4):RT 链由深到浅渲染 + Lengyel 斜近裁剪,门里有门、门里的门里还有门
- **分块扫掠运动**:每个 1/120s 子步再按位移切成 ≤9cm 的小块,高速飞跃(18 m/s)不会漏检门面,
  传送发生在真实越面时刻,剩余位移在另一侧继续走完
- 关卡几何、门洞、窗洞、传送门开口共用同一套盒运算;渲染按材质合并,每材质一次 draw call
- 穿门后朝向由变换后的前向量重建,上向量偏差转成 0.25s 内回正的**滚转平滑**(L4);
  出口是地面/天花板门时朝向会退化成竖直,此时改用变换后的上向量定水平朝向并把俯仰夹在 ±69°

### 内容

- 5 间递进测试室:固定门教学 → 单色枪 → 方块与按钮(深坑)→ 动量飞跃 → 综合测验
- 可搬运方块(含穿门保动量)、重量按钮、双扇滑门、消解栅、出口电梯、跌落自动重生、R 重置
- 中文 UI:HUD / 横幅 / 令牌式过场 / 选关(localStorage 解锁)/ 自测弹窗 / 门中门层数切换
- WebAudio 程序化音效与环境低鸣;canvas 程序化贴图;零外部资产
- `window.__bench = { ready, stepFrame, getState, portalTest, game, chambers }`
