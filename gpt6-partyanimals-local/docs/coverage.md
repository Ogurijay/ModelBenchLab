## 本项目实现对照

| 功能族 | 本地实现 | 当前边界 |
|---|---|---|
| 移动 / 拳脚 / 头槌 / 飞踢 | 体力、意识、击晕、恢复、冲量；正常行走抬头 | 输入、恢复和姿态已测试；未认定等同原作手感 |
| 抓取 / 举起 / 投掷 / 抓沿 | 真实球关节、握力、主动举起、攀爬、持物跳跃 | 实际抓取投掷已试玩；攀爬、持物跳跃有逻辑测试 |
| 淘汰赛 | 13 种地图机关、个人或队伍、连续回合 | 原创场景，不是原作地图几何 |
| 抢分赛 | 球类、搬运、火炉、街机、投石、气球 | 部分规则为独立简化复现 |
| SMASH / What If | 12 项能力卡与 4 项变异规则；多名本地玩家依次选卡 | 双人选卡与分屏已试玩；非原作全部卡牌及限时规则 |
| 卡丁车 | 3 赛道、检查点、漂移、5 道具、AI、三圈 | 非原作全部赛道 / 赛车道具 |
| Final Destination | 列车、横梁与断裂车厢 | 原创场景 |
| Black Sails | 炮击、修船、跳帮、船体胜负 | 简化舰船规则 |
| Crisis | 单人 + AI 隐藏身份、维修、破坏、报告、投票 | 非原作全部身份和任务小游戏 |
| 小屋 | 四季外观、PAWS 手牌交接、钓鱼、图鉴、售鱼、鱼竿 | 桌游交接及一次完整钓鱼已试玩；其它桌游 / 原作全部生活互动未覆盖 |
| 本地系统 | 16 动物、8 装扮、商店、成就、任务、存档、设置、教学 | 非原作全部角色 / 皮肤 / 经济内容 |
| 本地多人 | 1–4 人、键盘 / 手柄、共屏或分屏 | 双键盘与双人分屏已试玩；真机手柄待核验；推理暂为单人 + AI |
| 观众与表现 | 观众投掷干扰、表情、弹道、警示范围与截图 | 独立实现；非原作全部道具和表现效果 |
| 联机与网络 | 排除 | 用户明确排除 |

## 不得省略的差距

当前实现不能声称等同原作当前版本的全部非网络内容。原作全部角色、联动皮肤、地图几何、能力卡、赛车场景、实验室桌游、任务与成就需要逐项采集和实现。当前仅有官方公开概览和更新公告，未获得完整且冻结的当前客户端功能清单。

每种模式必须验证实际输入、目标变化、失败 / 胜利、退出 / 重开、保存恢复。自动化逻辑测试与内置浏览器实际试玩分开记录。

当前 19 项自动化测试通过，所有场景已有固定种子的 AI 稳定性检查；已进行的人工流程、测试条件和未覆盖的人工验收见 [验收记录](validation.md)。这些证据不能证明原作内容完全等价。
