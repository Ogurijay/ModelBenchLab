# 毛球俱乐部 · PARTY CLUB

Three.js 0.185.1 + Rapier 0.12.0 的本地动物物理派对。用户要求当前版《猛兽派对》的全部非网络功能；具体覆盖状态见 [功能对照](docs/coverage.md)，不以入口数量宣称与原作完全等价。

已实现 10 类模式、33 个场景、16 种动物、12 种武器、12 项能力、8 种装扮，以及三条卡丁车赛道、PAWS 桌游、钓鱼和本地进度。支持单人对 AI、双人键盘及最多四人共屏或分屏；推理与列车决斗限制为一名本地玩家。19 项自动化测试通过，并在内置浏览器中验证生产构建；范围与未验证项见 [验收记录](docs/validation.md)。这不代表原作全部内容已经逐项复刻。

## 运行

- 统一门户：根目录 `npm run dev` → http://localhost:3000/gpt6-partyanimals-local/
- 并行开发：根目录 `npm run dev:one -- gpt6-partyanimals-local` → http://localhost:3069/
- 项目目录：`npm run dev` / `npm run build` / `npm run preview`；独立开发、生产预览均固定 3069 strictPort，不同时启动。
- 测试：根目录 `npm test --workspace gpt6-partyanimals-local`。
- 构建在本项目 `dist/`；临时截图及检查报告放仓库 `tmp/partyanimals-local/`，不提交。

全部素材由程序生成，运行不需要外部 CDN、图片或联网服务。键鼠、本地双键盘布局、最多四个手柄及触屏。玩家 3 / 4 需要手柄。存档保存在本浏览器，支持导出与导入。

## 操作

1P：WASD 移动，Shift 冲刺，Space 跳跃，J / 鼠标左键出拳，K 踢，L 按住蓄力头槌、松开释放，E / 鼠标右键按住抓取，持抓自动举起，R 投掷，F 交互，T 表情，Esc 暂停。

2P：方向键移动，右 Shift 冲刺，数字键盘 0 跳跃，数字键盘 1 / 2 / 3 拳 / 踢 / 头槌，数字键盘 4 抓，5 投掷，6 交互。

赛车：W 加速，S 倒车，AD 转向，Shift 刹车，E 漂移，J 使用道具。钓鱼：Space / F 抛竿与提竿，按住 E 收线，也可使用画面按钮。桌游使用画面按钮；本地多人通过交接遮罩保护手牌。

被抓住后可通过拳、踢、跳挣脱；持物跳跃会保留抓取。淘汰后的观众可移动准星并按 J 投掷干扰物。

## 技术边界

本项目为独立功能复现，非原作源码或资产移植。采用 60Hz 固定步进、关节布娃娃与分离模式规则。默认不创建任何联网功能。渲染采用 WebGL 2；失去窗口焦点时自动暂停。验收结果见 HANDOVER.md。

已修复正常行走时头部下垂：增强清醒状态的头部关节回正力度，测得行走 / 冲刺倾角由约 43–46° 降至约 2°。眩晕时仍保留自由摆动。
