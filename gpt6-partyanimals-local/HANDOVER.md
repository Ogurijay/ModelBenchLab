# 交接

2026-10-13：本地游戏已整合并完成下述验证。用户要求的原作当前版本全部非网络内容尚未逐项对齐，不能称为完整复刻；差距记录在 [功能对照](docs/coverage.md)。用户指定 Three.js 0.185.1，并仅授权内置浏览器交互验收。

## 运行与约束

- Three.js 0.185.1、Rapier 0.12.0、WebGL 2、60Hz 固定物理步进。
- 独立开发或生产预览固定 3069 strictPort；统一门户路径 `/gpt6-partyanimals-local/`。当前交付页面为 `http://127.0.0.1:3069/` 的生产预览。
- `npm test --workspace gpt6-partyanimals-local`；`npm run build --workspace gpt6-partyanimals-local`。
- 本地存档含试玩形成的比赛、钓鱼与奖励记录，保留这些数据。支持界面导出与导入。
- 仓库包含大量并行改动，仅本项目与必要的工作区、锁文件、注册表、任务登记属于本次工作。未提交或推送。

## 模块

- `src/catalog.js`、`maps.js`：内容目录、碰撞几何、场地机关与赛道。
- `src/simulation.js`：关节角色、战斗、抓取、武器、AI、淘汰 / 目标规则、身份与投票、观众交互。
- `src/kart.js`：赛车运动、漂移、道具与有序检查点；`activities.js`：PAWS 与钓鱼。
- `src/art.js`、`render.js`：程序模型、姿态、粒子、灯光、分屏与摄像机。
- `src/main.js`、`style.css`：完整菜单、角色与模式选择、设置、商店、进度、回合结算和重开。
- `src/input.js`、`audio.js`、`profile.js`：输入、合成音效、本地存档与奖励。
- `#bench-state` 与页面 benchmark 状态只供读取运行数据，不提供跳过对局或自动取胜接口。

## 修复与验证

正常行走低头源于头部关节回正力度不足。清醒状态的头部伺服力度由 6 提升至 65，保留真实关节；眩晕分支不施加此回正。相同诊断测得修复前行走 45.93°、冲刺 42.93°，修复后分别为 1.74°、2.05°，并增加倾角回归测试。内置浏览器实际移动后确认角色抬头正常。

项目自动化测试 19 / 19 通过；构建通过。全仓 `sync:check` 通过（64 个项目），`policy:test` 16 / 16 通过，`benchmark:check` 通过但运行记录为 0，尚未开展正式评测。生产主包约 2.74 MB，gzip 约 0.95 MB，包含内联物理 WASM；构建有体积提示。

内置浏览器已验证训练输入、真实抓取投掷、双键盘移动、双人 SMASH 选卡及分屏、卡丁车加速 / 漂移 / 道具、推理会议、小屋桌游交接、完整钓鱼收获、存档恢复，以及 390px 布局和触屏按钮驱动物理跳跃。详细条件和证据见 [验收记录](docs/validation.md)。
