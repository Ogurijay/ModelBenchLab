# 参考简报：暴风城（《魔兽世界》）

没有可用的图像生成工具，也不引用游戏截图（避免把原作素材带进仓库）。参考来自公开 wiki 的文字描述，落成 `src/world/coords.js` 的布局数据。

## 方位（游戏内地图）

| 区域 | 方位 | 辨识元素 |
| --- | --- | --- |
| 英雄谷 | 东南入口 | 城门耸立在艾尔文森林树冠之上；门内是天然盆地，一座大桥横跨，桥两侧立着第二次战争英雄雕像（图拉扬、卡德加、达纳斯等） |
| 贸易区 | 中心 | 银行、拍卖行、旅店、狮鹫管理员；通往法师区、大教堂广场、旧城区 |
| 法师区 | 西南 | 巫师圣所（紫色尖顶高塔）、屠宰之羊酒馆；紫瓦屋顶 |
| 旧城区 | 东 | 要塞脚下的老村落遗存：军情七处、猪与哨子酒馆、勇士大厅 |
| 大教堂广场 | 北 | 光明大教堂、市政厅、孤儿院；圣光信仰中心 |
| 矮人区 | 东北 | 铁炉堡矮人与侏儒的街区，熔炉、烟囱；东侧有矿道地铁入口 |
| 暴风要塞 | 最东北 | 高台上的王城；城门在旧城区与矮人区之间；王座厅、皇家图书馆 |
| 雄狮安息地（原公园区） | 西北 | 绿地与纪念碑 |
| 暴风港 | 西北城墙外 | 码头、船坞；穿过北墙隧道进入 |

运河把每个区隔开，区与区之间靠桥连通。

## 视觉辨识（风格化方向）

白色 / 暖白石墙，钴蓝色板瓦屋顶，金色饰件，蓝底金狮旗帜；贸易区和旧城区的房子是半木构（奶白灰泥 + 深色木梁）上层出挑；矮人区石材偏暗、屋顶红褐；法师区紫瓦。
