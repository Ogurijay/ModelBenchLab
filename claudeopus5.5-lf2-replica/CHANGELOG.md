# 改动记录

## 2026-10-10 · 角色头像换为生图

- 23 名角色的头像由程序化侧脸换成 Grok Build CLI(Imagine `image_gen` / `image_edit`)生成的正脸像素头像,存于 `assets/portraits/`(128×128,量化 48 色)。原因:用户认为程序化头像效果差,要求调用 Grok Build 生图替换较差的资产;战斗动作精灵需要约 160 个姿势帧间一致,生图难以保证,保留程序化骨架方案。
- 选人画面改为原版式 120×120 大头像 + 小号站姿精灵;状态栏、出招表、结算同步使用新头像,缺图时退回程序化头像。
- 为与头像一致:Warden 改为灰发铁面罩绿制服,Malakar 改为银白长发骨白角面具,Poacher 加胡子。
- 新增 `docs/portraits.md` 记录生成流程与全部提示词;README / HANDOVER 注明头像非本模型自身产出。

## 2026-10-10 · 初版

- 新建项目:按 *Little Fighter 2* 复刻 2.5D 横版格斗「Little Brawlers 2」。原因:用户要求「1:1 复刻 little fighter 2 横板格斗游戏」;新建 mission `lf2`(code-to-ui,`codeui-lf2-001` v1 draft)。
- 复刻范围:玩法、规则、操作、数值、帧数据引擎与五种模式按原版;原版角色形象/名字/位图/音乐有版权,改为 23 名原创角色(对应原版定位与出招指令)、8 张原创场景、9 首原创配乐,全部程序生成。
- 内容:30 TU/s 帧数据引擎(itr/bdy、fall 分档、防御计数与破防、盔甲、冰冻/燃烧、空翻、抓投、武器/饮料、飞行道具反弹/对消)、骨架姿势程序化像素精灵、原版布局状态栏、4 人键盘 + 电脑四档难度、VS/闯关(5×5 + 生存)/锦标赛/军团战/演示、结算统计、键位设置(含原版键位)与出招表、原版功能键 F1–F9、`lf2.net` 秘技、`window.__bench` 评测钩子。
- 数值对齐:初版按记忆标定后,依据原版官方出招表、v2.0a `.dat` 数据与社区研究资料统一校正 —— 各角色出招指令与 MP 原始值(如 Davis 定位的 D>A 40、DvA 75、D^A 225、D^J 25)、MP 回复公式、暗红 HP 规则、fall 分档取整、防御计数(格挡 ≤30 / 挨打置 45 / bdefend>60 不可防)、盔甲阈值、命中硬直 3/3/5、走路帧 4 TU 与斜向速度、摔投参数、饮料速率、武器四档强度表、空投条件(场上少于 4 件)、闯关 5 幕结构与敌人血量、军团战兵种血量、状态栏坐标与配色。
- 测试中修复:
  - 濒死(HP 0)角色在空中仍按可恢复上限回血,落地时 HP>0 永远不死 → HP≤0 时停止回复,且击倒致死后落地前不再可被追打。
  - 空投物品物理顺序错误,y>0 后不再判定落地、无限下落,影子被放大成巨大黑椭圆 → 只在空中积分 y 并落地。
  - 收招帧的连击 hit_a 固定接普通拳 → 按前方是否有晕眩/破防敌人选择重拳;重拳触发距离放宽到与拳的攻击距离一致。
  - 按键在攻击收尾被吞 → 控制器加入输入缓冲(帧内按键 4 TU)。
  - 锦标赛对阵画面:世界为空时场景提前 return 导致不推进;方法被实例属性覆盖导致对阵图不绘制;轮空场次不会自动推进 → 均已修正。
  - 对局设置默认光标落在 Back → 默认落在 FIGHT!;出招表长描述与招式列表重叠 → 按描述行数下移。
  - 冰火合体后被并入的角色仍占状态栏格子 → 已移除的角色不再显示。
- 代码检查中修复:空翻循环帧与翻滚、防御帧号重叠(空翻后会误入防御)→ 改用独立帧号。
- 登记:`benchmark/registry.json` 新增项目(端口 3063)、mission `lf2` 与门户分组;根 `package.json` workspaces 加入本目录并更新 lockfile;新增题面 `benchmark/tasks/code-to-ui/lf2-fighter.md` 与测试单元 `codeui-lf2-001.v1.json`;`code-to-ui-game` 专项 rubric 适用范围加入 lf2。
