# Little Brawlers 2 · Little Fighter 2 玩法复刻(Claude Opus 5.5)

按 PC 经典 *Little Fighter 2*(LF2 v2.0a,Marti Wong & Starsky Wong)复刻的 2.5D 横版格斗。引擎按原版 `.dat` 帧系统重写,时间、物理、受击 / 防御 / 盔甲 / 抓投规则、各角色出招指令与 MP 消耗、道具数值、闯关结构与界面布局均对照原版官方出招表与 v2.0a 数据文件复刻。

**复刻范围说明**:玩法、规则、操作、数值、模式结构按原版 1:1;原版角色形象、名字、位图与音乐受版权保护,因此 23 名角色均为原创设计(每人对应原版一名角色的定位,出招指令与机制一致),8 张场景与 9 首配乐也是原创。**除 23 张角色头像外,画面、音效、音乐全部由代码生成,零运行时依赖。** 角色头像(`assets/portraits/`)由 Grok Build 的生图工具按本项目原创角色描述生成,再经脚本量化成 128×128 像素图,生成方法与提示词见 [docs/portraits.md](docs/portraits.md)。

## 运行

- 常规:仓库根目录 `npm run dev`,访问 `http://localhost:3000/claudeopus5.5-lf2-replica/`
- 单独调试:根目录 `npm run dev:one -- claudeopus5.5-lf2-replica`(端口 3063)
- 构建:本目录 `npm run build`(使用根目录 vite)

| 动作 | P1 | P2 | P3 | P4 |
|---|---|---|---|---|
| 上 / 下 / 左 / 右 | W S A D | ↑ ↓ ← → | T G F H | 小键盘 8 5 4 6 |
| 攻击 A | J | 小键盘 1 | Z | 小键盘 7 |
| 跳 J | K | 小键盘 2 | X | 小键盘 9 |
| 防御 D | L | 小键盘 3 | C | 小键盘 + |

功能键(同原版):F1 暂停、F2 暂停中单步、F4 回选人、F5 加速;VS 模式下 F6 无限 MP、F7 全员回复、F8 空投武器、F9 销毁武器。Esc 打开暂停菜单,F10 显示帧率。

### 基本规则(与原版一致)

| 输入 | 效果 |
|---|---|
| 双击 ← / →(约 10 TU 内) | 跑步,按反方向急停 |
| 跑步中 J / A / D | 冲跳 / 跑攻 / 翻滚;落地蹲伏时按 J / D 也可冲跳 / 翻滚 |
| 空中 A、冲跳中 A | 跳踢、冲踢 |
| 连按 A | 左右拳连击(每拳 20 伤害、fall 20)|
| fall 点数 | 每次受击累加、每 TU 衰减 1:≤20 轻受击,≤40 重受击,≤60 晕眩(约 28 TU),>60 倒地;进档时取整到 20 的倍数,所以三拳晕眩、四拳倒地 |
| 晕眩 / 破防的敌人 | 按 A 自动变重拳;走路撞上晕眩的敌人会抓住:A 连揍,方向 + A 摔出(不按前方就向后摔),被摔者会砸伤碰到的任何人 |
| D | 防御 13 TU,只挡正面,伤害 10%;防御计数 >30 破防;挨打后计数置 45,短时间内难以再防;bdefend>60 的攻击无视防御 |
| 被击飞下落时 J | 空翻卸力,落地前无敌 |
| 道具 | A 拾取;轻武器 A 挥砍(普通 / 跳 / 跑 / 冲四种强度),小刀和回旋镖方向 + A 投掷,其他武器跑跳中方向 + A 投掷;重物 A 投出;牛奶 / 啤酒站立 A 持续喝(D 中止)|
| D + 方向 + A/J、D + J + A | 必杀技;最后三次按键成立即挂起,进入可出招的帧且 MP 足够时发动,按其他键取消;连按两次 D 会清空 |

HP / MP:各 500;受击时 1/3 伤害变为不可恢复(暗红段以上可每 12 TU 回 1);MP 每 3 TU 回复 1 + ⌊(500−HP)/100⌋,残血回得更快;VS 开局 200 MP、闯关 500 MP。命中硬直:攻击方 3、受击方 3、格挡方 5 TU。

## 模式

- **VS Mode**:1–4 名玩家 + 电脑,共最多 8 人,独立或 4 支队伍混战,最后存活的队伍获胜;场上武器少于 4 件时定时空投。
- **Stage Mode**:5 大关 × 5 幕 + 生存关。每幕从场景左端开始,段内锁镜头,清敌后 GO→ 推进;敌人数量 = 基础数 × 我方人数(CRAZY! 每人算 2 人),Easy 敌人 3/4 血、CRAZY! 1.5 倍血;每幕结束阵亡者复活并按难度回复暗红上限(200/150/100/50)。首领:1-4/1-5 Brute、3-5 / 5-3 Gallant EX(1000)、4-4 Pyra + Glacia、4-5 Tempest(1500,杂兵不断)、5-2 Nocturne(750)、5-4 Tempest(1000)、5-5 Malakar(2500)。生存关 10 关一循环,第 7–10 关依次为四名首领。
- **Championship**:所有参赛者 1 对 1 淘汰赛,有对阵图与轮空,电脑对战可观看或在暂停菜单跳过。
- **Battle Mode**:两大阵营,各有英雄领队与混编兵团(山贼 / 猎人 50 血、巫师 100、拳师 / 典狱长 150、壮汉 / 武僧 / 骑士 200、修女 250),同屏最多 10 名、按增援队列补充,领队与兵团全灭的一方失败。
- **Demo**:电脑混战演示(混战 / 2v2v2v2 / 4v4 / 3v3v2 随机分组),标题画面闲置 40 秒自动进入。

难度 Easy / Normal / Difficult / CRAZY! 影响电脑的反应间隔、防御 / 闪避 / 出招概率与闯关敌人数量 / 血量。结算表按原版列出 Kill、Attack、HP Lost、MP Usage、Picking、Status(Win/Lose + Alive/Dead)与用时。
