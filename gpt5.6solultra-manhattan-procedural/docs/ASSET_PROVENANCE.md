# 资产来源与合规说明

本项目不包含、下载或运行时请求任何外部模型、贴图、HDRI（高动态范围环境图）、图片、视频或音频文件。

| 产物 | 生成方式 | 外部素材 |
|---|---|---|
| 城市、地标、桥梁、雕像 | Three.js 基础几何、`BufferGeometry`、曲线扫掠与实例矩阵实时生成 | 无 |
| 公园、湖盆、岩石 | 网格顶点位移与确定性噪声实时生成 | 无 |
| 云、雨、雪、闪电、蒸汽 | 三维几何、粒子缓冲与程序曲线实时生成 | 无 |
| 星空、窗灯、道路标线、广告内容 | 点云、实例几何或运行时 Canvas 生成 | 无 |
| 雷声 | WebAudio 振荡器与噪声缓冲实时合成 | 无音频文件 |

地标采用公众可见轮廓的概括性程序化体量，用于模型能力评测；不复制品牌标识、真实广告、扫描数据或受保护平面图稿。广告牌文字均为虚构内容。

依赖仅为本地 npm 软件包 `three`、`vite`、`vitest`。页面业务代码没有 `fetch`、XHR、WebSocket 或外部 Loader（加载器）调用。
