# Manhattan Storm Shift（曼哈顿风暴换班）

## 用例目标

本实现严格使用仓库冻结的 `code3d-manhattan-001` 题面，不修改横向对比的输入锁。`Storm Shift` 是场景内部的连续编排：它让同一座确定性城市在一个加速日内经历晨雾、早高峰、午后降雨与雷暴、冷锋降雪、夜间放晴，从而检验五种能力是否真正耦合。

坐标约定为 `1 unit = 1 m`，纬度固定为纽约 `40.7128°N`，太阳计算日固定为一年中的第 295 天。公平模式使用种子 `1337`、`2026`、`42`，1920×1080，观察不少于 90 秒。

## 连续时间线

| 纽约时刻 | 场景阶段 | 可观察证据 |
|---|---|---|
| 04:00–08:00 | 晨雾 | 远处高楼没入雾层，窗灯与路灯随日出熄灭 |
| 08:00–13:30 | 晴朗早高峰 | 红绿灯相位、跟车停车、路口转向与城市地标清晰可见 |
| 13:30–15:00 | 降雨 | 风改变雨丝倾角，路面粗糙度下降并出现湿亮反射 |
| 15:00–17:00 | 雷暴 | 闪电优先命中最高避雷点，雷声按距离除以 343 m/s 延迟 |
| 17:00–20:00 | 降雪 | 水平屋顶与地面逐步显出积雪，交通和云仍持续运行 |
| 20:00–04:00 | 夜间放晴 | 星空、月亮、窗灯、路灯和动态广告成为主视觉 |

## 五能力考点

1. **建模（结构化几何生成）**：正交大道与街道、Broadway 斜切三角地块、四座以上地标、程序化楼群、街具和悬索桥。
2. **3D 雕刻（顶点级形体塑造）**：公园起伏与下凹湖盆、位移岩石、带衣褶的自由女神轮廓、非公告板体积云。
3. **动画绘制（时序与运动编排）**：昼夜天体、信号交通、鸟群/直升机/船、环境蒸汽、自动样条环游与自由轨道。
4. **天气（多系统环境响应）**：晴、多云、雾、雨、雷暴、雪六态平滑过渡；风、湿地、积雪、能见度、雷电与雷声联动。
5. **计算（确定性与真实公式）**：种子城市函数、太阳位置、悬链线、双峰高度场、固定步长交通与实例化渲染统计。

## 自动评测接口

页面就绪后暴露 `window.__BENCH__`，评分器应从真实场景对象和渲染器交叉检查，不只相信自报数字。

```js
const bench = window.__BENCH__;
await bench.reset(1337);
bench.setTime(15.5);
bench.setWeather('storm', 0);
bench.setWind(9, -4);
bench.step(1 / 60, 600);
console.table(bench.getMetrics());
console.log(bench.getCityHash());
```

核心对象使用 `object.userData.benchRole` 标出语义角色。固定步长 `step(dt, n)` 允许在不等待真实时间的情况下检查长时交通、天气过渡和资源稳定性。
