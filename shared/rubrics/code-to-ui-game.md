# 专项评分卡：浏览器生活与经营游戏

适用于 code-to-ui 的 life/business mission；与数据网格使用不同的专项 rubric，不要求列表虚拟化或搜索防抖 HUD。A 必跑，B 可选；其他评测约束遵守 methodology。

| key | 维度 | 权重 | 0 / 3 / 5 锚点 |
|---|---|---|---|
| A | 需求与玩法闭环 | .20 | 不可玩 / 主循环可用 / 所有任务要求完成 |
| B | 状态与性能工程 | .25 | 状态错乱卡死 / 操作与结算正常 / 组合状态可靠且性能证据充分 |
| C | 交互与反馈 | .15 | 无反馈 / 反馈可懂 / 键盘触屏一致清晰 |
| D | 像素视觉规范 | .15 | 风格混乱 / 基本统一 / 色板布局像素边缘精细统一 |
| E | 健壮性与存档 | .10 | 常崩 / 边界可用 / 错误恢复与持久化可靠 |
| F | 无障碍 | .05 | 不可达 / 基本可操作 / 语义焦点文字提示完整 |
| G | 代码质量 | .10 | 难维护 / 有分层 / 清晰结构与有效验证 |

只对 task.axes 命中的通用轴打分。帧率、CPU 档位和操作脚本按每个冻结单元确定，不能把数据网格的 DOM 行数或防抖计数判给 Canvas 游戏。
