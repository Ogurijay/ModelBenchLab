# 漫威八人招式设计（未实现）

状态：2026-10-13 设计稿。本文没有对应的已实现角色、DAT、图片、音效或运行验收；数字是首轮平衡目标，不能作为功能已完成的证据。所有方案限定为现有 OpenLF2 的普通 DAT、`opoint`、`itr`、`cpoint`、帧序列和速度字段，不要求新增引擎机制。原 Kate 三版资源保持原样。

## 输入与数值约定

| 原 LF2 输入 | 网页当前键位显示 | DAT 入口字段 |
|---|---|---|
| D 前 A | L 前 J | `hit_Fa` |
| D 前 J | L 前 K | `hit_Fj` |
| D 下 J | L 下 K | `hit_Dj` |
| D 上 J | L 上 K | `hit_Uj` |
| D J A | L K J | `hit_ja` |

“前”为面朝方向。按顺序输入，不要求三个键同时按下。A 是原版攻击键，J 是原版跳跃键；网页 J/K 的显示含义不同。

以 HP 500、MP 500 上限和原引擎自然回蓝为共同基准；不增加职业专属槽、弹药或冷却计时器。表内时间是模拟 tick（按 30 tick/s 估算），列为“起手/有效/收招”；命中停顿、落地、受击会改变实际时长。每个 DAT 帧停留为 `wait + 1`，需要据此编排，不能直接把 tick 填进 `wait`。范围为游戏坐标单位，不是屏幕 CSS 像素。`X/Z` 分别为前后距离/纵深半宽；近战通常 Z=12，宽域招式最多 Z=30。

伤害是无防御、无护甲时的 `injury` 或各次 `injury` 之和；不是命中保证或所有目标总伤害。“击退 x/y”是最终一击 `dvx/dvy` 目标值，负 y 为上挑，方向按朝向镜像。连击前段 `fall` 宜 10–20，终段 60–70；低伤压制不得每击都用高 `fall`。`bdefend` 常规 15–40；明确破防招才用 65，避免普遍使用 100。

只有入口帧扣 MP，后续帧 MP=0。动作期间保留正常 `bdy`，不凭空赋予无敌、霸体或防御反击。多段命中用有限帧、合理 `vrest` 和投射物命中后消失限制；表中总伤害仅为全中预算，不能依靠多枚物体共享 `vrest` 来保证统一命中上限。

## DAT 落地约束与验证清单

1. 人物基础行走、跑动、跳跃、倒地、冻结、抓取/被抓和持武器帧使用完整 LF2 骨架；五个技能入口暂建议240/260/280/300/320，仅是新人物内部分配建议。技能含接续帧均在0–399，实际分配先审计骨架空槽。五个入口分别保留对应输入字段；受击/收招不得自行再次触发完整技能。
2. 每人最多10张 BMP，单帧最多5个 itr、5个 bdy；本方案多数帧仅1个 itr。DAT 帧标签使用不超过19字符的ASCII短名，路径仅ASCII。角色和效果对象ID必须从三版共享清单中寻找无冲突区间，不能复用原版/Kate的已有ID、改写已有对象或猜一个空闲ID。
3. 所有投射物和残影经普通 `opoint kind1` 生成，保留 owner/team 归属用于伤害、胜负和录像。设置命中/被打碎/超时结束路径：飞行球可用3000、命中3001、消失3004，有限 `next` 结束到1000由现有越界帧清理。不能忘记每个碰撞分支的回收；不能依赖未添加的自定义 state。
4. 成本只在技能入口扣一次。不同英雄不新增不同回血/回蓝全局参数，不修改原角色平衡。分身、护盾物体、雷电、蛛网和金属的外观只属于新对象，不替换全局冰冻、火焰或其他原角色资源。
5. 蛛网抓取、盾反弹、牵引、自愈分别依据当前 `combat.lua` 的 catch/kind9/kind15 分支及 `match.lua` heal 分支；`control.lua` 是输入/MP依据，`objects.lua` 是普通spawn和球行为依据，`animation.lua` 是wait/next依据。源资料位于研究目录 `tmp/lf2-openlf-research/OpenLF2/scripts/base/game/`；实际测试应针对产品打包的同版本引擎，以防实现版本漂移。
6. 新人物ID能显示在选人列表不等于AI支持五招。当前AI有原版角色ID分支；自定义ID的招式AI覆盖需另外检验/实现，不能在此宣称八人CPU已经会用技能。手动输入、demo启动和完整CPU战斗是不同验收项。

实施验收应包括：八人×五招的真实输入边沿与入口MP断言；每招全中/空招/被打断；左右朝向镜像；纵深侧移；对防御/护甲/空中/倒地对象的规则；所有投射物被反弹/拦截后的结束；蜘蛛侠被第三人攻击时释放抓取；盾盘外飞碰撞后是否仍按设计折返；万磁王牵引作用于各类原生对象的准确范围；金刚狼恢复104上限与dark_hp限制；多英雄同时大招的对象数量与帧推进；原生录像保存和回放逐帧一致。未跑上述测试前，伤害、范围、控制窗口和AI行为均为待验证设计。

首轮平衡目标：低成本技能伤害12–45，高成本技能理论总伤害52–86；快银用位移收益换伤害，雷神用慢起手换击倒，铁人用射程换贴身风险，蜘蛛侠用抓取/跳跃换单段伤害，队长用正面反弹换范围，万磁王用牵引换直接爆发，金刚狼用短射程换连击/有限恢复，死侍用枪剑不保证衔接换中距离选项。若实测出现无限连，应先降低攻击密度、增加末段fall促成倒地、增加收招或缩短控制时间，并以真实受击恢复和逃脱证据调整；不能单靠表内理论DPS判定平衡。
