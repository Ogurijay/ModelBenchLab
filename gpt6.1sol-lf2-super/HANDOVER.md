## 技术方案

OpenLF2 官方 WASM 运行原 LF2 数据。基础 LF2 v2.0a 安装器只作为只读压缩资源使用，不执行 Windows EXE。Kate 原始分块保持字节一致；运行时副本只截短超出严格解析器上限的帧说明词，并隔离 Ver2/3 一个无编号 Bandit 帧块。全部有效帧编号和数值前后必须一致。Lua 桥接加载真实资源，新增全部改版角色及真实 stage ID 选择。SDL canvas selector 与官方 fullscreen strategy 处理网页画布和全屏，避免黑屏与裁切。

网页外壳负责阶段切换、资源完整性、图鉴、招式原图与录像导入导出。录像用 IndexedDB 分阶段保存，键位在本机浏览器存储。原菜单 Exit 保存录像后返回网页启动页。WebRTC 远程同屏捕获真实 canvas 并只接受远端 P2 的白名单按键；默认无 STUN，可手工交换连接码进行直连。

统一预览 3000，独立开发 3068。公共资产位于 `shared/assets/lf2-super/`，源码只在本目录。其他项目及仓库并行开发已有变更保留。
