## 结构

- `src/catalog.js`：车辆、版本、部件与性能参数；`src/blueprints.js`：八款独立车壳截面，单位毫米、+Z 向前、+Y 向上。
- `src/models.ts`：曲面、座舱、轮组与 13 个结构组件；`src/model-details.ts`：涂装区域和机械细节。涂装贴合原始网格并使用绘制顺序，避免交叠闪烁。
- `src/track.js`：三维曲线、全姿态环道、独立车道路程、上跨换道桥、连续路面坐标系。
- `src/physics.js`：固定 240 Hz 模拟，显式牵引力、支撑力、损耗、离轨和完赛条件。渲染帧率独立于物理。比赛结束后，已经离轨的车辆仍完成落地动画。
- `src/world.ts`：房间、赛道实体、赛用车辆批处理、GPU 资源释放。
- `src/main.ts` / `style.css`：桌面操作、镜头、部件选择、存档导入导出。
- `review.html`：开发时的模型六视图工具。`scripts/capture-models.mjs` 保存六角度；`publish-previews.mjs` 将斜前模型预览集中到公共资源，验证副本、移除重复文件并更新 SHA-256，原 JSON 指向公共文件。

## 验证与边界

见 [VERIFICATION.md](docs/VERIFICATION.md) 和 `docs/qa/browser-acceptance.json`。单位测试覆盖三条赛道的完整八圈，而浏览器的完整八圈使用同一物理函数加速推进；没有声称八圈全程均经过人工观看。

经典进化者、极速眼镜蛇为展示模型，比赛动力底盘是有说明的改编。车壳仍是程序化近似，没有扫描或独立盲评相似度。img2threejs 的输入校验通过，但像素轮廓门禁失败 / 不可靠，完整 pipeline 没有通过，不能把保存的 state.json 当作已完成认证。后续若追求更高相似度，应先改进照片前景分割与视角标定，再按流程评审。

当前碰撞是导槽内的距离约束，不包括每个轮胎的接触求解、柔性车壳、完整碰撞刚体、损毁或联网多人。手动模式控制架空马达供电和制动。拓展车扩展名称、涂色及配置，不导入任意 GLTF。

构建有 Three.js 体积超过 500 kB 的提示；无构建失败。保留 0.185.1 未升级到 r186。自动化测到的 FPS 来自本机无头 Edge，不承诺其他设备帧率。桌面验收到 1280×800 和 1600×1000，未做移动适配。

仓库结构通过不等于正式评测通过；`code3d-mini4wd-001` v1 保持 draft，本轮没有生成正式榜单评分。补充资料 JSON 中 `tmp/astra-reference-*` 的路径是本次研究的本机溯源，八张主要参考、模型截图和来源 URL 已保存在持久目录。
