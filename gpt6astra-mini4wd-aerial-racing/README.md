# ASTRA · 四驱实验室

桌面端独立实现。先核对八款经典原版的照片，再分别编写车壳、轮罩、座舱、尾翼与涂装。Three.js 固定为 0.185.1，未改动此前的 `gpt6-mini4wd-room-racing`。

常规入口：根目录 `npm run dev`，打开 `http://localhost:3000/gpt6astra-mini4wd-aerial-racing/`。
独立调试：根目录 `npm run dev:one -- 3059`，打开 `http://localhost:3059/`。

本变体新增立体环道与近距跟随镜头，题面记录在 docs/BRIEF.md。当前 benchmark 仍为 draft，不代表已通过正式横向评测。

## 已实现

- 八款经典赛车，最多八车同时发车；也可选择 2 / 4 车。
- 天穹双环 110.60 米、螺旋登峰 124.05 米、连弯试验场 99.40 米；长度为八车道平均单圈长度。包含双 360° 垂直环、连续 S 弯、高架爬升与机械换道桥。
- 每圈前进一个车道，八圈遍历八条路线。引擎计算马达负载、传动比、牵引力、重力、导轮阻力与接地支撑；速度不足会在环道脱轨，离轨后按重力落下。
- 贴身跟随、车头、全景、自由视角。贴身镜头随路面姿态一起翻转，距离可调。
- 13 个可分离结构组件，8 类可替换系统：马达、齿轮、轮胎、导轮、刹车、电池、底盘、车壳。点击部件进入相应编辑器，配置自动保存。
- 新建独立名称和颜色的拓展车，最多 12 辆；支持 JSON 导入导出。拓展车使用所选经典车的结构模板。
- 四驱俱乐部、夜间训练室、木作工坊三种房间。
- 游戏内车型档案与参考对照；缩略图来自实际模型渲染。

## 操作

自动模式持续供电，由导槽决定行驶方向。手动模式是架空的可控马达改装：按住 **W / ↑** 加电，**S / ↓** 制动，松开滑行，不做自由方向盘转向。真实 Mini 4WD 通常没有遥控调速。

**1–8** 跟随对应赛车，**V** 切换镜头，**空格** 暂停 / 继续，**R** 重新准备。工房中拖动旋转、滚轮缩放，点“展开结构”拆解。比赛过程中配置锁定；进入工房会暂停比赛，返回后点“继续”。

立体赛道建议先用基础配置或“立体稳定套件”。“标准 130”马达动力较低，无法保证通过高空环道；改装有速度、抓地力、重量和稳定性的取舍。

## 运行与验证

在仓库根目录运行：

```powershell
npm run dev:one -- 3059
npm test --workspace gpt6astra-mini4wd-aerial-racing
npm run build --workspace gpt6astra-mini4wd-aerial-racing
```

停止独立开发服务后，可以用 `npm run preview --workspace gpt6astra-mini4wd-aerial-racing` 在 `http://127.0.0.1:3059/` 预览生产构建。服务运行时，执行 `npm run test:browser --workspace gpt6astra-mini4wd-aerial-racing` 使用独立的无头 Edge 上下文验收；不会操作个人浏览器档案。

正常仓库入口仍是根服务 3000，3059 是登记的独立调试 / 预览例外。浏览器验收可通过 `ASTRA_URL` 指定根服务中的项目 URL。验收证据见 [docs/VERIFICATION.md](docs/VERIFICATION.md)。

## 参考与准确性范围

车壳以经典型号为准：[参考索引](docs/REFERENCES.md)。原版进化者和极速眼镜蛇属于无动力 Real Mini 4WD 展示模型，本作保留其经典车壳、透明座舱与银色机械特征，并适配比赛底盘、动力与导轮。

这是参考图驱动的程序化模型，局部曲面、字号、胎纹、固定卡扣和内部结构仍有近似，未达到扫描级复刻。照片背景分割使自动轮廓评分失真，未将其报告为“相似度通过”；原失败结果和不完整的工具状态保留在 `reconstruction/`。性能参数也是玩法模型，未与实车实验标定。
