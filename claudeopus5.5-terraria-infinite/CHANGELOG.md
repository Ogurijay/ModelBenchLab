# 改动记录

## 2026-10-10 · 试玩反馈修复:删除世界、意外回到首页、门卡人

- 世界无法删除:删除按钮使用原生 `confirm()`,内置浏览器面板会直接吞掉对话框(恒为取消)→ 改为列表内二次确认(“确认删除 / 取消”),同时清除该世界的续玩标记与快照。
- 有时自动回到首页:原因是共用的 :3000 开发服务器被其他会话改动共享文件或重启时整页刷新 → 监听 Vite 的 `vite:beforeFullReload` / `vite:ws:disconnect`(Vite 会等待回调完成)先写完存档;`pagehide`/`beforeunload` 时把玩家、角色、任务、时间的同步快照写入 localStorage;进入世界时在 sessionStorage 记录续玩标记,页面意外刷新后自动回到原世界;自动存档间隔 30 秒 → 15 秒;启动时清理已删除世界残留的快照。
- 门卡住角色:门只有 2 格高而角色约 2.6 格高 → 门改为泰拉瑞亚式 3 格高(meta 新增“中部”位,兼容旧的 2 格门);营地、浮空岛木屋的门与地下小屋的门洞同步改为 3 格;放置门需要 3 格空间并给出提示;开关与破坏按整列门格处理。
- 验证:新营地门为底/中/顶 3 格,右键三格同时打开,角色可穿门进屋;界面点击删除流程生效;进入世界后直接 `location.reload()`(不手动存档),刷新后自动回到原世界,位置与金钱一致。

## 2026-10-10 · 艾泽拉斯无限(魔兽世界元素扩展)

- 原因:用户追加需求——融合魔兽世界元素,以暴雪《魔兽世界:无限》为故事背景,可选种族;世界按阵营生成,非同阵营 NPC 变为怪物并有不同的任务线与掉落;角色定制更丰富;嵌合建造、合成、职业技能体系,并支持职业融合。
- 新增模块:`wow.js`(阵营/种族/职业/技能/NPC/任务/商人/区域数据)、`rpg.js`(等级、资源、增益、技能、宠物、图腾、法术飞弹)、`npc.js`(阵营 NPC AI)、`quests.js`(任务日志)、`avatar.js`(种族角色精灵)、`rpgui.js`(魔兽式 HUD 与窗口)。
- 内容:10 个种族(联盟/部落各 5,含双阵营的天裔,可滑翔)与种族出生地;9 个职业 45 个技能、种族技能、职业融合;营地生成(起始营地、宿敌营地、无限延伸的随机营地)与 NPC 复活;敌对巡逻队;两阵营各 10 环主线 + 可重复战争任务;阵营掉落、徽记兑换、商人买卖、金银铜钱包;前哨(房屋判定后 NPC 入住、周边免刷怪);武器装备槽与法杖法术强度;区域等级与区域名;角色创建器(名姓、性别、肤色、眼睛、10 种发型、发色、胡须、服装、普通/硬核规则集);HUD 改为头像框、目标框、经验条、技能栏与任务追踪;名牌与任务标记;K 技能书、L 任务日志。
- 修复与调整:营地 NPC 原本全部挤在屋内 → 任务官/商人在屋内、战斗单位在屋外站岗;名牌重叠 → 按距离排序并错开;顶部提示条与头像框重叠 → 下移;删除旧的 `humanParts` 与外观表。
- 验证:见 HANDOVER“本轮验证”。

## 2026-10-10 · 挖掘掉落修正

- 用户反馈“敲地板不会掉落方块”。原因:沿用了《我的世界》规则——创造模式挖掘不掉落;工具等级不足时也能慢慢挖碎方块但不给掉落,看起来像 bug。
- 改为泰拉瑞亚式规则:能挖动的方块一律按掉落表掉落(创造模式同样掉落,背景墙也一样);镐的等级不足时直接挖不动,并提示“需要 X 镐或更好的镐才能挖掘 Y”。
- 验证:生存木镐向下挖 9 格(草/泥土 → 泥土,石头 → 圆石)全部入包;手持泥土挖石头不动并出现提示;创造模式秒挖且掉落。

## 2026-10-10 · 初版

- 新建项目「无垠拓荒 · Boundless Frontier」。原因:用户要求实现泰拉瑞亚风格 + 我的世界玩法、具备独立时间观与无限拓展地图的 2D 游戏,可无剧情;仓库此前无同类 mission,新建 mission `terraria`。
- 内容:无限区块世界与 8 种群系、洞穴/含水层/发光蘑菇洞/地下小屋/浮空岛/地狱;独立历法(昼长随四季、月相血月、天气与预报、季节视觉与积雪结冰、离线区块按世界时间补算、睡眠延时跳夜、时间饰品);挖掘与工具等级、配方合成、熔炉冶炼、饥饿与护甲、12 种生物与 AI、爆炸、有限流体、重力方块、种田、门床梯平台箱子;生存/创造与四档难度;IndexedDB 存档;世界地图与小地图;程序化美术/音效/生成式音乐;指令系统;`window.__bench` 评测钩子。
- 测试中修复:
  - 单纯形噪声实际值域约 ±0.7,原阈值下矿石永不生成 → 改为 6×6 网格矿脉 + 深度权重表,并校准其余阈值。
  - 方块外角削圆后背后未绘制墙/岩幕,地下透出天空亮点 → 地下格子一律先绘制背景墙或岩幕。
  - 新游戏沿用标题演示世界的区块缓存(季节错乱)→ 每局重置渲染缓存。
  - 砍树会剥掉相邻树的树冠 → 树叶紧邻他树树干时不计入本树。
  - 隐藏面板下画布尺寸为 0 → 渲染器兜底 1280×720;评测钩子鼠标改为锁定世界坐标。
  - 开局 07:00 处于初春日出前 → 改为 08:30;锄头可在高草下耕地;苦力怕爆炸无视无敌帧;日月光晕改为圆形;地狱增加暗红环境光;夜晚月光略增亮。
- 登记:`benchmark/registry.json`(端口 3062、门户主题“沙盒与生存”)、`benchmark/tasks/index.json`、题面 `benchmark/tasks/code-to-ui/terraria-sandbox.md`、测试单元 `codeui-terraria-001.v1.json`(draft)、根 workspaces。
