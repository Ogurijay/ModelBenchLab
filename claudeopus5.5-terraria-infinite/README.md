# 无垠拓荒 · 艾泽拉斯无限(Boundless Frontier)

泰拉瑞亚画风 + 我的世界玩法 + 魔兽世界元素的 2D 无限世界沙盒 RPG(Claude Opus 5.5 实现)。

- 统一入口:<http://localhost:3000/claudeopus5.5-terraria-infinite/>(仓库根目录 `npm run dev`)
- 单独调试:根目录 `npm run dev:one -- claudeopus5.5-terraria-infinite`(登记端口 3062)
- 技术:原生 ES 模块 + Canvas 2D,零运行时依赖;所有像素美术、音效、音乐均在运行时程序化生成。
- 任务:mission `terraria` · variant `infinite` · `codeui-terraria-001` v1(draft)。第二轮追加了魔兽世界元素需求(见 CHANGELOG)。

## 故事背景

致敬《魔兽世界:无限》(WoW: Forever):原初 60 级艾泽拉斯的平行时空,不再有服务器之分,联盟与部落彻底隔绝。在本作里,这片原初大陆向两端无尽延伸——你选择的阵营决定了世界:同阵营的营地是你的家,敌对阵营的士兵见到你就会拔刀。角色拥有“名 + 姓”,可选普通或硬核规则集(硬核只有一条命,阵亡后转入普通规则)。文本与数值均为原创改编。

## 种族与阵营(10 个)

| 联盟 | 部落 |
|---|---|
| 人类(经验/金钱 +10%,不屈意志) | 兽人(受伤 -5%,血性狂怒) |
| 矮人(挖掘 +20%,石像形态) | 亡灵(水下呼吸,食尸回血) |
| 暗夜精灵(夜行加速与闪避,影遁) | 牛头人(生命 +10%,战争践踏) |
| 侏儒(法力 +10%,逃命专家) | 巨魔(回血翻倍,狂暴) |
| 高阶会天裔(滑翔、免摔伤,风之跃) | 塑风者天裔(滑翔、免摔伤,风之跃) |

- 种族决定出生地:人类/暗夜精灵在森林,矮人/侏儒在雪山,兽人在沙漠,牛头人在平原,巨魔在丛林海岸,**天裔出生在浮空岛上**(空中按住空格滑翔 10 秒)。
- 每个种族有独特外形:体型(矮人与侏儒矮小、牛头人高大)、长耳、獠牙、牛角与口鼻、发光的眼睛、亡灵的骨颚。
- **角色定制**:名与姓、性别、肤色(按种族给色板)、眼睛颜色、10 种发型、12 种发色、4 种胡须、上衣与裤子配色,实时动画预览与一键随机。

## 职业(9 个)与职业融合

战士(怒气)、圣骑士、猎人、盗贼(能量)、牧师、萨满、法师、术士、德鲁伊(法力)。每个职业 5 个技能,Z X C V B 施放,G 为种族技能,K 打开技能书自由装配:

- 冲锋昏迷、旋风斩、盾墙、斩杀;审判、圣光术、奉献、圣盾术、制裁之锤;稳固/震荡/多重射击、召唤狼伙伴、急速射击;邪恶攻击、潜行、闪避、肾击、疾跑;惩击、快速治疗、真言术:盾、暗言术:痛、心灵尖啸;闪电箭、大地震击、治疗波、灼热图腾、闪电链;火球术、寒冰箭、冰霜新星、**闪现术**、炎爆术;暗影箭、腐蚀术、生命分流、召唤小鬼、恐惧术;愤怒、回春术、**熊形态 / 猎豹形态**、月火术。
- 状态效果:昏迷、减速、定身、恐惧、持续伤害、护盾吸收、闪避、潜行(怪物需贴身才能发现你)。
- 等级 1–60,经验来自击杀与任务;生命、法力、伤害随等级成长。
- **职业融合**:20 级完成主线最终任务后,可在任务官处选择第二职业,两职业技能可混搭进技能栏,资源不同时同时拥有两种资源条。

## 阵营世界:营地、敌对 NPC、任务线与掉落

- 世界里每隔数百格生成联盟石砖堡垒或部落尖顶硬木营地(旗帜、火盆、灯柱/尖木桩、箱子、工作台);出生点旁固定有一座己方营地,不远处有一座宿敌营地。
- 同阵营 NPC 友好:任务官(头顶 !/?)、商人($)、卫兵会迎击靠近的怪物与敌军;敌对阵营 NPC 就是怪物:步兵、射手、施法者(寒冰箭/闪电箭)与精英(队长/勇士)。阵亡的营地成员会在世界时间流逝后复活;**砍倒敌方战旗**,该营地便不再有援军。白天地表还会遇到敌对阵营巡逻队。
- 联盟与部落各有 10 环主线任务(收集、建造、讨伐、勘探、砍旗、建立前哨、探索天空/地底、职业融合)与可重复的阵营战争任务,对白与奖励各不相同。
- 掉落按阵营区分:联盟士兵掉亚麻布、联盟徽记、暴风城长剑、达纳苏斯长弓、联盟战袍;部落士兵掉毛料、部落徽记、奥格瑞玛战斧、暗矛长矛、部落战袍;另有铜币/银币(金钱单独计入钱包)。徽记可在己方军需官处换取阵营装备,商人也收购杂物。
- 等级随区域缩放:离出生点越远、越深,怪物与敌军等级越高,HUD 显示区域名与等级。

## 建造与合成的融合

- 新增阵营建材:联盟石砖、部落硬木、火盆、联盟/部落旗帜(仅能合成本阵营的)。
- **前哨**:建一间有背景墙、门和光源的封闭房屋(30–700 格),把本阵营旗帜插在屋里,即建立前哨——卫兵、商人、任务官会陆续入住,周围 40 格不再刷怪。房屋不合格时会提示原因。
- 背包新增“武器”装备槽:技能伤害与法术强度取自装备的武器,手里拿着镐也能正常战斗;法杖提供法术强度。

## 原有的核心玩法(第一轮)

- **无限地图**:32×32 区块按需生成、远处卸载,改动存入 IndexedDB;8 种群系、洞穴、含水层、发光蘑菇洞、地下小屋、浮空岛、地狱与基岩;世界地图(M)与小地图。
- **独立时间观**:与现实无关的世界刻;四季昼长变化、季节外观、积雪结冰、作物季节生长;8 相月相与血月;天气与气压计预报;离开的区块再加载时按流逝的世界时间补算作物、树苗、熔炉与积雪;睡眠延时摄影式跳夜;怀表/历书等时间饰品;`/time` `/season` `/weather` 指令。
- **我的世界式机制**:工具等级(等级不够挖不动并提示)、合成与熔炉冶炼、饥饿、护甲、刷怪与苦力怕爆炸、有限流体、重力方块、种田、门床梯平台箱子 TNT、生存/创造、四档难度、死亡墓碑。
