# 粉末物理沙盒游戏 - 产品需求文档

## 1. 产品概述
一款复刻 The Powder Toy 的全中文物理沙盒游戏，玩家可以在画布上放置各种元素，观察丰富的物理和化学反应。包含粉末、液体、气体、固体、能源、生命体等多种元素类别，支持重力、热传导、燃烧、电流、压力等真实物理模拟。

- 目标用户：物理爱好者、创意玩家、休闲游戏用户
- 核心价值：自由创造、物理实验、解压娱乐

## 2. 核心功能

### 2.1 功能模块
1. **游戏主界面**：元素工具栏、游戏画布、控制面板、信息显示区
2. **元素系统**：8大类超过50种元素，每种元素有独特物理化学属性
3. **物理引擎**：重力、压力、热传导、流体力学、空气流动模拟
4. **交互系统**：画笔、橡皮擦、矩形填充、圆形填充、吸管工具
5. **视图控制**：缩放、平移、网格显示、速度调节、暂停/播放
6. **存档系统**：保存/加载作品、清空画布、撤销操作

### 2.2 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|---------|---------|---------|
| 游戏主界面 | 顶部工具栏 | 元素分类标签、当前选中元素显示、画笔大小调节 |
| 游戏主界面 | 左侧元素面板 | 分类显示所有元素，带中文名称和元素符号，可点击选择 |
| 游戏主界面 | 中央游戏画布 | 像素级物理模拟区域，支持鼠标绘制和交互 |
| 游戏主界面 | 右侧控制面板 | 画笔形状、绘制模式、模拟速度、重力方向、显示选项 |
| 游戏主界面 | 底部信息栏 | 帧率显示、元素数量、温度显示、当前坐标信息 |

### 2.3 元素分类与列表

**粉末类 (Powders)**
- 沙子(Sand) - 受重力下落，可堆积
- 盐(Salt) - 可溶于水，能灭火
- 火药(Gunpowder) - 遇火或高温爆炸
- 雪(Snow) - 轻盈下落，遇热融化
- 灰尘(Dust) - 非常轻，易被气流带动
- 灰烬(Ash) - 燃烧残留物
- 煤粉(Coal) - 可燃烧，热值高
- 水泥(Cement) - 遇水凝固成混凝土
- 肥料(Fertilizer) - 促进植物生长
- 火药粉(Spark) - 电火花引信

**液体类 (Liquids)**
- 水(H₂O) - 基础液体，可流动，灭火，导电
- 油(Oil) - 可燃液体，浮于水面，燃烧产生烟
- 岩浆(Lava) - 高温液体，引燃可燃物，凝固成石头
- 酸(Acid) - 腐蚀多数物质，产生气体
- 液氮(LN₂) - 超低温液体，冻结物体，蒸发为冷气
- 液态金属(Mercury) - 重金属液体，导电，密度大
- 酒精(Alcohol) - 高度易燃液体，燃烧温度低
- 胶水(Glue) - 粘性液体，使物体粘在一起
- 血液(Blood) - 生命体液体，含铁，变色
- 盐水(Brine) - 导电溶液，冰点更低

**气体类 (Gases)**
- 水蒸气(Steam) - 水蒸发形成，冷凝成水，向上飘
- 烟(Smoke) - 燃烧产生，缓慢上升消散
- 氧气(O₂) - 助燃气体，燃烧必需
- 氢气(H₂) - 极轻可燃气体，遇火爆炸
- 二氧化碳(CO₂) - 灭火气体，比空气重
- 氯气(Cl₂) - 有毒气体，黄绿色
- 甲烷(CH₄) - 天然气，可燃，比空气轻
- 等离子体(Plasma) - 超高温电离气体，发光
- 冷气(Cold) - 低温雾气，冷却物体
- 毒气(Poison) - 毒雾，腐蚀生命体

**固体类 (Solids)**
- 墙(Wall) - 不可摧毁的障碍物
- 石头(Stone) - 坚固固体，可被酸腐蚀
- 金属(Metal) - 导电固体，导热快，熔点高
- 玻璃(Glass) - 透明固体，易碎，熔点高
- 木头(Wood) - 可燃固体，漂浮在水面
- 冰(Ice) - 水的固态，遇热融化，光滑
- 混凝土(Concrete) - 水泥凝固后，非常坚固
- 植物(Plant) - 可生长，遇水和肥料生长快
- 蜡(Wax) - 可燃固体，熔点低
- 炸药(C4) - 强力爆炸物，需要雷管引爆

**能源类 (Energy)**
- 火(Fire) - 燃烧态，消耗氧气和燃料，产生热和光
- 电(Electricity) - 在导体中流动，激活设备
- 火花(Spark) - 电火花，可点火，引爆火药
- 激光(Laser) - 直线传播的光束，加热物体
- 中子(Neutron) - 放射性粒子，穿透物质，触发核反应
- 光子(Photon) - 光线粒子，直线传播，反射
- 压力(Pressure) - 空气压力波，推动物体
- 热源(Heat) - 加热区域
- 冷源(Cold) - 冷却区域
- 虚空(Void) - 吞噬一切物质

**电子类 (Electronics)**
- 导线(Wire) - 传导电流
- 开关(Switch) - 可切换电路通断
- 电池(Battery) - 持续供电
- 二极管(Diode) - 单向导电
- 晶体管(Transistor) - 信号放大/开关
- 灯泡(Lamp) - 通电发光发热
- 加热器(Heater) - 通电加热
- 冷却器(Cooler) - 通电制冷
- 泵(Pump) - 推动液体/气体
- 探测器(Detector) - 检测物质输出电信号

**生命类 (Life)**
- 蚂蚁(Ant) - 爬行生命体，收集食物
- 细菌(Germ) - 微生物，感染有机物
- 病毒(Virus) - 感染细胞，转化物质
- 真菌(Fungus) - 分解有机物蔓延
- 种子(Seed) - 长成植物
- 鱼(Fish) - 在水中游动
- 鸟(Bird) - 在空中飞行
- 捕食者(Predator) - 攻击其他生命体
- 细胞(Cell) - 基础生命单元，可分裂
- 蠕虫(Worm) - 穿行于固体中

**特殊类 (Special)**
- 橡皮擦(Eraser) - 删除一切元素
- 克隆器(Cloner) - 复制接触的元素
- 破坏器(Destroyer) - 摧毁接触的元素
- 发射器(Emitter) - 持续发射选定元素
- 吸引器(Attractor) - 吸引周围物质
- 排斥器(Repeller) - 排斥周围物质
- 传送门A(PortalA) - 传送入口
- 传送门B(PortalB) - 传送出口
- 重力反转(Gravity) - 局部重力反转
- 风力(Wind) - 产生定向气流

## 3. 核心流程

```mermaid
flowchart TD
    "启动游戏" --> "进入主界面"
    "进入主界面" --> "选择元素"
    "选择元素" --> "选择画笔工具"
    "选择画笔工具" --> "在画布绘制"
    "在画布绘制" --> "物理模拟运行"
    "物理模拟运行" --> "观察反应"
    "观察反应" --> "继续添加元素"
    "观察反应" --> "调整参数"
    "调整参数" --> "物理模拟运行"
    "继续添加元素" --> "物理模拟运行"
    "观察反应" --> "保存作品"
    "保存作品" --> "继续创作"
```

用户流程：
1. 打开页面自动进入游戏界面
2. 从左侧面板选择想要放置的元素类别和具体元素
3. 在中央画布上点击/拖动鼠标放置元素
4. 物理引擎自动运行，观察元素间的相互作用
5. 可随时更换元素、调整画笔大小、改变模拟速度
6. 使用橡皮擦删除不需要的部分，或清空画布重来
7. 可保存当前状态，之后加载继续

## 4. 用户界面设计

### 4.1 设计风格
- 主题色调：深色科技风，深色背景(#0a0a0f)，霓虹蓝/橙高亮色
- 按钮风格：扁平+微立体，选中状态高亮发光
- 字体：使用等宽字体'JetBrains Mono'和无衬线字体，元素名称清晰可读
- 布局风格：经典游戏编辑器布局，左侧工具栏+中央画布+右侧参数面板
- 视觉效果：元素粒子有像素质感，发光/火焰元素有光晕效果，UI有微妙的发光边框

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI元素 |
|---------|---------|-------|
| 游戏主界面 | 顶部工具栏 | 深色背景、分类标签胶囊形、选中标签发光、当前元素预览方块、画笔大小滑块 |
| 游戏主界面 | 左侧元素面板 | 滚动列表、元素色块+中文名称+元素符号、悬停高亮、点击选中带边框 |
| 游戏主界面 | 中央画布 | 纯黑背景、像素化渲染、元素粒子原色显示、可缩放平移 |
| 游戏主界面 | 右侧控制面板 | 分组折叠面板、开关按钮、滑块控件、信息显示区域 |
| 游戏主界面 | 底部信息栏 | 半透明背景、绿色/橙色文字显示帧率/坐标/温度、等宽字体 |

### 4.3 响应式设计
- 桌面优先设计，最小支持1024x768分辨率
- 画布区域自适应窗口大小
- 工具栏宽度固定，内容区域弹性伸缩
- 支持鼠标和触屏操作（平板适配）
- 高DPI屏幕适配

### 4.4 视觉特效
- 火焰/岩浆/等离子体元素自发光效果
- 液体表面有微妙的波动光泽
- 电流通过时有电弧效果
- 爆炸时有闪光和冲击波
- 玻璃/冰有半透明折射效果
- 选中元素在面板中有呼吸灯效果
