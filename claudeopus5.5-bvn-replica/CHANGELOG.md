## 2026-10-10 · 初版

- 新建项目:按 *Bleach vs Naruto*(死神vs火影,BVN)复刻 2D 动漫格斗「魂叶乱斗 SOUL × LEAF」。原因:用户要求「复刻一个火影vs死神小游戏」;新建 mission `bvn`(code-to-ui,`codeui-bvn-001` v1 draft)。
- 复刻范围:BVN 的操作(J/K/L/U/I/O + W/S 方向、按住 S 防御)、命中取消与空中连段、气 / 查克拉(灵力)/ 援助资源、替身术、受身、破防、奥义冻结 cut-in、援助召唤、镜头缩放与七种模式;原作角色与素材有版权,改为忍界 / 魂界两阵营 10 名原创角色 + 6 名原创援助(各自对应原作人物定位),美术、场景、音效、配乐全部程序生成。
- 内容:骨架姿势程序化动漫人物(分层刺发、服装、飘带链、武器刀光)、182 招(技能 40、必杀 40,含 4 种 3 格变身)、8 张原创场景、60 种合成音效与 12 首原创配乐、BVN 式状态栏(体力 / 查克拉或灵力 / 气 3 格 / 援助环)、连击计数、四档 AI、团队接力、生存、训练木桩设置、出招表、改键、`window.__bench` 评测钩子。场景与音频模块由子任务按约定接口实现。
- 测试中修复:
  - 输入缓冲在命中停顿期间衰减,连段第三下常被吞 → 停顿期间冻结缓冲。
  - 同一帧多个菜单按键在切换场景后仍送给旧场景 → 每个按键重新取当前场景。
  - 团队模式换人不重置计时,后续成员常因超时判负 → 每组对决重新计时。
  - 飞行道具型普攻(流砂砂系)命中不算"命中",无法跳消 / 取消 → 飞行道具命中回写所属招式。
  - 陷阱锁定的目标以空中受击姿势绘制,露出黑棺之外 → 改为地面受击姿势;横幅字幕计时挂在渲染上(手动步进时不消失)→ 移到逻辑更新。
  - 月牙类剑气过细 → 按高度加粗并加外发光;cut-in 头像偏上 → 下移。
  - 截图 / 窗口缩放清空画布后手动模式不重绘 → 缩放后立即重绘。
- 平衡调整(依据 10×10 CPU 循环赛):徒手普攻判定 ×1.22、伤害 ×1.08,持刀普攻判定 ×0.94;忍界冲刺加入起步无敌;绯樱瞬步背斩加耗与预兆、千本樱与千本樱景严削弱;疾风 / 夜叉 / 雷牙小幅增强;AI 学会识破陷阱预兆。胜率区间由 14%–89% 收敛到 31%–69%。
- 同角色对战时 2P 自动色相换色。
- 登记:`benchmark/registry.json` 新增项目(端口 3064)、mission `bvn` 与门户分组「2D 动漫格斗 · 死神vs火影」;根 `package.json` workspaces 加入本目录并更新 lockfile;新增题面 `benchmark/tasks/code-to-ui/bvn-fighter.md` 与测试单元 `codeui-bvn-001.v1.json`;`code-to-ui-game` 专项 rubric 适用范围加入 bvn。
