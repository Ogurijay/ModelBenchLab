# 魂叶乱斗 SOUL × LEAF · 死神vs火影式格斗复刻(Claude Opus 5.5)

按经典 Flash 同人格斗 *Bleach vs Naruto*(死神vs火影,BVN)复刻的 2D 动漫格斗。操作键位、出招体系(方向 + 键)、气 / 查克拉 / 援助三槽、命中取消与空中连段、替身术、受身、奥义冻结 cut-in、援助召唤、镜头缩放与模式结构均按 BVN 的玩法复刻。

**复刻范围说明**:原作《火影忍者》《死神》的角色形象、名字与 BVN 素材受版权保护,因此 10 名可选角色与 6 名援助均为**原创造型与名字**,分别承担原作人物的招式定位(例如「疾风」对应影分身 + 螺旋查克拉球,「苍牙」对应巨刃月牙 + 卍解虚化)。

**美术来源**:角色立绘、头像、奥义 cut-in 与战斗精灵(10 人 × 19 帧)由 **OpenAI Codex CLI 的 image_generation 生图**(非本模型产出),生成与后处理流程、提示词见 [docs/art.md](docs/art.md);缺图时自动回退到代码绘制的骨架人物。场景、特效、界面、音效与音乐全部由代码生成,零运行时依赖。

## 运行

- 常规:仓库根目录 `npm run dev`,访问 `http://localhost:3000/claudeopus5.5-bvn-replica/`
- 单独调试:根目录 `npm run dev:one -- claudeopus5.5-bvn-replica`(端口 3064)
- 构建:本目录 `npm run build`(使用根目录 vite)

## 操作(同 BVN 默认键位,设置中可改键)

| 动作 | 1P | 2P | 说明 |
|---|---|---|---|
| 移动 | A / D | ← / → | 自动面向对手 |
| 防御 | 按住 S | 按住 ↓ | 只挡正面;连续格挡过多会破防 |
| 攻击 J | J | 小键盘 1 | 连按出 4 段普攻;W+J 挑空、S+J 下段;空中 J 三段、空中 S+J |
| 跳跃 K | K | 小键盘 2 | 空中可再跳一次;被击飞时按 K 受身;倒地时按 K 快速起身 |
| 冲刺 L | L | 小键盘 3 | 忍界为瞬身冲刺、魂界为瞬步(起步短暂无敌);空中冲刺耗 10;**受击中按 L 替身术**(耗 50) |
| 技能 U | U | 小键盘 4 | U / W+U / S+U / 空中 U,消耗查克拉(忍界)或灵力(魂界) |
| 必杀 I | I | 小键盘 5 | I / W+I / S+I / 空中 I,消耗 1–3 格气并触发奥义 cut-in |
| 援助 O | O | 小键盘 6 | 援助槽满时召唤援助角色 |

2P 无小键盘时可用备用键 `, . / M ; '`(对应 J K L U I O)。Esc / P 暂停(训练模式在暂停菜单里设置木桩)。菜单:方向选择、J / 回车确认、K / Esc 返回,也可鼠标点击。

### 战斗规则

- **命中取消**:普攻命中后可取消成技能 / 必杀 / 冲刺;技能命中后可取消成必杀;挑空(W+J)命中后按 K 跳起追击空中连段。普攻连段空挥也能续接。
- **资源**:体力 1000;气槽 3 格(300),攻击与受击都会积累,必杀耗 1–3 格;查克拉 / 灵力 100,技能 15–30、空中冲刺 10、替身 50,停止消耗半秒后每秒回复 12;援助槽约 11 秒充满,受击加速。
- **连击修正**:第 4 击起伤害逐击递减(普通最低 30%,必杀最低 50%);硬直累积超过上限强制击倒且不可受身;空中连段重力随段数增加。
- **防御**:按住下防正面,普攻削血 4%、技能 / 必杀 12%;格挡累计伤害超过 240 破防(约 0.8 秒晕眩)。陷阱类奥义(砂缚柩、黑棺、天照等)不可防御,但落点有预兆,可冲刺 / 跳开。
- **其他**:反击架势(替身反击、镜花水月)化解近身攻击并瞬移到背后;招式起手被打出现 COUNTER(伤害 +15%);同角色对战时 2P 自动换色。

## 模式

单人闯关(随机 7 战 + 最终首领幻主,后段难度上升,败北可续关)、人机对战、双人对战(同键盘)、团队对战 3v3(VS 电脑或 2P,KOF 式接力,胜者回复 25% 已损体力,每组重新计时)、生存挑战(无尽连战,体力继承并回复 30%)、训练模式(木桩:站立 / 全防御 / 跳跃 / 电脑,无限资源、自动回血、判定框显示)、观战演示(标题界面闲置 25 秒也会进入)。设置:电脑难度(简单 / 普通 / 困难 / 地狱)、胜利局数、回合时间、开局气、音量、帧率显示、双方改键。

## 文件结构

- `src/main.js` 入口:固定 60 帧逻辑 + rAF 渲染,画布按窗口与 DPR 缩放,`window.__bench` 评测钩子
- `src/battle.js` 对战核心(回合 / 团队接力 / 判定 / 飞行道具 / 援助 / 奥义冻结 / 镜头 / 渲染);`src/fighter.js` 角色状态机;`src/moves.js` 招式工厂;`src/proj.js` 飞行道具与陷阱绘制
- `src/chars_ninja.js` / `src/chars_soul.js` / `src/roster.js` 角色、援助与出招表;`src/looks.js` 外观;`src/skeleton.js` / `src/poses.js` 程序化人物与姿势库
- `src/ai.js` 电脑对手;`src/hud.js` 状态栏与 cut-in;`src/scenes.js` / `src/ui.js` 各界面;`src/fx.js` 粒子特效
- `src/stages.js` 8 张原创场景;`src/audio.js` WebAudio 合成音效与配乐
- `src/art.js` 生图资源加载、精灵帧尺寸归一化与变体烘焙;`assets/art/` 处理后的 WebP 与 `sprites.json`;`tools/gen_codex.py` / `tools/process_art.py` 生成与后处理脚本(原图 `assets/raw_codex/` 不入库)
- `tools/figure.html`(人物预览)、`tools/stages.html`(场景预览)、`tools/audio.html`(音效 / 配乐试听)
