## 2026-10-15 · Three.js r186 升级

按用户本轮授权，当前 Three.js 依赖已从 0.185.x 升级并固定为 **0.186.1**。历史条目中的旧版本与验收结果保留原记录；它们不代表 r186 的运行验收。

## 2026-07-19 — 2.5D 平面战斗与自由形态作弊

### Changed / 变更

- 参考 `claudefable5-digimon-rumble` 的正侧视战斗结构，将斗士、投射物、掉落物、道具与机关统一锁定到 X/Y 战斗平面，Z 轴固定为场地 `laneZ`。
- 玩家和 CPU 的攻击方式收敛为普通攻击与远程攻击；移除界面和玩家输入中的纵深移动、闪避、防御与治疗。
- 镜头固定正对战斗平面，HUD 和键位说明同步为 A/D 左右、J 普攻、K 远程攻击。

### Added / 新增

- 新增默认开启的“自由进化作弊”设置，以及战斗 HUD 的“退化 / 进化”可点击按钮。
- 新增 `BattleSimulation.forceForm()` 与 `window.__bench.cheatEvolve/cheatDevolve`；形态切换免费、保留能量并具有真实形态边界保护。
- 新增 `combatPlane` 快照、`devolution` 事件，以及平面锁定、作弊升降阶和设置迁移测试。

### Verification / 验证

- `npm test`：32/32 通过。
- `npm run build`：成功；仅保留原有主 JS 分块超过 500 kB 的非阻断警告。

## 2026-07-17 — 从单局原型升级为完整产品

### Added / 新增

- 新增标题、主菜单、模式、角色、场地、杯赛、战斗、暂停、结算、结局、资料库与设置的完整有限状态机。
- 新增数码杯六战路线、逐轮奖励、DATA、场地/Boss 解锁、冠军徽章和可恢复进度。

- 新增网络终端、熔岩核心、齿轮工厂、遗迹丛林、黑暗区域五个场地及 pulse、lava、laser、rocks、void 五种确定性机关。
- 新增生命制、限时制、进化竞速、训练四种规则。
- 新增 1–4 斗士配置、多人目标选择与 Rookie/Normal/Veteran 三档 CPU。
- 新增双键盘布局和最多四个标准手柄输入；补充 Guard（防御）与 Heal（治疗）。
- 新增 hit-drop（命中掉落）能量争夺、真实形态索引、降阶重生、最终形态 Ultra 范围攻击。
- 新增 energy、health、power、life 四种模拟层道具。
- 新增版本化存档/设置服务、本地存储降级、迁移、比赛统计和解锁记录。
- 新增本局 GLB 预载进度、缓存/克隆/引用计数/中止/卸载，以及加载错误反馈。
- 新增全产品 UI、四斗士 HUD、程序化音效、机关/进化/Ultra/KO/重生特效与自适应镜头。
- 新增 `MatchFactory` 比赛配置/结算归一化模块与 `window.__bench` 浏览器自动化接口。
- 新增完整产品设计、启动操作和开发交接文档。

### Changed / 变更

- 战斗内核由固定 `player/enemy` 双人假设改为配置驱动的 `fighters[1..4]`；保留旧别名只用于兼容。
- 战场从单平面半径限制改为共享侧视 2.5D 平台边界，越界可直接 KO。
- 能量从自动增长的“爆裂模式”改为命中掉落、拾取归属、技能/治疗/进化共用的资源循环。
- 进化从限时数值增益改为三段真实模型切换；最终形态满槽改为 Ultra。
- 单场开始/结果遮罩扩展为可返回、可重试、可继续杯赛并持久化解锁的产品闭环。
- 渲染、UI、音频和特效改为消费模拟快照/事件，胜负不再由视觉对象决定。
- 道具展示 id/effect 与模拟层类型分离，组合层统一映射为 `energy/health/power/life`。

### Fixed / 修复

- 修复投射物只能命中固定对手的问题，现在可命中任意有效敌方目标。
- 修复多人 CPU 仍以 P1 为唯一目标的问题，现在按最近有效敌人重新选择。
- 修复重生后形态层级与真实模型索引不同步的问题，KO 只下降一个真实层级。
- 修复单形态 Boss 被补齐为三个假形态的问题；满能量会直接释放 Ultra，并增加回归测试。
- 修复机关、道具、暂停和快照中依赖 DOM/随机时序而难以复测的问题，改为种子化确定性逻辑。
- 最终视觉 QA 修复 battle/pause 页面根背景遮挡 Three.js 画布的问题，战斗与暂停界面现在保留正确透明层级和 3D 场景可见性。
