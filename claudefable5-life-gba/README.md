# 像素小日子 — GBA 风模拟人生(Claude Fable 5)

复刻 GBA 掌机质感的模拟人生(The Sims)玩法:240×160 逻辑分辨率的俯视像素小屋,
六项需求驱动的生活模拟,上班-账单-购物的经济闭环。**美术与音频 100% 代码生成,零静态资产。**

## 运行

- 常规:仓库根目录 `npm run dev`,访问 `http://localhost:3000/claudefable5-life-gba/`
- 单独调试:根目录 `npm run dev:one claudefable5-life-gba`(端口 3041)

## 操作(键盘 / 屏上按键均可)

| 按键 | 功能 |
|---|---|
| 方向键 / WASD | 走动(按住 B 跑步) |
| Z / J / 空格(A 键) | 互动 / 确认 / 快进对话 |
| X / K(B 键) | 取消 / 中断当前行动 |
| 回车(START) | 暂停菜单(状态 / 帮助 / 音乐 / 存档 / 回标题) |
| Tab(SELECT) | 收起 HUD |
| M | 音乐开关 |

## 玩法

- **六项需求**:饱食 / 精力 / 卫生 / 膀胱 / 娱乐 / 社交,按不同速率衰减;加权得出心情,头顶菱形宝石绿→黄→红。
- **16 件可互动家具**:床(睡觉跳日 / 小睡)、冰箱、灶台、淋浴、马桶、洗漱台、水槽、电视、沙发、椅子、书架、音响、盆栽、落地灯、电话、邮箱 + 家门与水洼;交互期间时间 ×4~×8,B 可中断。
- **作息**:1 现实秒 = 1 游戏分;昼夜色调渐变,夜里窗户与落地灯发光;睡觉直跳次日 07:00 并弹"第 N 天"过场。
- **经济**:开局 §500;工作日 8:30–9:30 从家门出发上班(蒙太奇),工资 = 职级底薪 ×(0.6+0.6×心情/100);心情 ≥65 绩效 +1,连续 3 点升职加薪(送报员→…→公司老板),旷工 / 低迷降绩效降职。
- **账单**:每周一 8:00 到邮箱(旗子立起),逾期 48h 停电——夜里全黑、电器罢工、只能吃冷食;缴清即复电。
- **电话**:购物热线 6 件升级家具(大床 / 大彩电 / 真皮沙发 / 音响 / 游戏主机 / 大盆栽,即时送达且像素画与数值同时变化)、叫外卖、闲聊热线。
- **NPC**:邻居小樱每天 16:00 门铃来访(BFS 寻路进屋),聊天涨社交攒好感,每 3 次来访送饼干;一只会蹭人的橘猫可撸。
- **后果事件**:膀胱归零尿裤子(现场水洼需拖地)、精力归零倒地睡 3 小时、低需求想法气泡。
- **芯片音乐**:WebAudio 合成,白天 / 夜晚 / 标题三首循环 + 22 种音效。
- **存档**:localStorage 每游戏整点 / 睡觉 / 上班归来 / 手动保存自动写档,标题页"继续生活"。

## 评测钩子

```js
window.__bench.ready            // true
window.__bench.getState()       // { state, day, clock, money, mood, needs{6}, power, billsDue, job, fps }
window.__bench.step(n)          // 无头确定性推进 n 帧(含输入边沿清理)并重绘
window.__bench.press(code, n)   // 模拟按键(KeyboardEvent code),如 press('KeyZ')
window.__bench.shot()           // 画布 dataURL(480×320)
```

标签页隐藏时 rAF 停摆,内置 setInterval 兜底继续推进(评测无头场景可直接 `step()` 精确驱动)。

## 技术

原生 JavaScript + Canvas2D,零运行时依赖(仅 vite devDependency)。物理画布 480×320 = 2× GBA,
世界层按 2× 变换绘制(16px 瓦片美术),中文以 12px 宋体点阵光栅化后 ×2 最近邻放大,得到汉化卡带观感。
模块:`art`(字符网格像素画) / `world`(瓦片地图 + 昼夜光照 + BFS) / `objects`(家具注册表) /
`sim`(需求 / 日历 / 经济) / `npc` / `ui` / `game`(状态机) / `audio`(芯片合成) / `text` / `input` / `main`。
