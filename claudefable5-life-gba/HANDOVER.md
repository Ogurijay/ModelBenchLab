# HANDOVER — claudefable5-life-gba

> 最近更新:2026-07-18 · 状态:**可玩,全流程已过验收**

## 项目定位

Mission `life`(GBA 风格生活模拟)的 Claude Fable 5 作答,与 `gpt5.6solultra-life-gba` 同题对照。
门户分区 "Life Sim — 像素生活模拟",端口 3041(dev:one),常规经 `:3000/claudefable5-life-gba/`。
任务文档:`benchmark/tasks/code-to-ui/life-sim.md`。

## 技术方案速览

- **呈现**:物理画布 480×320(=2× GBA 240×160)。世界层 `ctx.setTransform(2,0,0,2,0,0)` 下按 16px 瓦片坐标绘制;UI 层在物理坐标绘制。页面套 CSS 手绘 GBA 外壳,屏上按键 pointer 事件与键盘共用一套 `Input`。
- **中文像素字**:`text.js` 把字符串按 12px 宋体(有点阵字形)画到暂存画布,再关平滑 ×2 放大 blit,并做 LRU 缓存。**CJK 字号必须 ≥12**,更小会走轮廓渲染发糊(已全量排查过一次)。
- **美术**:`art.js` 全程序化——角色为"身体网格 + 腿部帧网格"拼装(4 方向 ×3 帧 + 坐姿),4 套调色板成 4 名可选角色;NPC 用裙装腿部变体;家具混用字符网格与行构造器;地块用确定性 PRNG 撒噪点。`sheet()` 对行宽不一致会 console.warn(容错渲染),改画时留意控制台。
- **模拟**:`sim.js` 六需求衰减(睡眠另一组倍率)、时刻事件用"跨越检测"(`prev < mark <= now`,兼容手动跳钟);工作与睡觉为**解析式结算**(不逐分模拟)。
- **世界**:`world.js` 28×18 字符地图(图例见文件头),烘焙整张地面 canvas;昼夜 = multiply 双层色 + 夜窗贴片 + lighter 辉光精灵;BFS 供 NPC/猫寻路。
- **状态机**:`game.js` boot/title/charsel/play/status/help/shop/work/newday;对话与选单是回调队列(非 Promise),`ui.busy` 时阻断移动与互动。
- **主循环**:rAF 为主,**标签页隐藏时 rAF 停摆,由 setInterval(50ms, gap>120ms 才补帧)兜底**;`__bench.step/press` 提供无头确定性驱动(评测用)。

精力归零倒地睡;暂停菜单/状态页/帮助页;存档回环(刷新后钱/位置/家具升级/灯态完全一致);22 音效+3 BGM 无运行时错误。

## 已知问题 / 注意

1. **交互优先级**:NPC/猫 > 家具——猫蹲在门口瓦片时 A 会变成撸猫(设计使然,猫被撸后会坐下让路)。
2. 停电时逾期账单只在缴费后复电,无二次惩罚(可扩展:连续拖欠涨滞纳金)。
3. `flags` 中后果类标志(collapse/accident/…)在 `loadFrom` 时清除,日程类保留——改动存档结构时别破坏这一约定,否则要么事件被永久压制、要么周一重复计费。
4. 猫/小樱不做碰撞体(可穿行),避免堵路死锁。
5. 同帧输入泄漏:status/help 退出有 0.15s 去抖;新增全屏页记得同样处理。
