# Mission: fire — 实体火焰模拟(code-to-3d)

审美与图形技术综合题：测试体积感、时序稳定性、透明混合、程序化噪声、动态照明和可控性。固定机位截图用于审美盲评，环绕观察用于判断火焰是否真正具有三维体积。

## 原始任务描述(冻结 v1 · 2026-07-15)

> 使用 Three.js r185 实现一个可实时运行的实体火焰效果。要求：
> ① 火焰从任意水平观察角度都应保持三维体积，不能只用始终朝向相机的单张平面贴图；
> ② 至少表现高温核心、明亮主焰、橙红外焰三层，并具有连续的上升、卷曲、分叉与收尖运动；
> ③ 火焰必须照亮周围实体，亮度随燃烧自然波动；
> ④ 包含火星和烟羽两类伴随现象，运动方向受热流与风向影响；
> ⑤ 提供中文实时控制，可调火势、湍流、风向与渲染质量，并支持暂停和重置视角；
> ⑥ 不使用外部模型、图片或视频素材，几何、材质和纹理全部程序化生成；
> ⑦ 桌面 1080p 目标 60fps，无控制台报错。
>
> 工程要求：Vite 项目，入口 `index.html`；Three.js 版本 `^0.185.0`；暴露 `window.__bench = { ready, stepFrame(n), getState() }` 调试钩子；UI 为中文。

## 核心要求 checklist(遵循度轴逐条勾选)

- [ ] 非 billboard（广告牌）的三维体积火焰，可环绕观察
- [ ] 核心 / 主焰 / 外焰三层温度色，具有连续卷曲和收尖
- [ ] 动态火光照亮至少三类周边实体材质
- [ ] 火星 + 烟羽，受热流和风向影响
- [ ] 火势 / 湍流 / 风向 / 质量控制，暂停与视角复位
- [ ] 零外部资产，全程序化生成
- [ ] 1080p 目标 60fps / 无报错 / `__bench` 钩子

**L4 加分**：真正的体积光线步进（ray marching，沿视线在三维密度场中积分）而非多层切片；域扭曲（domain warping，用噪声扭曲采样空间）形成自然火舌；质量档位能单调改变采样数与性能。
