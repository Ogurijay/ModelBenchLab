# 秋名山 · 再快的86 — 剧情驱动网页赛车

任务身份：`code3d-initiald-001` / v1；mission：`initiald`；类别：`code-to-3d`；难度：L4。状态：draft，尚未冻结正式评测环境或产生模型评分。

## 目标与边界

制作以 2005 年电影《头文字D》为原型的 Three.js 网页赛车同人作品，供自己和朋友本地游玩，不公开发布。角色称呼用演员小名，车辆用真实名称。整体基调是“笑着笑着就哭了”：表面网络梗与弹幕，关键情感时刻突然安静、认真。漂移手感第一优先级，每场比赛都具有赛车之外的动机。

结构是“先登顶，再坠落”：第11章赢下陈老师，成为秋名山车神；终章追不上根本不知道自己在比赛的奔驰；打出“再快的86也追不上奔驰”，尾声加入 Project D。不得把终章变成可以通过升级车辆或技术赢下的普通 Boss 战。

## 终章的完整节拍

1. **追逐起因**：封神第二天清晨送豆腐，山脚看见奔驰；夏树在副驾驶。拓海什么都没想，踩油门。
2. **下坡逼近**：全是弯。奔驰沿固定路线按弯道区间恒定速度前进，略低于玩家可达上限；不读取玩家输入，不堵车，不闪灯，不回头，不做对抗 AI。玩家靠漂移一点点逼近，确实能产生“我能追上”的感受。
3. **最后发夹弯**：触发区保证出现并排镜头，即使玩家落后也不得漏掉；进入慢镜头。2D 漫画分格展示拓海眼睛与车窗后的夏树，一秒对视。立即清空弹幕、隐藏 HUD，音轨停止或只留引擎。
4. **出山**：路变直。奔驰直道恒定速度远超86极速，持续远去，没有双闪，没有后视镜动作。速度由赛道区间定义，不能实现成“永远在玩家前面固定距离”的橡皮筋。
5. **停靠**：86 停路边，画面低饱和、胶片颗粒、电影黑边。沉默很久后第一条“再快的86也追不上奔驰”，再逐渐增加同句，最终化作全屏标题卡。
6. **尾声**：进入 Project D。自由赛的奔驰可战胜，不能把剧情固定败局扩散到自由赛。

自动镜头只接管关键情感区，之前的弯道必须允许真实操控；终章不是把普通赛车循环换个标题，也不是直接显示失败文本。

## 四个玩法系统

### 漂移（地基）

街机模型，自写车辆运动，不使用物理引擎车辆模块。车头朝向与速度向量分开计算，夹角即漂移角。手刹或重心转移降低后轮抓地，反打维持漂移，松手后抓地逐渐恢复。稳定漂移角与高出弯速度加分，完美漂移触发0.5秒慢镜头、音效和轻微震动。碰撞有可恢复反馈，不能只沿轨道播放动画或用左右平移冒充漂移。

验收状态至少可读：位置、车头角、速度向量、漂移角、后轮抓地、车速、漂移连击、碰撞数、赛道进度、固定步长。30/60/120fps输入回放须给出误差，不把渲染帧当物理步。

### 水杯

豆腐送货与自由赛豆腐挑战显示水面晃动；横向加速度、急刹会洒水，平稳行驶明显较少，洒光失败。不能把水量简单按时间线性扣减。五菱后备箱豆腐也接入此系统。尾声放水杯构成首尾呼应。

### 排水渠

指定急弯内侧有可见排水沟。第6章首次解锁。只有内侧轮进入合法窄区间、方向与车速满足条件才可获得过弯收益；需要练习。不能全路段贴边就加速，也不能第1章已经启用。

### 弹幕

HTML 覆盖 Three.js 画布。比赛事件触发梗池：普通漂移、完美漂移、超车、宏光、章节封神有差异。常用“86上山了”“前方高能”“这是物理外挂吧”“山鸡哥yyds”。情感区进入时清理已有与排队弹幕，禁止慢镜头之后残留。关闭弹幕是叙事开关；用户另有弹幕开关，不能破坏强制静默。

### 五菱宏光的完整设定

一辆几万块的白色面包车站在一排日系名车起跑线上，对比感是核心。用户提供的梗来源为山路视频追逐甩开 BRZ 与宝马 M2，传播出“昨晚我在秋名山输给一辆五菱宏光”；此来源尚未核实。

- 被动“遇强则强”：对手越贵越强，隐藏加成越高，对奔驰最大。定义明确的对手强度表、上限，状态可读；不能把约100匹当作加成后的真实动力。
- 涂装：白色面包车，“专业防水补漏”广告与电话。电话使用虚构占位号，避免出现真实私人联系方式。
- 七座：后排可载阿木、山鸡哥；喊话、晃动、提供小加成。
- 后备箱装豆腐，兼容水杯。
- 极小概率速度表跳518km/h，定义为测速表故障彩蛋，不改变实际速度向量；测试可用固定seed复现。
- 任意车可贴五菱车标，运气+1%；效果与概率明确，可复现。
- 专属弹幕：“人民需要什么，五菱就造什么”“车不行，别怪路不平”。

## 美术、镜头、情绪与音频

90年代日本赛车动画赛璐璐质感 + 青春电影光影。赛车段高对比，情感段低饱和、有空气感。车与近景3D，低多边形但型号轮廓清晰，三阶卡通色阶、黑色描边。远山、天空、晚霞用手绘风贴图形成层次。

人物为2D漫画式立绘，HTML层覆盖画布，视觉小说对话框，常态/笑/沉默差分；车内仅低多边形剪影。SVG用于Q版梗、震惊表情、漫画分格、速度线、集中线、气泡与大字；海滩表白、终章对视的少量关键画面用单独精绘PNG，不能拿通用SVG声称已达到精绘质量。

| 时间 / 章节 | 主色 | 情绪 |
|---|---|---|
| 黎明 / 1、终章开头、尾声 | #2B3A67冷蓝 + 淡粉天边 | 孤独、重复 |
| 正午 / 2、7 | #4FB3FF天蓝 + 纯白 | 青春、心动 |
| 黄昏 / 3、5 | #F28C38暖橙 + 紫 | 温暖、日常 |
| 夜赛 / 4、6、8、11 | #0D1225蓝黑 + 灯带 | 热血、紧张 |
| 雨夜 / 9、10 | #5A6B73灰青 | 痛苦、失落 |
| 终章出山 | 过曝白 + 淡金 | 迷茫、释然 |

尾灯轨迹：86白，GT-R红，FC冰蓝，EVO紫，奔驰金。视角随速度扩大，高速速度线与径向模糊；漂移镜头向外侧摆。关键超车切2–3格漫画分镜，插入对手震惊反应。情感区去饱和、胶片颗粒、电影黑边、隐藏HUD、停弹幕，只留环境音。

仪表是80年代数码液晶转速/速度，粗黑标题配日式毛笔感，竖排章节卡，弹幕白字黑描边，刷屏放大。比赛用原创 Eurobeat 风格音乐，节奏响应排名与连击；情感用钢琴/木吉他，海滩结尾、对视、终章结尾以静音或引擎声配乐。不得自动播放侵权电影原声冒充原创音乐。

## 验收与评分

专项 rubric：`shared/rubrics/initiald-story-racing.md`。漂移占35%，剧情/终章占25%；其余见评分卡。正式评测需固定逐字输入、Three.js解析版本、构建工具、浏览器/GPU、分辨率、观察时长、输入回放与seed，每模型至少3次独立生成，A为主榜，B可选。内部单元测试不替代三次模型采样。

关键检查：

- 从首页开始完整送货、赢一次正常比赛、重试一次失误失败。
- 手刹起漂→反打稳定→松手恢复→护栏碰撞恢复；重复输入跨帧率比较。
- 水杯平稳/急刹/横向漂移差异；洒光真实失败。
- 排水渠未解锁不生效，合法内侧窄区生效，外侧/直道不生效。
- 第3章AE85败局、第9章最后一弯爆缸、第11章FC真实技术赛、第9章和终章解锁例外。
- 慢玩家、快玩家均能触发终章对视；奔驰不读取玩家状态、直道速度优势、长静默、同句刷屏、标题、Project D。
- 自由赛四赛道、五赛制、最多8车、各车型差异；86下坡赢奔驰，主线奔驰仍必输。
- 情感段清除排队弹幕、隐藏HUD、音频切换；夏树台词不玩梗。
- 本地存档刷新恢复；新游戏明确重置；暂停/失焦释放按键，不后台继续比赛。
- 真浏览器操控与console、1440×900与390×844截图；移动端控制可见、不被剧情层遮挡。

手感、角色辨识度、情绪节奏和精绘质量需要人工游玩与视觉评分；结构校验或build通过不等于这些项目合格。
