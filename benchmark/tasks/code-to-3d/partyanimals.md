# Mission: partyanimals — 动物派对式物理乱斗

## 固定任务

逐字原始 prompt：「用three.js复刻动物派对」（2026-10-13，用户直接提出，无附加约束）。

复刻对象是 *Party Animals*（动物派对，Recreate Games）的玩法：毛绒动物在物理布娃娃驱动下互殴，把对手打晕后抓起扔出场外，最后存活者赢下回合。原作角色形象、名称、地图美术与音乐受版权保护，作答应使用原创动物造型、原创地图与音频承担对应玩法，复刻的是操作、物理手感、规则与模式结构。

## 必须满足

- Three.js 渲染的 3D 场景，第三人称跟随镜头；动物由物理驱动（布娃娃 / 主动布娃娃），受击会晃动、跌倒，而不是播放固定动画。
- 原作式操作：移动、疾跑、跳跃；出拳、踢、头槌、空中飞踢；抓取（可抓人、抓物、抓场景边沿），抓住时可拖拽、举起、投掷与攀爬。
- 规则：受击累积导致晕倒（有明显晕眩表现），晕倒期间可被抓起扔出；掉出场外 / 落水等出局；回合制，最后存活的个人或队伍得分，先到设定分数者获胜。
- 多张带机关的地图（随时间推进的危险，如收缩毒雾、大浪、强风、断桥等），以及武器 / 可投掷道具。
- 电脑对手会主动战斗并会把晕倒的对手扔出场外；至少个人混战与团队两种模式，有结算统计。

## 重点评审

1. 物理手感：角色站立与行走是否稳定、软萌又可被打飞；拳脚命中的反馈；抓取关节是否可靠（拖、举、扔、挂边、攀爬）。
2. 规则与模式还原：击晕—抓起—扔出的核心循环，回合 / 比分 / 突然死亡流程，团队与个人模式。
3. 地图机关与道具：每张地图是否有独特的淘汰手段并影响战术；武器差异化。
4. 美术与表现：毛绒质感、表情（晕眩、受伤）、特效、音效、HUD 与菜单完成度，帧率。
5. AI：能否追打、捡武器、躲机关、把晕倒的对手扔下去。

## 复核路径

1. 进入主菜单 → 开始派对，选择动物与毛色，设置模式 / 对手数 / 难度 / 地图，开打。
2. 练习场：对木桩连续出拳至其晕倒（星星），按住抓取将其举过头顶后投掷出场外；测试踢、飞踢、蓄力头槌。
3. 抓住护栏 / 墙沿悬挂并按跳跃攀爬；被抓时连按动作键挣脱。
4. 逐张地图各打一回合，确认机关（毒雾 / 大浪 / 浮冰下沉 / 狂风 / 断桥）会造成淘汰，90 秒后进入突然死亡。
5. 拾取各类武器（含冰冻枪与炸弹）并命中对手；打完整场比赛检查结算表。
6. 记录 1080p 下 8 只动物混战时的帧率。
