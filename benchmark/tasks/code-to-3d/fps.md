# Mission: fps — Three.js 第一人称射击

## 固定任务

逐字原始 prompt：「做一个基于three.js的fps游戏」（2026-10-10，用户直接提出，无附加约束）。

题面极简，评测重点是模型能否把一句话需求自行扩展成**完整可玩**的第一人称射击游戏，而不是只做一个能开枪的场景演示。

## 必须满足

- 基于 Three.js 渲染，第一人称视角，指针锁定鼠标瞄准 + 键盘移动，可在浏览器直接运行。
- 射击闭环：开火、命中判定、弹药与换弹、敌人受伤与死亡、玩家受伤与死亡。
- 有会主动作战的敌人（不是静止靶），有可完成或可失败的目标，以及开始 / 结束 / 重来流程。
- HUD 至少包含准星、生命、弹药，并有命中与受伤反馈。

## 重点评审

1. 手感：移动加速度、视角灵敏度、后坐与散布、开镜、射击声光反馈是否扎实。
2. 敌人 AI：感知（视线/听觉）、寻路、掩体或走位、射击可躲避性与难度平衡。
3. 关卡与美术：空间结构是否支持多路线交战，光影/材质/特效的完成度，帧率表现。
4. 内容完整度：武器种类、敌人种类、任务/模式、音效音乐、设置与暂停。

## 复核路径

1. 打开页面进入主菜单，选择任意模式与难度，确认指针锁定、移动、跳跃、蹲伏与冲刺。
2. 切换全部武器，射击墙面与敌人，检查弹孔/火花、命中标记、击杀反馈与换弹动画。
3. 与多个敌人交战：确认敌人会发现玩家、移动并射击，玩家可侧移躲避弹丸并被击中时有方向提示。
4. 完成或失败一局，检查结算界面与重新开始。
5. 记录 1080p 下典型战斗场景的帧率。
