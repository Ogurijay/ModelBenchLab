# Mission: domino — 多米诺·鲁布戈德堡机关(code-to-3d)

物理串联 + **确定性**题:刚体链式反应,同一初始条件多次运行结果必须一致(直接考"一致性"轴)。

## 原始任务描述(冻结 v1 · 2026-07-10)

> 用 Three.js 实现一个多米诺·鲁布戈德堡机关链场景。要求:
> ① 至少 5 种不同类型的机关依次触发,形成一条完整链:例如 多米诺骨牌序列 → 球沿斜坡滚落 → 杠杆跷跷板 → 摆锤撞击 → 终点铃铛(响声 + 视觉反馈);
> ② 物理引擎可用 cannon-es 或自写刚体,但必须**固定 timestep**(与渲染帧率解耦),保证同一初始条件多次运行结果确定一致;
> ③ 「触发」按钮启动链条,「复位」按钮完全还原初始状态,可反复触发且每次结果一致;
> ④ 相机:自动跟随当前活动机关的运镜模式 + 手动轨道控制模式,可切换;
> ⑤ 全程链条能可靠走通(无卡死 / 无穿模断链),终点铃铛必响;
> ⑥ 布景有设计感:灯光、材质、配色统一,不是灰盒子;
> ⑦ 桌面 1080p 稳定 60fps,无控制台报错。
>
> 工程要求(所有作答统一):Vite 项目,入口 `index.html`;暴露 `window.__bench = { ready, stepFrame(n), getState() }` 调试钩子,`getState()` 至少返回 `{ triggered, currentStage, bellRung }`;UI 为中文。

## 核心要求 checklist

- [ ] ≥5 种机关类型且依次触发成链
- [ ] 固定 timestep、渲染解耦
- [ ] 触发 / 复位可反复、结果确定(评委连跑 3 次比对 bellRung 时刻)
- [ ] 自动跟随 + 手动轨道双相机模式
- [ ] 链条 100% 走通、铃铛必响
- [ ] 布景审美(主观锚定)
- [ ] 60fps / 无报错 / `__bench` 钩子

**L4 加分**:机关 ≥8 种;用户可编辑摆放多米诺;慢动作回放。

**验收陷阱(评委必做)**:连续「触发→复位」5 次,任何一次断链 / 铃不响 / 复位后残留位移即扣一致性分;切到后台再切回(RAF 暂停)不得导致物理爆炸。
