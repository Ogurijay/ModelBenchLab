# Mission: cloth — 旗帜布料模拟(code-to-3d)

物理算法深度题:**真物理 vs 假波动的分水岭**。禁用现成物理库,必须自写 Verlet 积分 + 约束求解。

## 原始任务描述(冻结 v1 · 2026-07-10)

> 用 Three.js 实现一面挂在旗杆上的旗帜布料模拟。要求:
> ① 布料物理必须自行实现:Verlet 积分 + 距离约束迭代求解(结构约束 + 剪切约束),**禁止使用任何现成布料 / 物理库**;
> ② 风力系统:方向 + 强度滑杆实时响应,带阵风扰动(非均匀恒定风),风对布料的作用须考虑面片朝向(法线投影);
> ③ 鼠标可抓取布料任意点拖拽,松手后自然恢复;
> ④ 固定点模式可切换:整边固定(旗帜)/ 仅两角固定(晾布);
> ⑤ 法线实时重算、双面渲染、受场景光照,旗面有程序化图案;
> ⑥ 参数面板:布料分辨率(重建)、约束迭代次数(刚度)、重力、阻尼、风参数;
> ⑦ 场景有地面 / 天空 / 旗杆,整体有氛围(不是黑底一块布);
> ⑧ 桌面 1080p 稳定 60fps(默认分辨率下),无控制台报错。
>
> 工程要求(所有作答统一):Vite 项目,入口 `index.html`;暴露 `window.__bench = { ready, stepFrame(n), getState() }` 调试钩子;UI 为中文。

## 核心要求 checklist

- [ ] Verlet + 距离约束自写(代码审查确认,无物理库依赖)

- [ ] 鼠标抓取拖拽任意布点、松手恢复
- [ ] 整边固定 / 两角固定切换
- [ ] 法线实时更新 + 双面光照 + 程序化旗面图案
- [ ] 参数面板 5 项齐备且生效
- [ ] 场景完整有氛围 / 60fps / 无报错 / `__bench` 钩子

**L4 加分**:布料撕裂(超应力断开约束);自碰撞或与旗杆碰撞;LOD 或 Web Worker 加速。

**验收陷阱(评委必做)**:抓住布料一角猛拽——顶点正弦波动的假布料立刻穿帮;把迭代次数调到 1 应明显变"松弛"。
