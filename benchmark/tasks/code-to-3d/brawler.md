# Mission：3D 竞技格斗（brawler）

## 目标

在浏览器中实现一个可玩的第三人称 3D 竞技格斗原型。评测重点不仅是角色和场景能否显示，还包括输入响应、攻击命中、AI 对手、胜负闭环与战斗信息反馈。

## 核心要求

- 至少一名玩家角色与一名 AI（人工智能）对手。
- 具备移动、普通攻击、特殊技能与防御性动作。
- 具备明确的生命、资源、计时和胜负状态。
- 角色动作与战斗状态一致，命中时有视觉与声音反馈。
- 固定时间步或等价的帧率无关逻辑，避免不同刷新率下战斗速度漂移。
- 桌面端可完整游玩，窄屏下 HUD（抬头显示界面）不遮挡核心画面。

## 本实现特性

- 亚古兽 vs 加布兽，读取本地自包含 GLB（网页 3D 模型）与骨骼动画。
- 三段近战、远程投射物、跳跃、闪避、能量拾取与 8 秒爆裂强化。
- 90 秒单局、CPU 决策、伤害硬直、击退、场地边缘约束、结果统计。
