# Mission: gallery — 美术馆布光(code-to-3d)

审美重心题:测 PBR 材质、多光源布光层次、空间构图。截图直接作为 `vlm-aesthetic` 的审美刺激材料(一鱼两吃)。

## 原始任务描述(冻结 v1 · 2026-07-10)

> 用 Three.js 建一个可第一人称漫游的小型美术馆室内场景。要求:
> ① 至少 6 件展品(雕塑 / 画作混合),每件配说明牌(名称 + 一句介绍,中文);
> ② 至少三种光源类型:聚光灯打展品(有半影)、面光源 / 补光做环境层次、可开关的自然天光(天窗或落地窗);
> ③ 材质使用 PBR,至少含金属、粗糙石材、木质三种质感,地面有真实反射感;
> ④ WASD + 鼠标视角漫游,不可穿墙穿展品;
> ⑤ 整体色调统一、有明确视觉动线(观众自然被引导逛完全部展品);
> ⑥ 不使用任何外部模型 / 贴图文件,几何与纹理全部程序化生成(canvas 纹理允许);
> ⑦ 桌面 1080p 稳定 60fps,无控制台报错。
>
> 工程要求(所有作答统一):Vite 项目,入口 `index.html`;暴露 `window.__bench = { ready, stepFrame(n), getState() }` 调试钩子供自动化验证;UI 为中文。

## 核心要求 checklist(遵循度轴逐条勾选)

- [ ] ≥6 件展品且雕塑画作混合、各有中文说明牌
- [ ] 聚光(带半影)+ 面光/补光 + 可开关天光,三类齐备
- [ ] 金属 / 石材 / 木质三种 PBR 质感 + 地面反射
- [ ] WASD + 鼠标漫游、墙体与展品碰撞
- [ ] 色调统一、动线明确(主观锚定)
- [ ] 零外部资产,纹理程序化
- [ ] 60fps / 无报错 / `__bench` 钩子

**L4 加分**:昼夜天光联动全场氛围;画作内容程序化生成且各不相同;烘焙感 AO。
