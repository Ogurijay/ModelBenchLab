# Mission: manhattan — 3D 曼哈顿场景复现(code-to-3d)

给定"用 Web 3D 技术复现一片可辨认的曼哈顿城市"这一任务,不同模型各自写代码生成场景。本文件是该 mission 的**冻结规范**:评分时对照此清单,保证同一标准。

**设计意图**:单一场景同时压测五项能力 —— ①结构化**建模**(地标/路网/城市肌理)、②有机形体**3D 雕刻**(地形/岩石/雕像/云)、③**动画**编排(交通/昼夜/生物/环境)、④**天气**系统(多态切换 + 场景响应)、⑤**计算**(确定性生成/真实公式/仿真/性能预算)。任一能力缺失都会在画面上直接可见,无法互相掩盖。

## 原始任务描述(冻结 v1 — 2026-07-10)

> 用 Web 3D 技术(Three.js 等通用库允许,游戏引擎导出物禁止)复现一片可辨认的 3D 曼哈顿。要求:
>
> 1. **建模**:曼哈顿式路网(南北大道 × 东西街道 + 百老汇斜切产生三角地块),≥4 座可辨认地标(如帝国大厦、克莱斯勒大厦、世贸中心一号楼、熨斗大厦),成片程序化楼群与屋顶水塔、路灯、红绿灯等城市肌理,一座悬索桥。
> 2. **3D 雕刻**:中央公园起伏地形与下凹水塘、裸露岩石、一座自由女神像(衣褶需体现雕刻手法)、有体积感的云团——全部用顶点级雕刻/位移完成,禁止用贴图假装体积。
> 3. **动画**:完整昼夜循环(太阳/月亮/星空/窗灯/路灯联动);车辆沿路网行驶、路口红绿灯停走与转向;≥2 种非车辆动画体(鸟群/直升机/船只等);广告牌、井盖蒸汽等环境动画;相机支持自由轨道 + 自动环游。
> 4. **天气**:≥5 种可切换天气(至少含雨、雪、雾、雷暴),切换需平滑过渡;场景必须响应——雨天路面变湿、雪天屋顶与地面积雪、雾天高楼没顶、雷暴闪电击中高楼并伴随雷声;风影响雨雪倾角与云速。
> 5. **计算**:种子驱动的确定性城市生成(同种子同城市,可输入种子重建);≥2 处真实公式(如纬度 40.7°N 的太阳高度角、悬索桥主缆悬链线、双峰天际线高度场);带信号相位与跟车防撞的交通仿真;实例化渲染,桌面 1080p ≥60fps,运行时统计 HUD(FPS/drawcall/实例数)。
>
> 约束:禁止加载任何外部二进制资产(模型/贴图/音频文件),所有几何、纹理、音效必须程序化生成;UI 用中文;无控制台报错。

## 公共核心要求(按五能力逐条勾选)

### ① 建模能力(结构化建模)

- [ ] 曼哈顿路网:南北大道 × 东西街道正交网格,百老汇斜切且产生三角地块
- [ ] ≥4 座可辨认地标,纯代码建模(退台/收分/冠顶/三角楼等特征到位)
- [ ] 成片程序化楼群(非复制粘贴同一盒子),屋顶水塔/空调箱等细节
- [ ] 街道家具:路灯、红绿灯,人行横道/车道线
- [ ] 悬索桥:主塔 + 主缆 + 吊索 + 桥面,结构可信

### ② 3D 雕刻能力(有机形体)

- [ ] 公园地形:噪声/手工雕刻的起伏丘陵,边缘与街面自然衔接
- [ ] 下凹水塘(真实凹陷,非贴图)
- [ ] 岩石露头:位移雕刻,形态自然
- [ ] 自由女神像:轮廓可辨(冠/炬/基座),衣褶有雕刻痕迹
- [ ] 云团有体积感(位移/多球聚合等,非公告板贴图)

### ③ 动画绘制能力

- [ ] 昼夜循环:太阳/月亮/星空运转,窗灯与路灯在黄昏自动亮起
- [ ] 交通流:车辆沿车道行驶,红灯停绿灯行,路口转向,不互相穿插
- [ ] ≥2 种非车辆动画体(拍翅鸟群/旋翼直升机/河面船只…)
- [ ] 环境动画:广告牌内容动画、蒸汽/烟雾、云漂移
- [ ] 相机:自由轨道 + 自动环游(平滑样条路径)

### ④ 天气能力

- [ ] ≥5 种天气预设可切换,至少含雨/雪/雾/雷暴
- [ ] 切换平滑过渡(参数插值,非硬切)
- [ ] 雨天:路面变湿变亮;雪天:屋顶与地面积雪(按朝上法线)
- [ ] 雾天:高楼没顶,天空/雾色一致
- [ ] 雷暴:闪电优先击中最高建筑,带雷声(按声速延迟加分)
- [ ] 风:影响雨雪倾角与云速(树摇加分)

### ⑤ 计算能力

- [ ] 种子确定性:同种子重建得到同一城市(UI 可输种子)
- [ ] ≥2 处真实公式计算(太阳高度角/悬链线/高度场分布等,文档需注明)
- [ ] 交通仿真:信号相位 + 跟车防撞(非匀速循环动画)
- [ ] 实例化/合批渲染,桌面 1080p ≥60fps
- [ ] 运行时统计 HUD:FPS、drawcall、三角形、实例数

## 约束(硬性)

- **零外部资产**:禁止加载模型/贴图/HDRI/音频文件,一切程序化生成(这使建模与雕刻测的是模型本身,而非找素材能力)
- 通用 3D 库(Three.js / Babylon 等)允许;Unity/Unreal 等引擎导出物禁止
- 中文 UI;无控制台报错;交接文档齐全(README / HANDOVER / CHANGELOG)

## 评分

用 `shared/rubrics/code-to-3d.md`(七维 + 审美子表)。A 需求遵循 = 上方五能力清单逐条勾选(五组各占 1/5,组内按条目均分)。

**评测环境锁定**:桌面 1920×1080、固定 GPU 档;观察 ≥90s,须覆盖一次完整昼夜(用时间加速)+ 每种天气 ≥10s + 种子重建一次(输入 1337 / 2026 / 42 各一次验证确定性);截图归档 `benchmark/runs/<date>_<model>/`,匿名盲评。
