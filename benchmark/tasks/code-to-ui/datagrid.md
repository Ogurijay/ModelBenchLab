# Mission: datagrid — 十万行虚拟滚动数据网格(code-to-ui)

前端 UI 工程题:**性能(虚拟化)、防抖 / 节流、交互细节**三位一体。禁用框架,原生 JS 手写。

## 原始任务描述(冻结 v1 · 2026-07-10)

> 用原生 JavaScript(禁止任何框架 / 组件库)实现一个十万行数据网格,Vite 项目。要求:
> ① 数据:100,000 行 × 7 列(工号、姓名、部门、城市、薪资、入职日期、状态),用**固定 seed 的 PRNG** 程序化生成(刷新后数据完全一致);
> ② **虚拟滚动**:任意时刻 DOM 中的数据行节点 ≤ 80 个;滚动条高度正确反映总数据量;快速拖拽滚动条 / 惯性滚动均流畅(≥55fps);
> ③ **实时搜索(防抖 300ms)**:跨姓名 / 部门 / 城市字段;连续输入期间不得执行过滤,停止输入 300ms 后恰好执行一次;命中关键字高亮;
> ④ **窗口 resize(节流或 rAF 合帧)**:可视区行数随窗口高度自适应,resize 处理频率受限;
> ⑤ 多列排序:点击表头三态循环(升 / 降 / 无),100k 行排序 UI 不失响应,显示排序耗时;
> ⑥ 列宽拖拽调整(带拖拽指示线),表头吸顶;
> ⑦ 键盘导航:↑↓ 移动活动行(自动滚动跟随)、PageUp/PageDown、Home/End;行选择:单击单选、Shift+单击范围多选、Ctrl+单击增删选;**排序 / 过滤后选中集合保持正确**(按行 id 而非行号);
> ⑧ 状态与反馈:空态(搜索无结果)有插画式提示;选中计数;斑马纹 + hover 高亮;暗色主题、有设计感;
> ⑨ **性能 HUD 自证**(右下角常驻):FPS、当前 DOM 行节点数、总行数 / 过滤后行数、最近一次过滤 / 排序耗时、过滤执行次数计数器;
> ⑩ 中文 UI,1080p 与 390px 宽移动端均可用。
>
> 工程要求(所有作答统一):入口 `index.html`;暴露 `window.__bench = { ready, getState(), scrollToRow(i), search(text) }` 调试钩子,`getState()` 返回 `{ domRowCount, totalRows, filteredRows, filterRuns, selectedCount }`;UI 为中文。

## 核心要求 checklist

- [ ] 100k 行固定 seed 生成、刷新一致
- [ ] DOM 行节点 ≤80(客观:`getState().domRowCount`)且滚动条比例正确
- [ ] 搜索防抖 300ms:输入期间 filterRuns 不增,停止后 +1(客观)
- [ ] resize 节流 / rAF(客观:处理计数)
- [ ] 表头三态排序 + 耗时显示
- [ ] 列宽拖拽 + 表头吸顶
- [ ] 键盘导航 + 三种选择模式 + 排序过滤后选中不错乱(按 id)
- [ ] 空态 / 选中计数 / 斑马纹 hover / 暗色主题
- [ ] 性能 HUD 五项齐备
- [ ] 移动端可用 / 中文 / `__bench` 钩子

**L4 加分**:列固定(冻结左列);行高不定(动态测量)虚拟化;Web Worker 排序;导出 CSV。

**验收陷阱(评委必做)**:快速输入"张伟"逐字删改,观察 filterRuns 只在停顿后 +1;拖滚动条到 50000 行处检查 DOM 行数仍 ≤80;排序后 Shift 范围选择再过滤,选中集合必须仍指向同一批行 id。
