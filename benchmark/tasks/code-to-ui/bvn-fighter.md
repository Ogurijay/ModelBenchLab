# Code-to-UI：死神vs火影(BVN)式 2D 动漫格斗复刻

## 固定任务

原始需求(逐字):「复刻一个火影vs死神小游戏」。

在浏览器中复刻经典 Flash 同人格斗游戏 *Bleach vs Naruto*(死神vs火影,BVN)的玩法:2D 横版动漫格斗,BVN 式六键操作与出招体系、气 / 查克拉(灵力)/ 援助三槽资源、奥义演出与多种模式。原作《火影忍者》《死神》角色形象、名字与 BVN 素材受版权保护,作答可用原创角色承担对应定位,复刻对象是操作、规则、系统与模式结构。

## 必须满足

- 2D 横版战场:左右移动、跳跃(含二段跳)、冲刺 / 瞬步,镜头随双方距离缩放与跟随,双方保持同屏。
- BVN 操作:每名玩家 方向 + J 攻击 / K 跳 / L 冲刺 / U 技能 / I 必杀 / O 援助;按住 S 防御;W / S + J/U/I 与空中 J/U/I 出不同招式;连按 J 打出普攻连段。
- 战斗系统:命中取消(普攻 → 技能 → 必杀)、挑空后跳跃追击空中连段、连击计数与伤害递减、硬直上限强制倒地;受身、倒地起身无敌;受击中消耗资源替身脱离;格挡与破防。
- 资源:体力;气槽 3 格(攻防积累,必杀消耗 1–3 格,含限时觉醒 / 卍解类变身);查克拉 / 灵力(技能与空中冲刺消耗、自动回复);援助槽充满后召唤援助角色。
- 演出:必杀发动时冻结画面并显示人物 cut-in 与招式名;两阵营(忍者 / 死神)角色各有招式定位(分身、螺旋查克拉球、雷遁突刺、操砂、瞳术、月牙剑气、冰龙、花刃、狂战、鬼道封印等)。
- 模式:单人闯关(连战 + 最终首领 + 续关)、人机对战、双人同键盘对战、团队 3v3 接力、生存、训练(可设木桩行为 / 无限资源 / 判定框)、观战演示;选人含援助选择,选场景,结算统计,出招表与键位设置;电脑对手按难度行动。

## 重点评审

1. 手感与系统还原度:连段节奏、命中取消、挑空追击、替身 / 受身、奥义冻结演出、镜头缩放是否接近 BVN。
2. 角色差异化:各角色是否有可辨识的定位与独立招式组,远程 / 突进 / 陷阱 / 变身等类型是否均衡,电脑能否使用。
3. 系统完整度:标题 → 模式 → 选人(含援助)→ 场景 → VS → 对战 → 结算 / 续关 的闭环,团队接力与生存推进。

## 复核路径

1. 标题 → 人机对战;1P 选角色与援助,再为电脑选角色,选场景,进入对战。
2. 贴身连按 J 打出四段普攻;J ×3 后 W+J 挑空,命中后按 K 跳起接空中 J 连段;J 连段命中后按 I 取消成必杀,确认 cut-in。
3. 测试 U / W+U / S+U / 空中 U 与 I / W+I / S+I / 空中 I;气满 3 格时 S+I 觉醒 / 卍解变身。
4. 被连击时按 L 替身、被击飞时按 K 受身;援助槽满时按 O 召唤援助。
5. 跑一局团队 3v3 与生存,单人闯关打到最终首领,检查结算与续关。
