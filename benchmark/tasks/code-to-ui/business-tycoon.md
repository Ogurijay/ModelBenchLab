# 像素商业大亨任务

## 目标

实现一款可直接在浏览器游玩的像素风商业养成与经营模拟游戏。重点评估复杂状态组织、数据驱动 UI（用户界面）和视觉完成度，而非静态仪表盘。

## 固定要求

- 至少 10 类会进入结算逻辑的商业机制。
- 至少 100 种可被玩家选择并实际开设的商业模式。
- 有完整的开店、逐日结算、盈利或亏损反馈与扩张循环。
- 玩家可调整不少于 4 项门店经营策略。
- 提供城市事件、资金或贷款、声誉或成长目标等长期变量。
- 使用像素风视觉语言，桌面和移动端均可操作。
- 不依赖服务端即可游玩，并提供本地存档。

## 复核路径

1. 打开模式图鉴，确认模式数量和筛选能力。
2. 开设一家门店，连续结算 3 天。
3. 调整定价、供应、人员、营销和数字化方案，再次结算。
4. 使用贷款扩张第二家店，观察全局现金、声誉、账本和目标变化。
5. 刷新页面，确认存档恢复。
