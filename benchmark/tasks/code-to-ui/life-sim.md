# Code-to-UI：GBA 风格生活模拟

## 固定任务

构建一个可直接在浏览器游玩的 GBA 风格生活模拟游戏。画面需要具有明确的低分辨率像素美术语言，并形成“移动 → 接近对象 → 互动 → 时间与需求变化”的完整循环。

## 必须满足

- 使用约 240×160 的内部游戏分辨率，并以 nearest-neighbor（最近邻）方式放大。
- 角色可通过键盘方向键移动，至少有 6 个可辨识、可互动的生活对象。
- 至少包含时间、金钱、饱腹、精力、卫生、娱乐、社交五类状态。
- 每次互动应有行动反馈，并真实改变状态或推进时间。
- 同时支持键盘和触屏/鼠标可操作的掌机按键。
- 窄屏与桌面端均可完整游玩，不依赖外部图片资产。

## 重点评审

1. 是否形成了可玩的生活模拟闭环，而不只是静态像素场景。
2. GBA 色板、低分辨率构图、像素边缘和掌机外观是否统一。
3. 交互提示、状态反馈和触屏操作是否清晰可靠。
