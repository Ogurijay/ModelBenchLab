# Code-to-UI：LF2 式 2.5D 横版格斗复刻

## 固定任务

原始需求(逐字):「1：1 复刻 little fighter 2横板格斗游戏」。

在浏览器中复刻 PC 游戏 *Little Fighter 2*(LF2)的玩法:2.5D 横版(左右 + 纵深 + 高度)多人格斗,LF2 式操作与出招、战斗规则和游戏模式。原版角色形象、位图与音乐受版权保护,作答应以原创角色/美术/音乐承担对应玩法定位,而复刻对象是规则、操作、引擎机制与模式结构。

## 必须满足

- 2.5D 战场:x 横向、z 纵深(可上下走位)、y 高度(跳跃/击飞),角色有影子与深度排序,镜头随玩家横向卷动。
- LF2 操作:每名玩家 7 键(上下左右 + 攻击/跳/防御);双击方向跑步,跑中跳 = 冲跳,跑中攻击/防御 = 跑攻/翻滚,空中攻击;D + 方向 + A/J 出必杀技。
- LF2 战斗规则:HP/MP 双槽(HP 含可恢复上限)、MP 自然回复;受击累积导致受击 → 晕眩 → 倒地;晕眩时可重拳或抓投;防御可被连续攻击破防;被击飞落地前可空翻卸力。
- 物品:地图会掉落轻武器(可挥砍、投掷)、重物(举起投掷)与回 HP/MP 的饮料;飞行道具可被近身攻击反弹、可互相抵消。
- 多名角色各有独立招式组;冰冻、燃烧等状态效果;电脑对手按难度行动。
- 模式:至少 VS 对战、闯关(分段推进 + 首领)与另一种 LF2 模式(锦标赛 / 军团战 / 演示),支持多人同键盘与电脑玩家、队伍设置,有结算统计。

## 重点评审

1. 手感与规则还原度:30 帧逻辑、重力、跳跃/冲跳弧线、连击节奏、晕眩—重拳—倒地、破防、空翻等是否接近原版。
2. 角色差异化:各角色招式是否覆盖原版定位(气功、升龙、瞬移、冰冻、燃烧、治疗、力场、射箭、分身、变身等),AI 能否使用。
3. 系统完整度:选人(加入/队伍/电脑)→ 模式设置 → 对战 → 结算的闭环;闯关推进与生存;锦标赛对阵;军团战增援。

## 复核路径

1. 标题 → Game Start;P1 按攻击加入,选角色与队伍,再加入 2–3 名电脑,进入 VS Mode。
2. 对电脑连按攻击:三拳令其晕眩,第四击自动重拳击倒;走近晕眩敌人可抓住,方向 + 攻击摔出。
3. 双击方向跑步,跑中按跳冲跳、冲跳中按攻击冲踢;被击飞时按跳空翻。
4. 依次输入 D>A、D^A、D>J、D^J、DvJ 测试招式;捡起武器挥砍与投掷,喝牛奶/啤酒。
5. 闯关模式打通 1-1~1-5(首领段),观察 GO 推进;锦标赛与军团战各跑一局,检查结算表。
