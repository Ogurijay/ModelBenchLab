# Code-to-UI：2D 无限世界沙盒生存（泰拉瑞亚风格 + 我的世界玩法）

## 固定任务

实现一个类似《泰拉瑞亚》的浏览器游戏：画面采用泰拉瑞亚式 2D 横版像素风格，玩法与机制参考《我的世界》；世界必须具备**独立的时间观**与**无限拓展地图**的能力，可以没有剧情。

## 必须满足

- 2D 横版方块世界，可挖掘与放置方块；方块之间有自然拼接的像素边缘。
- 地图可沿水平方向无限扩展：按区块按需生成，远处区块可卸载并在回来时恢复（含改动）。
- 世界拥有独立于现实时钟的时间系统：昼夜循环及其对光照、怪物、玩法的影响；时间推进不依赖帧率。
- 我的世界式机制：采集与工具等级、合成、冶炼、生命与饥饿、敌对生物与夜间刷怪、昼夜与床、种植等至少五项。
- 键盘 + 鼠标可完整操作，提供背包与合成界面，不依赖外部图片资产即可运行。
- 本地存档，刷新页面后可继续游戏。

## 重点评审

1. 无限地图：长距离移动后世界继续生成、无明显卡顿；改动过的区域离开再回来仍保持。
2. 时间观：历法/季节/天气等时间维度是否真实影响世界，且离开的区域是否随世界时间演进（而非冻结）。
3. 泰拉瑞亚画风与我的世界玩法的融合度：光照、背景、像素边缘统一；挖掘—合成—生存循环完整可玩。

## 复核路径

1. 新建世界，砍树 → 合成木板/工作台 → 制作工具，向下挖掘获取石头与矿物。
2. 向任一方向持续移动数百格，观察群系变化与区块生成；回到起点确认改动仍在。
3. 放置熔炉开始冶炼并种下作物后远离（使区块卸载），推进世界时间后返回，检查补算结果。
4. 等待或指令跳至夜晚，观察刷怪与光照；在床上睡觉跳过夜晚。
5. 刷新页面，从世界列表读取存档。
