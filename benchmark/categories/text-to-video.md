# 类别规则:text-to-video — 文生视频

先打[通用六轴](../../shared/rubrics/00-common-six-axis.md),再叠加下列专项。

## 专项维度 · 示例任务 · 常见失败

| 维度 | 示例任务(difficulty) | 常见失败 |
|---|---|---|
| 物理合理性 | L3 倒水 / 球落地弹跳 / 玻璃碎裂 / 布料 | 反物理 |
| 时序一致性 | L2 主体不变形 / 不闪烁 / 不突变 | 漂移、抖动 |
| 运动自然度 | L3 人物行走步态、复杂动作 | 滑步 / 多肢 |
| 镜头控制 | L2 指定推 / 拉 / 摇 / 移 / 环绕 | 无响应 |
| 物体交互 | L3 碰撞、手拿杯子 | 穿模 |
| 稳定时长 | L4 长镜头后段是否崩 | 后段糊化 |
| 音画同步(如含音) | L4 对口型、脚步声 | 不同步 |

## 评分

时序一致性可用相邻帧特征漂移量做客观辅助;物理 / 运动 / 镜头用 0–5 锚定多评委。固定观察时长与截帧点。

## 参数卡要点

固定:seed、分辨率、帧率、时长、宽高比、运镜提示、每题样本数 n。产物(mp4)归档 `benchmark/runs/`。
