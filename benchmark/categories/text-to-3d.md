# 类别规则:text-to-3d — 文 / 图生 3D

先打[通用六轴](../../shared/rubrics/00-common-six-axis.md),再叠加下列专项。输入参考图存 `shared/fixtures/vision/`,产物模型归档 `benchmark/runs/`。

## 专项维度 · 示例任务 · 常见失败

| 维度 | 示例任务(difficulty) | 常见失败 |
|---|---|---|
| 几何质量 | L2 是否 watertight、拓扑合理、对称 | 破面 / 非流形 |
| 多视角一致 | L3 背面 / 侧面合理 | **Janus 多头** / 背面糊 |
| 纹理质量 | L2 UV、PBR、无接缝 | 拉伸 / 接缝 |
| 语义完整 | L3 复杂物体各部件齐全 | 缺部件 |
| 尺度比例 | L2 真实世界比例 | 比例失真 |
| 可用性 | L3 面数适中、可绑骨 / 游戏可用 | 面数爆炸 |
| 图生 3D 保真 | L3 单图 → 3D 与原图一致 | 走形 |

## 评分

几何可用客观指标辅助(是否 watertight、面数、非流形边计数);多视角一致 / 纹理 / 语义用 0–5 锚定,固定观察视角集(正 / 侧 / 背 / 俯)。

## 参数卡要点

固定:输入(文本 or 单图 or 多图)、seed、输出格式(glb/obj)、目标面数档、是否含 PBR 贴图、每题样本数 n。
