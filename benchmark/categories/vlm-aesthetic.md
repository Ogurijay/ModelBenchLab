# 类别规则:vlm-aesthetic — 视觉 / 审美理解(VLM)

测"模型看懂图、并对视觉/审美做出判断"的能力。**审美判断是本类别的重心**。
先打[通用六轴](../../shared/rubrics/00-common-six-axis.md),再叠加下列专项。输入图统一存 `shared/fixtures/vision/`(冻结)。

## 专项维度(各 0–5)

| 维度 | 测什么 | 评分要点 |
|---|---|---|
| 描述精度 | 图像内容识别、主体 / 关系 / 属性 | 关键要素全、无编造 |
| OCR / 文字 | 手写 / 表格 / 多语言 / 低清 | 逐字准确、版式还原 |
| 图表文档理解 | 从图表读数并推断、票据字段提取 | 读对轴 / 值、不编数 |
| 空间关系 | 左右 / 上下 / 前后 / 遮挡 | 方位正确 |
| 计数 | 密集小物体数量 | 计数准确 |
| 细节 / 异常 | 找不同、缺陷 / 异常检测 | 不漏检不误报 |
| **审美判断 ★** | 构图 / 配色 / 光影 / 风格 / 美感 / 情绪 | 见下方审美子表 |
| 视频理解 | 动作识别、时序问答、跨镜头指代 | 时序不乱 |

## 审美判断 ★（重心,子表各 0–5）

| 子项 | 怎么测(任务范式) |
|---|---|
| 美感排序 | 给 N 张图按美感排序,与人类偏好排序算相关性(Spearman) |
| 美感打分 | 给单图 0–10 审美分,与人工均分算 MAE / 相关 |
| 二选一偏好 | 两张对比图选更美的,与人类多数票对齐(pairwise 准确率) |
| 问题定位 | 指出构图 / 配色 / 光影的具体问题,与专家标注对比 |
| 风格识别 | 识别艺术风格 / 流派 / 摄影参数(镜头 / 景深 / 光型) |
| 情绪氛围 | 描述图像传达的情绪,与设定标签一致 |

**方法要点(与本 lab 联动)**:把 `code-to-3d` 各场景的截图作为审美刺激材料,让 VLM 用 [code-to-3d 审美子表](../../shared/rubrics/code-to-3d.md)打分,再与人工审美分对比 —— 这既复用了现有素材,又能反向量化 VLM 的审美判断力。生成类(文生图 / 文生 3D)的产物同样可作刺激材料。

## 示例任务(difficulty)

- **L1** 描述这张图里有哪些物体及其颜色。
- **L2** 这张发票的金额、日期、抬头分别是什么?(OCR + 字段)
- **L2** 杯子在书的左边还是右边?桌上共几个苹果?(空间 + 计数)
- **L3** 从这张折线图读出 2023 Q3 的值,并判断全年趋势。
- **L3** 这两张室内渲染,哪张打光更自然?说明理由。(审美二选一)
- **L4** 把这 6 张海景图按美感从高到低排序,并各指出一个可改进点。(审美排序 + 定位)
- **L4** 找出这两张几乎相同的图之间的 5 处不同。(细节)

## 常见失败模式

只描述不判断 / 审美被"流行 / 高饱和"偏见带偏 / 排序前后不自洽 / OCR 串字漏字 / 计数偏差 / 空间左右混淆 / 图表读错轴或编数。

## 参数卡要点

固定:图片分辨率与压缩、是否允许思维链、温度、单图 vs 多图输入方式、评委与人工标注集。审美类务必多评委 + 记方差(主观性强)。
