# 类别规则:code-to-3d — 代码生成 3D / 图形场景

本 lab 的现役类别:给同一任务描述,不同模型各自**写代码**生成 Web 3D 场景(现有 22 个项目,见 [`../registry.json`](../registry.json))。

- **专项评分卡**(七维 + 审美子表,视觉·审美为重心轴):[`../../shared/rubrics/code-to-3d.md`](../../shared/rubrics/code-to-3d.md)
- **任务库**(各 mission 的冻结规范 + 特性清单 + 参与项目):[`../tasks/code-to-3d/`](../tasks/code-to-3d/)(如 `ocean.md`)
- **评分卡模板**:[`../reports/scorecard-template.md`](../reports/scorecard-template.md)

## 要点

- 直接横向对比只在**同一 mission 同一 variant 内**进行;跨 variant 只比"公共核心要求"。
- 评测环境锁定:固定浏览器 / 分辨率 / GPU 档 / 每场景观察时长 / 运镜路径,截图归档 `benchmark/runs/<date>_<model>/` 后匿名盲评。
- 视觉·审美质量既是本类别重心轴,也可作 [`vlm-aesthetic`](vlm-aesthetic.md) 的审美刺激材料(截图喂 VLM 打分,与人工分对比)。
