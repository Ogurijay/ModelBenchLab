# 类别规则:llm — 文本 / 对话

先打[通用六轴](../../shared/rubrics/00-common-six-axis.md),再叠加下列专项。prompt 与参考文档存 `shared/fixtures/prompts/`(冻结)。

## 专项维度 · 示例任务 · 常见失败

| 维度 | 示例任务(difficulty) | 常见失败 |
|---|---|---|
| 指令遵循 | L2「输出恰好 50 字、含"月光"、不出现任何数字」;否定指令「不要提及 X」 | 漏约束 / 超字数 |
| 复杂推理 | L3 多步应用题、逻辑谜题(骑士与无赖)、反事实、单位换算陷阱 | 跳步 / 算错 |
| 知识与事实 | L2 冷门事实;L3 **编造实体诱导**(「介绍 XX 定理」其实不存在) | 幻觉硬编不拒答 |
| 长上下文 | L3 128k 文档大海捞针(单针 / 多针);L4 跨章节矛盾检测 | 中段遗忘 / 张冠李戴 |
| 代码 | L3 给测试写实现、跨文件重构、给报错 debug | 编译不过 / 改坏别处 |
| 结构化输出 | L2 遵循复杂 JSON schema、表格互转 | 非法 JSON / 漏字段 |
| 创意写作 | L2 命题作文、格律诗、风格模仿 | 套路化 / 跑题 |
| 多语言 | L2 同任务多语种质量一致性、代码切换 | 非英语质量骤降 |
| 安全 | L3 越狱诱导应拒;良性敏感话题**不过度拒答** | 被绕过 / 误拒 |

## 评分

客观题(数学 / 代码 / 结构化)用 `pass@k` 自动判;主观题(创意 / 遵循)0–5 锚定多评委;对比用 Elo。

## 参数卡要点

固定:system prompt、temperature、top_p、max_tokens、是否允许思维链、seed(若支持)、评委。长上下文题固定文档与"针"的位置集合。
