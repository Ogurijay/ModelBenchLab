# 类别规则:text-to-image — 文生图

先打[通用六轴](../../shared/rubrics/00-common-six-axis.md),再叠加下列专项。参考图 / 编辑底图存 `shared/fixtures/vision/`。

## 专项维度 · 示例任务 · 常见失败

| 维度 | 示例任务(difficulty) | 常见失败 |
|---|---|---|
| 属性绑定 | L2「红色立方体在蓝色球**左边**」 | 颜色串位(蓝立方红球) |
| 计数 | L2「恰好五个苹果」 | 多 / 少一个 |
| 空间构图 | L2 上下左右 / 遮挡 / 前后景 | 关系错乱 |
| 文字渲染 | L3 招牌写 "OPEN";中文标语 | 乱码 |
| 手部解剖 | L3 弹钢琴的双手特写 | 六指 / 畸形 |
| 风格·摄影控制 | L2 指定画风 / 镜头 / 景深 / 光型 | 指令不生效 |
| 否定语义 | L3「一个没有任何家具的房间」 | 反而画出家具 |
| 角色一致性 | L4 同一角色多姿势(系列生成) | 换脸 |
| 编辑能力 | L3 局部重绘 / 扩图 | 接缝 / 改动溢出 |

## 评分

语义遵循可拆成"可验证约束"逐条勾选(颜色 / 数量 / 空间 / 文字);美学质量用 0–5 锚定;一致性看同 prompt 多次生成的稳定度。可交给 [VLM 审美评委](vlm-aesthetic.md)辅助打分并与人工对比。

## 参数卡要点

固定:seed、分辨率、宽高比、采样步数、guidance/CFG、负面提示、采样器、每题样本数 n(看稳定性)。
