# 艾泽拉斯 · 无垠之境

独立的 GPT 6.1 SOL 像素沙盒 RPG 原型。Canvas 2D 程序化绘制，无运行时外部图片、字体或网络依赖。

## 运行

根目录执行 `npm run dev`，打开 http://localhost:3000/gpt6.1sol-terraria-infinite/ 。

独立调试：`npm run dev:one -- gpt6.1sol-terraria-infinite`。端口以 registry 为准。

构建：`npm run build -w gpt6.1sol-terraria-infinite`。

模型测试：`npm test -w gpt6.1sol-terraria-infinite`。

共享开发服务器已按项目隔离整页刷新：其他项目生成素材时不会重载本游戏；本项目代码修改和 CSS 热更新仍正常生效。排查证据见 `docs/refresh-fix.md`。

## 已实现

- 8 种族：人类、矮人、暗夜精灵、德莱尼、兽人、巨魔、亡灵、血精灵。种族影响出生群系、阵营、被动属性与四章任务线。
- 6 职业：战士、法师、猎人、圣骑士、萨满、潜行者，每职业四技能，共 24 技能；1/3/6 级解锁、五级技能强化、四条被动专精；真实箭矢/法术弹道、护盾、冲刺、冻结和治疗。
- 发型、发色、肤色、衣装、名字及世界种子定制。
- 32 × 112 格区块，左右按需生成；确定性噪声地形、五群系、洞穴与矿物。远处缓存释放，改动单独保存。
- 161 种物品、129 项配方、11 类制作站；铜 → 铁 → 银 → 金 → 秘银 → 狱岩六级矿石、工具、武器与护甲。
- 前景方块、4 种背景墙、木锤拆墙、多格家具、门、单向平台、绳索、箱子、住房判定与放置预览。
- 八种制作专业：锻造、制皮、裁缝、工程、炼金、木工、烹饪、附魔。熟练度独立保存，学徒 0 / 熟练 40 / 专家 120 / 大师 240；原有配方不新增熟练度门槛。
- 制皮提供远程护甲、箭袋和绷带；裁缝提供法力/施法护甲；工程提供零件、炸弹、勘探目镜和抓钩。材料跨专业流转。
- 重新组织头像、生命/法力、经验/饱食条、昼夜时间盘与四个技能槽；技能槽显示冷却、缺蓝、等级锁与详细提示。
- 小地图/大地图采用视线遮挡的探索迷雾：黑色未探索、暗色记忆、亮色当前视野。已生成区块不会自动开图；负坐标和地下探索记录随存档保存。
- 装备四槽、防御和饰品属性；批量合成、分站制作、冶炼队列、炼金、烹饪、纺织、木工；材料图鉴双向查询配方。
- 24 px 地形纹理、20×42 角色精灵、32×32 物品图标、树冠明暗簇、远景林地、地下光照和火光。素材统一由 `src/assets.js` 生成，清单见 `docs/asset-manifest.json`。
- 种植、饥饿、进食、战斗、睡眠与死亡回营。
- 独立游戏时钟：12 分钟一天，8 天一季；昼夜光照及夜间敌人、天气视觉。作物与熔炉使用绝对世界时间，区块卸载后可补算。
- 联盟/部落军需官、敌对巡逻和营地守军，不同阵营徽记；任务目标、交付奖励与经验。
- 本地自动保存、读取、导入、导出；新建覆盖有提示，导入前下载当前进度备份。
- 只读 `window.__bench.getState()` / `shot()` 供运行核验。

## 边界

单人本地原型，非完整商业游戏。水平世界按需扩展，地下深度固定 112 格；超远坐标受 JavaScript 整数精度与存储容量限制。职业融合、多人生存、完整魔兽剧情、大型副本与动态流体尚未实现。季节影响历法展示，天气影响场景，尚无气温/生态模拟。面板、后台标签页与关闭页面暂停世界时间；并非现实时间离线挂机。技能包括范围判定与真实弹道，敌人仍为简单追踪跳跃；尚未覆盖原作的完整敌怪、Boss、事件、液体、电路、斜坡与数千种道具。视觉为本项目重新绘制的像素素材，未使用原作贴图，也不声称已达到逐像素一致。

本项目沿用 `codeui-terraria-001` 的沙盒任务身份；本轮扩展需求原文在 `docs/request.md`。原测试单元仍为 draft，不声称与基础题面形成公平正式评测。

## 建造验收样板

`node gpt6.1sol-terraria-infinite/scripts/create-demo.mjs` 在根目录执行，生成 `tmp/azeroth-sol-qa/v2-building-demo.json`。在项目 URL 添加 `?qa=1` 可用独立测试存档槽，再通过菜单导入。该样板带预置材料、房屋和设施，用于测试与展示，不代表生存通关。正常游戏地址不共享该存档槽。

v3 保持旧保存键。首次从 v1/v2 升级会备份到原键加 `-backup-v1` / `-backup-v2`；已有 v1 旧备份不删除。已有地形改动、任务、物品、角色和时间可迁移。旧存档从当前位置开始记录探索，不能将历史已生成区块推断为亲自探索。

## 制作专业入口

按 C 打开工匠公会，先选专业，再选分支。制作页会分别列出所需专业阶级、材料和附近设施，支持按成品/材料搜索、仅可制作过滤、批量制作，以及材料图鉴跳转。制皮需鞣皮架，工程需工程台；两者都能通过原有基础制作链获得。新专业从 0 熟练度开始，同一角色可以同时学习全部专业。

新验证见 `docs/verification-v3.md`。本轮进行了模型测试和离屏 Canvas 渲染检查，未进行浏览器交互验收。
