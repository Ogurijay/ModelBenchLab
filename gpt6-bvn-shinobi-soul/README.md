# 火影 VS 死神 · SHINOBI / SOUL

独立 Canvas 2D 同人格斗小游戏。8 名可玩角色：鸣人、佐助、樱、卡卡西、一护、露琪亚、白哉、恋次。美术由代码绘制，音效由 Web Audio 合成，无外部素材或运行时网络请求。是玩法致敬，并非原版游戏移植。

## 运行

仓库根目录 `npm run dev`，访问 http://localhost:3000/gpt6-bvn-shinobi-soul/ 。独立调试端口 3065：`npm run dev:one -- gpt6-bvn-shinobi-soul`。

`npm run build -w gpt6-bvn-shinobi-soul` 生成相对路径生产包。`npm test -w gpt6-bvn-shinobi-soul` 验证战斗规则；根服务运行时执行 `npm run test:browser -w gpt6-bvn-shinobi-soul`。

## 操作

1P：A/D 移动，W 方向变招，S 防御，J 普攻，K 二段跳，L 冲刺/受击替身，U 技能，I 奥义，O 援助。空中受击 K 受身。W+J 挑空；W/S/空中+U 变招；W+I 强化奥义；S+I 满三格气觉醒。

2P：方向键，主键盘数字 1–6 或小键盘 1–6 对应 J/K/L/U/I/O。ESC 暂停。手机提供触屏按键。声音默认关闭，可点击顶栏打开。

普攻四段连击，命中后取消到技能，再接奥义。气通过攻击/受击积累；技能消耗查克拉；援助充能后可使用手里剑、治疗或缚道。连续受击保护、破防、起身无敌、资源约束和冷却由固定 60Hz 模拟处理。

## 模式与内容

- 人机、本地双人、观战：三局两胜，三个电脑难度。
- 闯关：八场连战，末关强化首领，失败可原关续关。
- 团队：选择角色自动搭配同阵营三人，保留获胜者体力的 3v3 接力。
- 生存：连战、胜后恢复 220 体力。
- 训练：无限时间、可切换无限资源、站立/防御/反击木桩、判定框、恢复资源。
- 终结之谷、瀞灵廷、木叶村三个程序化场景。

## 验收边界

`window.__bench.getState()` 提供只读状态，`shot()` 返回截图。登记使用现有 `codeui-bvn-001` draft 任务，未经正式三样本评测。人物是原创矢量风格程序绘制，并非原作逐帧精灵素材；键位固定，尚无自定义键位、联网、手柄与专业音轨。八名角色的技能/奥义、配色、发型、服装和武器各异，基础骨架动画共享。方向分支属于简化格斗规则，不宣称覆盖原 BVN 全部招式。
