# 火影 VS 死神 · SHINOBI / SOUL

以经典网页版《死神 VS 火影》为方向的 Canvas 2D 同人重制。8 名可玩角色：鸣人、佐助、樱、卡卡西、一护、露琪亚、白哉、恋次。2026-10-13 已移除几何人偶，改为 imagegen 生成的动漫肖像、128 格基础动作、32 格九尾/卍解动作、三张像素战场；蓝色街机选人、黄色体力条、三格气槽。素材随项目构建，无运行时外站请求；音效由 Web Audio 合成。不是原版 Flash 移植。

## 运行

仓库根目录 `npm run dev`，访问 http://localhost:3000/gpt6-bvn-shinobi-soul/ 。独立调试端口 3065：`npm run dev:one -- gpt6-bvn-shinobi-soul`。

`npm run build -w gpt6-bvn-shinobi-soul` 生成相对路径生产包。`npm test -w gpt6-bvn-shinobi-soul` 验证战斗规则；根服务运行时执行 `npm run test:browser -w gpt6-bvn-shinobi-soul`。

## 操作

2026-10-13 本轮调整：进入 S 防御时自动面向对手，持续防御锁定方向，保留背后可被命中和硬直限制；训练选项变更后自动把按键焦点交还战斗。人物尺寸缩小 20%，受击框、普通攻击范围与身体间距同步调整，近身镜头最大放大由 1.16 降到 1.04。每个回合结束显示 K.O. / 时间到、胜者肖像、角色名和比分，3.2 秒后衔接下一回合或最终结果；平局使用双人画面。

1P：A/D 移动，W 方向变招，S 防御，J 普攻，K 二段跳，L 冲刺/受击替身，U 技能，I 奥义，O 援助。空中受击 K 受身。W+J 挑空；W/S/空中+U 变招；W+I 强化奥义；S+I 三格最终奥义；J+K 满三格气变身，持续本回合。平台上 S+K 下落。选人界面 WASD/方向键移动，J 确认。

2P：方向键，主键盘数字 1–6 或小键盘 1–6 对应 J/K/L/U/I/O。ESC 暂停。手机提供触屏按键。声音默认开启，首次交互解锁，顶栏可切换并记住偏好。

普攻四段连击，命中后在窗口内取消到技能，再接奥义，打空需等收招。左右输入决定朝向，出招锁定方向；S 只防正面，格挡后有防御硬直。L 替身消耗 35 查克拉；K 受身消耗 15，仅挑空后接近顶点 / 下落的窗口开放，强制倒地除外。气通过攻击/受击积累；援助充能后可使用。连续受击保护、破防、倒地 / 起身、资源与冷却由固定 60Hz 模拟处理。

## 模式与内容

- 人机、本地双人、观战：三局两胜，三个电脑难度。
- 闯关：八场连战，末关强化首领，失败可原关续关。
- 团队：选择角色自动搭配同阵营三人，保留获胜者体力的 3v3 接力。
- 生存：连战、胜后恢复 220 体力。
- 训练：无限时间、可切换无限资源、站立/防御/反击木桩、判定框、恢复资源。
- 终结之谷、瀞灵廷、木叶演习场三个像素场景，带可落脚平台。
