## 方法

1. **底盘先行**：AR / Super-II / Super-1 / FM-A 四种底盘按商品页尺寸（全长、全宽）与套件扫描图建模，轴距 80 mm、轮距 64 mm、13 mm 导轮。导轮螺丝头与轮毂中心是照片里最容易精确点出的硬点。
2. **相机标定**：在照片上点出导轮螺丝与轮毂中心，用针孔相机模型（方位 / 俯仰 / 距离 / 视场 / 滚转 / 主点偏移 7 个自由度）做光束法平差；导轮的 x / y 也作为未知量一起求解（导轮位置随底盘版本不同，不能硬套）。同底盘的多张照片联合求解（三台 Super-II 车一起解），旋风冲锋用两张不同角度照片联合求解。
3. **三角测量**：标定后，用对称点（同一特征左右两侧在一张照片里同时可见）或双视图求三维坐标，得到车身锚点（鼻尖、座舱前尖、轮罩角点、尾翼端点、喷口、头灯等）。每个车型文件开头记录这些锚点。
4. **按锚点放样**：车身由多段截面放样（loft）、带圆角的折线截面和挤出件拼成；左右镜像保证对称。
5. **三向投影涂装**：贴纸在车身坐标系里分别画在俯视 / 侧视 / 前视三张画布上，着色器按表面法线混合投影，因此一条贴纸可以跨越多个零件连续延伸（例如旋风冲锋从鼻尖贯穿到座舱的蓝色 Y 形贴纸）。尾翼单独一层，避免翼面文字印到下方车身上。
6. **迭代比对**：在 `?lab=<车型>&view=ref` 中以标定机位渲染白底图，与照片做三联对照、轮廓描边叠加和剪影异或，逐处修正。

## 逐车状态与已知差异

- **旋风冲锋**：轮廓、前轮罩、座舱、尾翼、贴纸分布与照片一致度最高。后轮罩爪痕形状为近似。
- **飓风音速号**：前轮罩斜眼头灯、D2 前翼、楔形侧舱和鸥翼尾翼已按测量点建出；侧舱三角网格为平面贴片，真实件是凹陷格栅。
- **新三角剑**：参考为灰底旧版照片（长焦，视场约 9°）。三尖头、多面金色座舱、单柱尾翼与侧置后导轮已对齐；鼻部中央的多层折面与 V 形红色饰线做了简化。
- **进化者**：紫壳、银舱、高端板夹黑翼与 Y 辐轮已对上；照片中前轮罩前缘更锐利、带折边，模型为圆鼓近似。
- **极速眼镜蛇**：圆宽车身、椭圆镀铬头灯、银色鳞甲、双鳍翼与刻纹轮胎一致度高；后罩进气口位置按单张照片推定。
- **蜘蛛王**：蛛网格、三层阶梯翼、红底盘白轮胎已还原；网格线条走向为程序生成的近似，不是贴纸逐线复制。
- **巨无霸**：前置马达肋片罩、G 徽标、夹轮护板与管架、蓝色多面座舱已有；车身后段比照片略长偏平，尾部结构按说明书推定。
- **魔鬼司令**：三叉戟车头、红色肋条唇、金色四喷口、分节弯管、单片竖鳍、白色风扇轮一致；虎纹贴纸为近似图案。

共性限制：单张商品照看不到车底与车尾正面，这些面按底盘结构推导；贴纸图案是按位置与配色重绘的近似（不复制贴纸原图）；Premium 版底盘、轮胎颜色可能与动画中的原版不同，本项目以 Premium 套件照片为准（新三角剑为 19409 原版）。

## 复现

```powershell
# 根目录 npm run dev 运行时
node claudeopus5.5-mini4wd-replica/tests/capture.mjs cyclone ref,rear,top   # 单车多机位白底图
node claudeopus5.5-mini4wd-replica/tests/compare.mjs ../tmp/mini4wd-lab/final  # 八车标定机位批量渲染
node claudeopus5.5-mini4wd-replica/tests/fit.mjs <landmarks.json>               # 由地标拟合机位
```

相机拟合与三角测量的 Python 脚本（`cam.py`、`bundle.py`）属于开发期工具，保存在被忽略的 `tmp/mini4wd-lab/`。
