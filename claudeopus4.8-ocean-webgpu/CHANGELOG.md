# 历史改动清单

## 2026-06-27 — 海盗船加阴影/光影（自投影 + 接触阴影）

船之前无投影、显得"贴"在水面上、缺光影。本次：

- 开启 `shadowMap`（PCFSoft），方向光投影 → 船帆/桅杆/船身**互相投影（自投影）**，
  明暗立体；shadow camera 聚焦海盗船，`normalBias` 缓解低多边形的阴影粉刺。
- 船底加**随浪起伏的接触阴影**（`makeShadowBlob`，CanvasTexture 椭圆暗斑）→ 船"坐"进水里。
- 方向光从太阳方向照向船并略增强对比。实测 **165 FPS 不变、0 报错**。

## 2026-06-27 — 渲染器整体改回 WebGL（GLSL）+ 海盗船物理反射 + 修旗杆

应需求把渲染器从 `WebGPURenderer`(TSL) 整体改回 `WebGLRenderer`(GLSL `ShaderMaterial`)：

- **海面/天空着色 TSL → GLSL 重写**：Gerstner 位移、逐像素解析法线、菲涅尔、天空+太阳
  反照、次表面散射、湍流泡沫、距离雾、低频域扭曲、高频微法线全部用 GLSL 实现，视觉与
  原 WebGPU 版一致；波参数走 `vec4[16]` uniform 数组（改风/改向只更新数值）。
- **海盗船物理光线反射**（本次核心诉求）：由天空生成 **PMREM 环境贴图**喂给标准 PBR 材质
  —— 金属炮口/金饰反射天空、木质船身有镜面高光；方向光 + 半球光跟随日照。海面/天空手动
  做 sRGB 编码，与标准材质的船色彩一致。
- **修复海盗旗**：主桅顶加独立旗杆 + 顶端金球，海盗旗紧贴旗杆顶自然飘动（原先旗子直接
  糊在桅顶、顶部显乱）。
- 入口检测改为 WebGL；UI 文案与门户卡片徽章 WebGPU → WebGL。
- 实测全新会话 **165 FPS、0 报错**；风速 11→25 海况 3→5 级联动、浮力随浪、暂停/重生成正常。
- 注：目录名仍为 `claudeopus4.8-ocean-webgpu`（端口/门户/workspace 绑定，未改名；详见 HANDOVER）。

## 2026-06-27 — 修复「海面波浪太规整」

物理化升级时把方向散布收窄、波长改成几何谐波阶梯，导致大浪近乎平行、波峰排成一排排，
观感「太规整」。本次回补不规整性（保留物理风驱与饱和浪高）：

- **波数 10 → 16**，谱更丰富。
- **宽方向散布 + 交叉涌浪**：方向围绕主风向三次方权重宽散布（最大 ~±66°），并有约
  30% 的波跟随一条大夹角的次涌浪向 → 短峰交叉浪，打破平行波峰。
- **对数非谐波波长**：波长按对数分布 + 强抖动跨越 `[主波长, 2.2m]`，取代几何 `0.72ⁱ`
  阶梯，避免谐波规整。
- **低频域扭曲**（`uWarp`）：在波相位前用慢速低频噪声扭曲采样坐标，把残余的笔直波峰
  揉成自然蜿蜒的浪线；位移与着色共用同一扭曲场，保持一致。
- 浏览器实测：默认/和风/风暴各档均为自然短峰不规整海面，0 报错、165 FPS、16 波。

## 2026-06-27 — 物理化海面升级（参考 claudefable5-ocean-realistic 优化）

参考 Fable 5 海洋项目的物理建模思路，对原 WebGPU/TSL 海面做了一次实感与交互升级。
核心架构（TSL 节点 → WGSL，逐像素解析法线，🎲 随机重生成）保持不变。

### 新增 / 改进

- **物理风驱波谱**：波长不再固定，改由「风速」按深水重力波关系 `L ∝ v²/g` 驱动 ——
  风越大，主涌浪越长、整体浪越高（`rebuildWaves()`）。"风速"从原来的「时间倍率」
  变成有物理意义的控制量。
- **波参数移入 `uniformArray`（重大架构优化）**：每个 Gerstner 波打包为两个 `vec4`
  常驻 GPU（`uWaveA/uWaveB`）。改风 / 改向 / 改浪高 / 重新生成，**只更新 uniform 数值，
  绝不重新编译着色器**。原实现把波组烘焙成 TSL 常量，任何改动都要重建材质并重编译 WGSL，
  拖动滑块会卡顿；现在调参全程实时顺滑、零编译开销。
- **陡度预算**：`baseQ = 1 / Σ(k·A)` 使 `Σ baseQ·k·A = 1`，实时 `uChop∈[0,1]` 再缩放，
  从数学上保证 Gerstner 波**永不自交打结**（替换原 `1/(k·N)` 经验系数）。
- **波数 8 → 10**：谱更丰富（长涌浪 + 短碎浪层次更足）。
- **新增控制**：风向（0–360°）、日照方位（0–360°）。原先方位写死在 -34°。
- **蒲福海况读数**：右下 HUD 按风速显示 `级数 · 中文海况`（无风镜面…飓风骇浪）。
- **高频微法线波光**：片元侧叠加 `mx_noise_float` 微法线扰动，制造次像素细碎波光，
  并**随距离淡出**避免远处闪烁噪点。
- **反射压平地平线**：反射射线 `reflDir.y = abs(reflDir.y)`，掠射角不再采样到地平线
  以下的暗区。
- **浪高 / 陡度滑块语义重定义**：浪高 0.2–2.5（整体振幅比例）、陡度 0–1（预算占比）。

### 验证

- `npx vite build` 通过（导入解析、无语法错误）。
- 浏览器实测（Chrome WebGPU，127.0.0.1:3001）：着色器编译运行 **0 报错**，165 FPS，
  顶点 103k；风速 11→27 海况 3 级→5 级实时联动、无重编译卡顿；风向 / 浪高 / 陡度 / 日照
  全部实时生效；最小风速/浪高/陡度=0 边界不崩；🎲 重新生成正常换海。截图见会话记录。
