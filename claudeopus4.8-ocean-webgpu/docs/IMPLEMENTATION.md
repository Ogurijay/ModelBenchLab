# 实现原理

## 核心思路：把海面运算放进 GLSL 着色器

很多海面示例把波形放在 **CPU** 上用 JavaScript 逐顶点循环计算：

```js
// ❌ 常见做法：CPU 逐顶点，主线程每帧遍历几十万顶点
for (let i = 0; i < positions.length; i += 3) {
  positions[i + 1] = sumOfWaves(x, z, t);   // 主线程算
}
geometry.computeVertexNormals();             // 主线程再算一遍法线
positions.needsUpdate = true;                // 每帧重传整个顶点缓冲
```

这种写法有三个瓶颈：① 波形计算占满主线程；② 法线靠 `computeVertexNormals`
全网格重算；③ 每帧把几 MB 顶点数据从 CPU 重新上传到 GPU。顶点数一高就卡。

本项目用 **GLSL `ShaderMaterial`**：位移写进顶点着色器，逐像素法线与海水着色写进片元
着色器，全部在 **GPU** 上执行。CPU 每帧只更新一个时间 `uniform`，顶点缓冲一次上传、永不变动：

```glsl
// ✅ 本项目：顶点着色器算位移（offset = Σ Gerstner 波）
vec3 displaced = base + offset;
gl_Position = projectionMatrix * viewMatrix * vec4(displaced, 1.0);
```

## 1. 物理风驱波谱（`rebuildWaves`）

海面由 **16 个 Gerstner 波**叠加而成。它们不是手工固定的，而是由 `rebuildWaves()`
按**风参数 + 谱**生成——这是让海面看起来「随机、不整齐」又「随风而变」的关键：

- **物理风驱**：主波长由风速按深水重力波关系 `L ∝ v²/g` 决定——风越大，主涌浪
  越长；总振幅随风速增长但**饱和**（充分成长浪不会无限长高）。"风速"由此成为有
  物理意义的控制量，右下角海况读数同步联动。
- **随机相位** `φ₀`：每个波在不同位置起峰。若所有波都在原点同时达到峰值，
  叠加后会出现规则的干涉条纹（「很整齐」）；随机相位彻底打破它。
- **宽方向散布 + 交叉涌浪**（抗规整关键）：各波方向围绕主风向**宽散布**（三次方权重
  向主向集中、保留 ~±66° 斜浪），并有约 30% 跟随一条大夹角的**次涌浪向**——形成
  短峰交叉浪，杜绝「一排排平行波峰」的规整感。
- **对数非谐波谱**：波长按对数分布 + 强抖动跨越 `[主波长, 2.2m]`，避免几何谐波阶梯，
  谱更连续；相对振幅按波长加权，长波高、短波细。
- **深水色散** ω = √(g·k)：短波移动更快，叠加更自然。
- **低频域扭曲**：在波相位前用一层慢速低频噪声扭曲采样坐标，把残余的笔直波峰揉成
  自然蜿蜒的浪线（位移与着色共用同一扭曲场，保持一致）。

用**确定性伪随机**（mulberry32）：同一种子 → 同一片海，可复现。点击
**🎲 重新生成**即换一个种子、**重填波谱数组**，得到一片全新随机海面。

> **关键架构：波参数走 uniform 数组，不烘焙常量。** 每个波打包为两个 `vec4`
> 常驻 GPU（`vec4[16]` uniform 数组）。改风 / 改向 / 改浪高 / 重新生成都**只更新 uniform 数值，
> 不重新编译着色器**——材质只构建一次，调参全程实时顺滑、零编译开销。
> （早期 WebGPU/TSL 实现把波组烘焙成着色器常量，任何改动都要重建材质并重编译。）

Gerstner 波不仅垂直位移，还沿传播方向**横向收拢**，形成尖峰平谷（陡度 `uChop` 控制）：

```
P.x += Σ  Qᵢ·Aᵢ·Dᵢ.x·cos(φᵢ)
P.z += Σ  Qᵢ·Aᵢ·Dᵢ.y·cos(φᵢ)
P.y  = Σ      Aᵢ·sin(φᵢ)
φᵢ = k·(Dᵢ·xz) + ωᵢ·t + φ₀ᵢ          ← φ₀ᵢ 为随机相位
```

横向收拢系数走**陡度预算**：取 `baseQ = 1 / Σ(kᵢ·Aᵢ)`，使 `Σ baseQ·kᵢ·Aᵢ = 1`；
运行期再乘陡度 `uChop∈[0,1]`，故实际 `Σ Q·kᵢ·Aᵢ = uChop ≤ 1`——从数学上保证
Gerstner 波永不自交打结。波参数写入 uniform 数组，全局量（陡度 / 海沫 / 太阳方向）
也是运行期可调的 `uniform`。

## 2. 解析 Gerstner 法线（片元着色器）

没有用 `computeVertexNormals`，而是在**片元着色器里**用 Gerstner 法线公式
（GPU Gems）**解析**求法线——与位移在同一次循环里算出，无需多次采样：

```
N = normalize( vec3( −Σ Dx·k·A·cos φ,  1 − Σ Q·k·A·sin φ,  −Σ Dz·k·A·cos φ ) )
```

因为是**逐像素**求值且包含全部谱波（含最短的波），水面高光与反射细节比逐顶点
插值的法线锐利得多——即便网格三角形较大，也能看到细密波纹。

## 3. 海水着色（片元着色器）

最终颜色由若干项合成：

- **水体色**：按高度在深水蓝（`#01080f` 附近）与浅水青之间过渡。
- **菲涅尔反射**：Schlick 近似 `F = (1−N·V)⁵`，掠射角反射更强。
- **天空 / 太阳反照**：沿反射方向 `reflect(-V, N)` 采样**与天空穹顶共用**的
  `skyColorFn`。因为天空里画了太阳本体与大气辉光，反射回来便是物理一致的
  **太阳波光**——低日照角度时在水面拉出长长的闪烁光带。
- **次表面散射**：迎着太阳的浪尖叠加青绿，模拟阳光穿透薄浪。
- **湍流海沫**：先由浪尖高度 + 陡坡判断「哪里可能起沫」，再乘以一层**随时间流动的
  噪声场**（GLSL 值噪声）过阈值，把泡沫切成**不规则斑块**而非沿波峰成排；
  叠加高频细沫噪声做出颗粒感。这样泡沫看起来是自然散布的，没有人工排布痕迹。
- **距离雾**：远处按距离平滑融入地平线天空色。

天空穹顶与海面反射复用同一个 `skyColorFn(dir)`，保证「水里的太阳」和
「天上的太阳」永远一致——这是太阳波光看起来真实的关键。

## 4. 暂停与时间

为了能暂停，用一个自管理的 `uTime` uniform：
动画循环里 `uTime.value += delta`，暂停时停止累加。波形与噪声都引用 `uTime`，
于是暂停时画面凝固、参数仍可调。

## 5. 降级处理

入口先检测 WebGL2；不支持时显示友好提示卡片而非白屏。
`startOcean()` 整体包在 `try/catch` 里，初始化异常也会被捕获并提示。
（注意：GLSL 编译错误只在运行时发生，`vite build` 抓不到 —— 改完务必浏览器实跑。）

## 6. 海盗船（Blender 建模 + 浮力随浪起伏）

海面上漂着一艘**自建**的三桅海盗大帆船，资源全部存在 `assets/`（脚本 + GLB + .blend）。

- **建模**：`build_pirate_ship.py` 用 Blender 程序化生成——船体用「纵向断面放样」（每个
  断面一条 U 形弧、首尖尾方、舷弧起伏），再加甲板、舷墙、三桅 + 鼓风方帆、艏斜桅 + 三角帆、
  艉楼/艏楼舱室、海盗旗、两舷火炮。后台导出自包含 GLB：
  `blender --background --python build_pirate_ship.py`。
- **加载与光照**：`GLTFLoader` 加载 GLB（Vite `?url` 导入）。场景新增一盏**方向光**（方向与
  强度跟随日照控制）和一盏**半球光**——只用来照亮标准材质的船；海面/天空是无光照
  `NodeMaterial`，完全不受影响。
- **浮力**：船要真正浮在浪上，就得在 CPU 复算波高。`sampleWaveY()` 用与着色器**同一套
  uniform 波组**累加 Gerstner 垂直位移 `Σ Aᵢ·sin(k·dot(dir,p) + ωt + φ)`（忽略低频域扭曲，
  对浮沉无可见影响）。每帧在**船首/尾/左/右四点**采样：四点均值定船的浮沉高度，四点高差
  经叉积构造出船体坐标系（沿船长向量 × 沿船宽向量 → 法线）→ 船随浪起伏、纵摇横摇。
  采样用的时间就是 `uTime.value`，于是**暂停时船与浪一起凝固**。

## 性能

| 项 | 值 |
| --- | --- |
| 网格 | 900×900，320×320 分段（≈ 103k 顶点） |
| 波数 | 16 个 Gerstner 波（物理风驱谱 + 域扭曲），逐像素解析法线一次求值 |
| 波形 / 法线 / 着色 | 全部 GPU（GLSL ShaderMaterial） |
| CPU 每帧开销 | 仅更新 1 个时间 uniform + OrbitControls（调参时另写少量 uniform 数组，无重编译） |

> **波数 vs 帧率**：片元侧逐像素求解 Gerstner 法线 + 微法线噪声，开销随波数线性增长。
> 16 波在主流独显上可轻松跑满 60 FPS（实测 165 FPS）；若在集显/共享 GPU 上偏卡，
> 可调小 `main.js` 顶部的 `N_WAVES`（如 12），或降低画布像素比。

> **实时调参零编译**：波参数走 `vec4[16]` uniform 数组，改风 / 改向 / 改浪高 / 🎲 重新生成
> 都只更新 uniform 数值，材质只构建一次，不重新编译着色器。
