# 🌊 WebGL Ocean · GPU 实时海面模拟 + 海盗船

基于 **Three.js `WebGLRenderer` + GLSL `ShaderMaterial`** 的实时海面模拟。
与「在 CPU 上逐顶点 `for` 循环算波形」的常见做法不同，本项目把 **波形位移、逐像素
解析法线、海水着色全部写进 GLSL 着色器**，在 **GPU** 上运行——10 万顶点的网格稳定
跑满 60 FPS（实测 165 FPS）。海面上还漂着一艘自建的三桅海盗船，随浪起伏。

> 运行 `npm run dev` 后即可在浏览器中看到实时海面：低角度阳光在浪尖拉出闪烁的波光带，
> 浪尖泛起白沫，海盗船在涌浪上纵摇横摇、船身映着天光，远处海面融入地平线。

## ✨ 特性

| 能力 | 实现位置 | 说明 |
| --- | --- | --- |
| **物理风驱波谱** | `rebuildWaves()` | 16 个 Gerstner 波，主波长由风速按深水重力波 `L ∝ v²/g` 决定（风大浪长浪高），**随机相位 + 宽方向散布 + 交叉涌浪 + 对数谱分布**，色散 ω=√(g·k) |
| **抗规整：宽散布 + 域扭曲** | `rebuildWaves` / 着色 | 方向宽散布(±66°)＋次涌浪交叉、波长对数非谐波分布、低频域扭曲揉弯波峰 → 短峰不规整海面，杜绝“一排排平行波” |
| **波参数走 uniform 数组** | `vec4[16]` uniform | 改风/改向/改浪高/重生成**只更新数值，不重编译着色器** → 调参全程实时顺滑、零卡顿 |
| **陡度预算** | JS + 顶点 | `Σ baseQ·k·A = 1`，实时陡度再缩放，数学上保证 Gerstner 波永不自交 |
| 🎲 一键重新生成 | 重填波谱 | 带种子的伪随机，确定可复现；点击即换一片全新随机海面（无重编译） |
| 逐像素解析法线 | 片元着色器 | Gerstner 导数公式一次求法线，逐像素，含全部谱波，细节锐利 |
| **高频微法线波光** | 片元 | GLSL 值噪声微法线扰动，制造次像素细碎波光，随距离淡出抗闪烁 |
| 菲涅尔反射 | 片元 | Schlick 近似，掠射角更亮；反射射线压平地平线 |
| 天空 + 太阳镜面反照 | 片元 | 沿反射方向采样同一套天空函数，物理一致的「太阳波光」 |
| 次表面散射近似 | 片元 | 迎光浪尖透出青绿 |
| 湍流海沫 | 片元 | 浪尖挤压量/高度/陡坡决定起沫位置，流动噪声切成**不规则斑块** |
| 距离雾 | 片元 | 远处融入地平线天空色 |
| **蒲福海况读数** | HUD | 按风速实时显示海况等级（无风镜面 … 飓风骇浪） |
| 🏴‍☠️ **自建海盗船 + 浮力** | Blender + `GLTFLoader` | Blender 程序化建模的三桅大帆船（GLB），CPU 复算 Gerstner 在船体四点采样 → 随浪自然起伏、纵摇横摇 |
| 🌅 **海盗船物理光照反射** | PMREM + PBR | 由天空生成环境贴图喂给标准材质，金属炮口/金饰反射天空、船身镜面高光；方向光 + 半球光跟随日照 |
| 实时参数 | uniform | 风速 / 风向 / 浪高 / 陡度 / 海沫 / 日照高度 / 日照方位，全部即时生效 |

## 🚀 运行

```bash
npm install
npm run dev      # 开发服务器
npm run build    # 生产构建到 dist/
npm run preview  # 预览构建产物
```

打开终端提示的地址（默认 `http://127.0.0.1:5173`）。

> **需要 WebGL2 浏览器**（几乎所有现代浏览器都支持，建议开启「硬件加速」）。
> 若浏览器不支持 WebGL，页面会显示友好的降级提示，不会白屏。

## 🎛️ 操作

- **拖拽**：旋转视角
- **滚轮**：缩放
- **右上面板**：调节风速、风向、浪高、陡度、海沫、日照高度、日照方位；暂停 / 重置视角。
  风速会按物理改变波谱（风大浪长浪高），右下角海况读数随之联动
- **🎲 重新生成随机波浪**：换一套随机波谱，得到一片全新的海面

## 🛠️ 技术栈

- [three.js](https://threejs.org/) `0.184` — `WebGLRenderer` + GLSL `ShaderMaterial`；`GLTFLoader`、`PMREMGenerator`
- [Blender](https://www.blender.org/) — 程序化建模海盗船（脚本与产物见 `assets/`）
- [Vite](https://vitejs.dev/) — 构建与开发服务器

详细原理见 [docs/IMPLEMENTATION.md](docs/IMPLEMENTATION.md)。
