# GPT 5.6 SOL Ocean 风暴与降雨扩展设计

日期：2026-07-10
状态：用户已选择独立叠加方案并授权直接实施

## 1. 目标

为现有 `gpt5.6sol-ocean` 增加一个独立“风暴”开关。风暴不替换正午、晨光、阴天三套基础光照，而是作为天气层叠加在任意基础预设上。开启后，海浪、天空、雾、色调和 GPU 暴雨在约 2.4 秒内逐步增强；关闭后平滑恢复当前基础预设。

成功标准：

- 三套基础光照仍可单独切换，风暴状态不会被基础预设切换重置。
- 风暴开启后可明显观察到更高的波浪、更多泡沫、压低的云层、降低的能见度和连续暴雨。
- 风暴关闭后环境与海面连续恢复，不跳色、不突然清空雨滴。
- 桌面与移动端均可运行；移动端使用较少雨滴。
- 控制台无错误或警告，原有测试、构建和仓库接线不回归。

## 2. 交互设计

- 在现有底部控制条中加入第 4 个“风暴”按钮。
- 前三个按钮仍是互斥的基础预设；风暴按钮是独立 `aria-pressed` 状态，可与其中任意一个同时保持选中。
- 鼠标点击风暴按钮或按 `S` 键切换风暴。
- 开启风暴时，左上角海况文字追加“风暴叠加”；关闭后恢复基础预设名称。
- 不新增单独雨量滑杆或第二个降雨开关，保持操作简单。

## 4. 风暴状态与数据流

`storm.js` 提供不可变状态：

- `createStormState()`：初始关闭，强度为 0。
- `setStormEnabled(state, enabled, duration)`：设置目标状态，默认过渡 2.4 秒。
- `stepStormState(state, deltaSeconds)`：使用平滑曲线推进强度。
- `applyStormOverlay(environment, intensity)`：基于当前基础环境生成风暴环境，不修改输入对象。

每帧数据流：

```text
基础光照预设插值
  → 风暴强度插值
  → 风暴环境叠加
  → 天空 / 海面 / 雾 / 曝光
  → 雨场强度与风向
  → WebGL 输出
```

基础预设与风暴状态相互独立，因此用户可以在风暴中从正午切换到晨光，风暴仍保持开启并平滑跟随新的基础色调。

## 5. 海面响应

- 海面 ShaderMaterial 新增 `uStormIntensity`。
- 垂直波浪振幅从 1.0 平滑增加到 1.24；水平 Gerstner 位移同步降低补偿，确保总陡峭度仍处于安全范围，避免波面自交。
- 片元着色器提高微法线扰动、浪尖泡沫和远处雾化，并轻微压低饱和度。
- CPU `sampleWaveSurface` 新增 `amplitudeScale` 参数，与 GPU 使用相同倍率，保证相机防穿水逻辑仍正确。

## 6. 天空与环境响应

`applyStormOverlay` 随强度执行以下插值：

- 天顶与地平线转为深蓝灰，云色变暗，云量接近 0.96。
- 太阳强度显著降低，曝光下降，雾密度增加。
- 深水与浅水颜色变冷，泡沫转为偏灰白，粗糙度上升。

本次不实现闪电、雷声音频或龙卷风，避免将范围扩展成完整极端天气系统。

## 7. GPU 暴雨

`rain.js` 使用一个随相机移动的 `THREE.Points` 雨场：

- 固定随机种子生成雨滴位置、长度、速度和相位，保证复现。
- 桌面高质量约 12,000 滴，移动端约 5,000 滴。
- 顶点着色器按时间循环雨滴高度，并根据风向产生水平偏移。
- 片元着色器在点精灵中绘制倾斜、柔边的细长雨线。
- `uIntensity` 控制透明度与可见数量；关闭风暴时雨滴连续淡出，而不是瞬间销毁。
- 雨场中心跟随相机 XZ 位置，始终覆盖当前观察范围。

雨场只有一个 Geometry 与一个 Material，不为每滴雨创建对象，避免大量 draw call（绘制调用）。

## 8. 性能与降级

- 桌面雨滴数 12,000，移动端 5,000。
- 雨滴只使用一个 Points draw call，关闭且强度归零后将对象设为不可见。
- 沿用现有自适应像素比策略，不在运行中重建海面几何或雨滴布局。
- 风暴过渡期间只更新 uniform（着色器参数）和少量环境数值。

## 9. 诊断与错误处理

`window.__ocean` 新增：

- `stormEnabled`
- `stormIntensity`
- `rainDrops`

雨场创建失败时由现有统一错误面板接管。页面销毁时必须释放雨场 Geometry 与 Material，并注销风暴按钮事件。

## 10. 测试与验收

单元测试：

- 风暴状态可平滑开启、关闭，端点精确且不突变。
- 环境叠加不修改基础预设，颜色和数值均保持有限。
- 雨滴布局在相同种子下完全一致，桌面/移动数量正确。
- CPU 海面采样的 `amplitudeScale` 与风暴倍率一致。
- 页面仍只有三个基础预设按钮，并新增一个独立风暴按钮。

浏览器验证：

- 在正午、晨光、阴天任意模式下均可开启风暴。
- 风暴按钮、`S` 键、诊断对象和雨场可见性一致。
- 风暴开启 2.4 秒后强度为 1，关闭 2.4 秒后为 0。
- 桌面与 390×844 移动视口无布局溢出。
- 控制台无错误或警告，保存桌面和移动风暴截图。
