本轮针对实际游玩反馈“方向相反、操作不流畅、漂移没有动画”修改。车辆前方是局部 +Z，追尾镜头朝 +Z 看，因此玩家右侧对应局部 -X；原先把正转向直接加到 yaw，导致 D/右键实际左转。现在输入统一为正值右转、负值左转，车头角、前轮、方向辅助、AI轮组和弯道提示遵循相同约定。

| 部分 | 当前行为 |
| --- | --- |
| 转向 | 普通输入指数响应，反打更快；保持原有各车性能参数 |
| 辅助 | 玩家操作时让出控制；松手后延迟300ms，按漂移角和时间渐入 |

| 画面 | 120Hz物理之间插值位置、速度和最短路径角度，镜头位置/朝向/视野平滑跟随速度方向，保留可见车身甩尾 |
| 车辆 | 前轮正确转向/反打，轮胎继续自转；车身随横向/纵向加速度侧倾和俯仰，漂移中有轻微震动 |
| 轮胎烟 | 两个后轮发射，向上扩散并淡出；160粒子池，单次Points绘制 |
| 胎痕 | 两条轮胎宽度的地面带，随实际轮位写入；640段循环池，10–16秒渐隐，单次Mesh绘制 |
| 音效 | 开启声音后有随漂移强度变化的合成轮胎摩擦声；暂停和情感段淡出 |

烟雾与胎痕采用r185 ShaderMaterial及动态BufferAttribute；颜色由Three.js Color转为线性空间再输出，不会把浅灰误当成黑色胎痕。比赛切换清空轨迹和上一帧姿态；对视、情感段隐藏烟雾/胎痕/玩家光轨，暂停冻结效果时间。重试清空上一场弹幕。

普通入口的只读 `window.__bench.getState().visual` 包含烟雾/胎痕数量、前轮角、车身侧倾、车头在屏幕中的朝向与场景绘制次数；它不提供正常入口的作弊控制。`?bench=1`保留内部QA的章节启动和固定步长推进。

## 复跑与操作

设置 `BENCH_PLAYWRIGHT_MODULE` 为本机已安装Playwright路径。用 `node gpt6.1sol-initiald-story-racing/tests/handling-smoke.mjs` 复跑操控；`BENCH_URL`可指向源码或dist入口，`BENCH_QA_LABEL`分别使用source/production。3000端口当前监听localhost；不要假设127.0.0.1可连接。

玩家操作：W/↑加速到约60–90km/h，在入弯时按A/←或D/→并短按空格；形成甩尾后松开空格，短按反方向稳住，再恢复油门。长按转向和手刹能继续甩尾，急弯仍需提前减速。方向辅助可在自由赛关闭，第11章维持无辅助技术赛。

本轮改善输入、镜头和反馈；具体漂移手感、FC难度与真实手机性能仍以玩家游玩为准。没有正式模型评分或公开发布。
