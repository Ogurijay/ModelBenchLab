# 地图修复 · 2026-10-03

针对游玩反馈“地图bug还有非常多”重新检查并调整本实现的共享山路线。它仍是动画风格的原创赛道，不是实测秋名山地形；四种配置共享线路，坡度、抓地和终章直道不同。

## 查到的问题与修复

| 问题 | 处理 |
| --- | --- |
| 两段非相邻路中心在平面上仅相距约1.23m，高程却相差约8m | 重排回头弯，不再以道路交叉模拟上下层；非相邻路中心最小间隔约49m |
| 24m宽的旧路基在急弯内侧翻折，缺乏连续地形 | 路肩收窄到距路中心9m，连接到12m网格的真实地形；曲率最大约0.070/m，路肩不翻折 |
| 89棵树挤进其他路段附近，5座装饰山体占用道路范围 | 按整条道路而非单个生成点检查净空；740棵树扎在实际地面，14座山体移至远处 |
| 护栏画在约7.9m处，碰撞却从中心偏移6.1m触发 | 可见护栏统一为7.7m；碰撞使用各车宽、长、甩尾角与曲率，车身达到护栏时才处理 |
| 擦墙每个物理步都大量减速，容易卡在边缘 | 首次冲击与持续接触分开；保留沿路速度、反射向外分量，并在撞击转动车身后再次计算包络 |
| 高程和进度按采样点跳变，最近路段查询可能跳到其他道路 | 连续插值距离/高度/切线；物理查询限定当前段附近，地形/植被查询用全路空间索引 |
| 小地图长宽分别缩放、左右镜像、没有终点/车头指向 | 单一比例投影，统一追尾镜头左右，增加起终点和朝向箭头 |
| 终点之后道路马上消失、坡道上的车辆和镜头不贴地 | 终点后增加160m缓冲；车辆随坡度俯仰，镜头保持地形上方 |

下坡/上坡/雨夜赛程约2,140.89m，终章国道约2,700.89m。山路段约1,860.89m，后接280m或840m直道。旧个人成绩保留原键，新赛道成绩使用`car:track:v2:mode`；主线、解锁与另一模型存档不受影响。
