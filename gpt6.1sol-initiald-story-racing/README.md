# 秋名山 · 再快的86

GPT 6.1 SOL 的独立剧情赛车首版，基于用户2026-10-01题面。只供本地与朋友游玩，没有发布或部署。共享任务 `code3d-initiald-001` v1，其他模型实现与本项目源码、存档隔离。

入口：**http://localhost:3000/gpt6.1sol-initiald-story-racing/**。仓库根目录运行 `npm run dev`；独立调试：`npm run dev:one -- gpt6.1sol-initiald-story-racing`（登记端口3054）。构建：`npm run build --workspace gpt6.1sol-initiald-story-racing`；物理与剧情契约检查：`npm test --workspace gpt6.1sol-initiald-story-racing`。

W/↑油门，S/↓刹车，A/←左转，D/→右转，空格手刹，P/Esc暂停，R重试。手机有油门、刹车、左右、手刹触控。声音默认关闭，可在首页开启。约60–90km/h入弯时转向并短按空格；形成甩尾后松开空格，短按反方向稳住。急弯需提前减速。方向辅助在玩家转向/漂移时退出，松手后平滑恢复，自由赛可关闭；第11章FC技术赛关闭辅助，需要自己选线与刹车。

首页可选正式主线、漂移练习、章节试驾、自由赛与车库。章节试驾不记录主线成绩或解锁。主线依序推进，普通比赛失败须重试；第3章AE85败局、第9章爆缸、终章奔驰是剧情败局，可推进。EVO III和奔驰按完成章节解锁。新游戏仅重置此实现的localStorage键。

首版包括：14段JSON式剧情数据、120Hz街机漂移、水杯、排水渠、八车型程序化模型、四条赛道配置、五赛制（8车混战）、两种奔驰彩蛋对决、宏光被动/乘客加成、五菱贴标概率加成、518仪表故障彩蛋、章节解锁与成绩存档、事件弹幕、漫画对视与奔驰直道离去、原创合成比赛音乐及环境声音。

美术为程序化低多边形车、三阶卡通材质、边线、程序化天空与SVG立绘/关键分格。**尚未达到精绘PNG、演员辨识度、专业原创Eurobeat成曲与完整postprocessing效果的目标**。四赛道复用同一山路曲线：上坡改变坡度、雨夜改变抓地、国道用于终章直道；不是四套独立实测地形。手感与情绪仍需你和朋友实际游玩评价。
