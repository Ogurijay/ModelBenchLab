# Doubao 2.1 WebGPU Ocean

一个基于 `WebGPU`（浏览器现代 GPU 图形接口）和 `Three.js`（三维渲染库）的实时海面模拟示例。

## 运行

```bash
npm install
npm run dev
```

## 入口

- 示例目录：`doubao2.1-ocean-webgpu`
- 实现说明：`doubao2.1-ocean-webgpu`
- 主代码：`doubao2.1-ocean-webgpu`

## 浏览器要求

需要支持 WebGPU 的浏览器。推荐新版 Chrome 或 Edge，并开启硬件加速。
