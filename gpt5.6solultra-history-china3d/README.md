# 华夏时空沙盘

`gpt5.6solultra-history-china3d` 是一个以中国为核心的 Web 3D 历史地理演变沙盘。它从前 770 年“春秋初期·周室东迁”延伸至 2025 年“现代中国·城市群时代”，可在全国势力版图、代表城市 3D 和世界粗粒度区域之间切换，并通过时间轴观察整体或局部演变。

## 这是什么

项目采用“**12 个历史关键帧 + 程序化推演**”：

- 关键帧负责锚定主要政权、代表城市、时代建筑和重大事件；
- 关键帧之间通过连续动画表达演变趋势；
- 城市细节按固定 seed（随机种子）程序化生成，保证逻辑一致和结果可复现；
- 中国以外地区只展示粗粒度势力版图与大事件，不逐城建模。

它不是逐年 GIS（地理信息系统）数据库，也不是考古或法定边界复原。时间轴落在两个关键帧之间时，画面表达的是“程序化推演”，不是该年份的精确历史断面。

## 三类证据标签

界面中的历史内容必须归入以下三类：

- **史实概括**：根据主流史学共识整理，并为全国尺度做过简化。
- **推定复原**：史料不足或形态存在争议时，为构成连续场景作出的合理推断。
- **程序化生成**：由固定 seed 按时代、地形、气候和城市等级生成的道路、建筑、植被或过渡态。

标签说明和数据处理原则见 [`docs/DATA_PROVENANCE.md`](docs/DATA_PROVENANCE.md)。

## 体验目标

- 全国视角：缩放、旋转并查看各势力颜色、边界、名称和图例。
- 城市视角：进入数据集中任一代表城市，查看地形、水系、道路和时代建筑群。
- 时间轴：选择关键帧、完整播放，或选定起止年份做局部播放。
- 世界视角：查看同期中国以外主要区域势力和重大事件。
- 可信度：在城市、势力、建筑和事件详情中查看证据标签。
- 可复现：相同关键帧和 seed 得到相同程序化细节。

全国尺度使用 LOD（Level of Detail，细节层级）控制性能：远处城市显示简化轮廓，进入城市后才展示完整建筑。所谓“每个城市完整 3D”指当前数据集收录的每座代表城市都有可进入的三维场景，不代表穷举历史上所有聚落。

## 启动

推荐从仓库根目录启动统一门户：

```powershell
npm install
npm run dev
```

访问：

`http://localhost:3000/gpt5.6solultra-history-china3d/`

单项目调试：

```powershell
npm run dev:one -- gpt5.6solultra-history-china3d
```

独立调试端口为 `3043`。

## 测试与构建

## 已知边界

- 只有 12 个关键帧具有明确的数据锚点，帧间不是逐年史实。
- 疆域边界是适合交互沙盘的概括图形，不是测绘级或法定边界。
- 建筑表达时代类型与城市气质，不复原单栋历史建筑的精确尺寸。
- 城市集合是具有代表性的样本，不等于历代全部城市清单。
- 世界层用于交代同期格局和事件，精度低于中国层。
- 2025 现代帧仅作演变叙事，不用于现实行政、外交、法律或导航判断。
