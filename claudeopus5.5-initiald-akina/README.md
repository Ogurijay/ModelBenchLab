# 头文字D · 秋名山 — 再快的86（Claude Opus 5.5）

以 2005 年电影《头文字D》为原型的剧情驱动网页赛车：拓海一路赢到秋名山车神，最后输给一辆根本不在比赛的奔驰。
自己和朋友玩的同人作品，不公开发布；角色用演员小名，车型用真实名称。

任务：`code3d-initiald-001` v1（mission `initiald`），题面见 [`benchmark/tasks/code-to-3d/initiald.md`](../benchmark/tasks/code-to-3d/initiald.md)。

## 内容

- **剧情模式**：序章 + 第 1–11 章 + 终章 + 尾声，共 14 段（JSON 脚本驱动，视觉小说立绘 + 竖排章节卡）。
  第 3 章（阿木的 AE85）、第 9 章（最后一弯爆缸）、终章（奔驰）为注定失败；其余比赛必须真实赢下，输了重试。
- **漂移**：自写街机模型，车头朝向与速度方向分开积分，夹角即漂移角；手刹 / 重心转移 / 重刹打舵降低后轮抓地，
  往里打加角、反打收角、松油门收角，回正后抓地逐渐恢复；完美漂移触发 0.5 秒慢镜头、音效与震屏。
- **水杯**：加速度驱动的弱阻尼液面，横向猛甩和急刹才洒，洒光失败。
- **排水渠**：发夹弯内侧的沟，第 6 章解锁；贴内侧、车身摆正、速度合适才能卡进去不减速过弯。
- **弹幕**：事件触发梗池；情感时刻立即清空并静默（弹幕的有无就是情绪开关）。
- **终章**：奔驰沿固定速度剖面行驶、不读取玩家；最后发夹弯触发并排慢镜头与漫画对视；出山后路变直，奔驰远去；
  86 停路边，沉默很久后弹幕从一条到刷屏，化为标题卡。
- **自由赛**：8 车车库（剧情解锁）、4 条赛道、5 种赛制（单挑 / 追逐 / 计时 / 豆腐挑战 / 神车混战）、
  五菱宏光（遇强则强、七座乘客、后备箱豆腐、518km/h 彩蛋、专属弹幕）、五菱护身符贴纸、两种奔驰彩蛋对决。

## 操作

| 键 | 作用 |
|---|---|
| ← → / A D | 转向 |
| ↑ / W | 油门 |
| ↓ / S | 刹车（停稳后倒车） |
| 空格 | 手刹（甩尾起漂） |
| R | 复位到赛道中心（剧情专用比赛除外） |
| Esc | 暂停（失焦自动暂停并释放按键） |
| 空格 / 回车 / 点击 | 推进对话 |

手柄：左摇杆转向、RT 油门、LT 刹车、A/X 手刹。触屏设备显示屏幕按钮。设置里可关闭弹幕或漂移辅助。

## 技术

Three.js 0.185 + postprocessing 6.39（泛光、径向模糊、去饱和、胶片颗粒、暗角）+ Vite。
不加载任何外部图片、模型、字体或音频：车模、赛道、天空远景、立绘、剧情背景、音乐与音效全部程序化生成。

```bash
npm test         # Vitest：跨帧率回放、漂移、排水渠、水杯、奔驰、剧情胜负等 25 项
npm run build    # 生产构建
```

测试接口：页面暴露 `window.__bench`（`state()`、`story(id)`、`free(cfg)`、`autopilot()`、`step(n, input)`、`fast()` 等），
用于无头浏览器确定性驱动。验收截图在 [`docs/qa/`](docs/qa/)。
