# 像素人生 · 绿钻镇物语(Claude Opus 5.5)

复刻 GBA 掌机版《模拟人生》(Bustin' Out / Urbz 那一代)的玩法结构:俯视像素小镇里自由走动,
照顾八项需求,靠打工小游戏赚钱、和镇民社交、练技能、买家具,按章节目标推进,最终买下湖景别墅。
人物、地名与文本均为原创。**画面、字形、音乐、音效全部由代码生成,零外部资产。**

## 运行

- 常规:仓库根目录 `npm run dev`,访问 `http://localhost:3000/claudeopus5.5-life-gba/`
- 单独调试:根目录 `npm run dev:one -- claudeopus5.5-life-gba`(端口 3060)
- 构建:本目录 `npm run build`(使用根目录 vite)

## 操作

| GBA 按键 | 键盘 | 作用 |
|---|---|---|
| 方向键 | 方向键 / WASD | 走动;菜单移动 |
| A | Z / J / 空格,或点击画面 | 互动、确认、推进对话 |
| B | X / K / Esc | 取消、中断行动;走路时按住 = 跑步 |
| START | 回车 | 状态菜单(需求/技能/关系/职业/目标/背包/系统) |
| SELECT | Shift / Tab | 需求速览开关 |
| L / R | Q / E | 状态菜单切换标签 |
| — | M | 静音 |

屏上掌机按键支持鼠标与触屏(D-pad 支持按住滑动换方向);窄屏/竖屏时屏幕在上、按键在下。

## 玩法要点

- **240×160 内部分辨率**,整数倍最近邻放大;GBA 15 位色感调色板、精灵 1px 描边、中文为系统 12px 字体阈值化成硬边像素字。
- **地图**:小镇(44×34 格,住宅区/商业街/工业区/公园湖泊)+ 自家小屋、咖啡馆、家具店、健身房、修车厂;门口进出,商店有营业时间。
- **八项需求**:饥饿、舒适、卫生、膀胱、精力、娱乐、社交、环境;加权得心情,头顶绿钻绿→黄→橙→红;需求过低头顶冒想法泡泡。
- **需求崩溃**:膀胱见底当场尿裤子(留下水洼、周围镇民反感)、精力见底累晕在地、饥饿见底被送诊所扣钱。
- **交互**:走到物件前按 A 弹出菜单,选中后角色自动寻路到使用位执行;行动期间时间加速,睡觉大幅快进。约 30 种物件行为:做饭(新手会着火)→上桌吃→脏盘子影响环境、叫披萨、看电视(旧电视会坏,可自修或叫修理工)、读书、对镜练演讲、电脑接单、画画卖钱、钓鱼卖鱼、许愿喷泉、下棋等。
- **镇民**:7 位,按小时日程在各场景间走动;9 种社交(聊天/笑话/夸赞/拥抱/调情/亲吻/送礼/恶作剧/打听),成功率取决于关系、喜好、魅力、心情与卫生;调情产生好感,亲吻可确立恋人。
- **技能**:烹饪、机械、魅力、体魄、逻辑、创意,各 5 级;心情差学得慢。
- **职业**:咖啡馆(点单配餐小游戏)与修车厂(时机拧螺丝小游戏),每班 4 小时;表现分决定工资与绩效,绩效满 + 技能达标升职,各 5 级。
- **经济**:家具店 12 件商品(升级替换或新增摆件,影响需求恢复与环境);每三天寄账单,逾期先自动扣款,不够则收债员搬走最贵的家具。
- **章节目标**:四章共 15 个目标,完成发奖励;第四章买下别墅地契进入结局,之后可继续自由生活。
- **存档**:localStorage,每游戏整点自动保存,标题页「继续生活」。

## 结构

```
index.html          GBA 外壳 + 画布
src/style.css       外壳样式与窄屏布局
src/gfx.js          画布、调色板、点阵数字字体、中文字形二值化、窗口框
src/sprites.js      全部程序化美术(地砖/家具/建筑/角色/头像/图标)
src/maps.js         地图数据与物件摆放
src/data.js         需求/技能/职业/商店/镇民/社交/章节/台词数据
src/sim.js          模拟核心:时间、需求、心情、技能、关系、账单、章节、存档
src/actions.js      物件交互菜单、行动定义、社交判定、打工结算、家具店
src/world.js        世界层:碰撞、BFS 寻路、镇民日程、行动执行、光照、深度排序绘制
src/ui.js           对话框、菜单、HUD、提示条、暂停面板
src/minigames.js    咖啡馆 / 修车厂打工小游戏
src/audio.js        WebAudio 芯片音乐(7 首)与音效
src/input.js        键盘与屏上按键
src/main.js         场景(标题/创建角色/世界/结局)、固定步长主循环、缩放、评测钩子
```

## 评测钩子

`window.__bench`:`scene`、`state`、`world`、`ui`、`mg`(小游戏内部状态)、`step(n)`、`press(btn, frames)`、`tap(btn, after)`、
`newGame()`、`goto(map, x, y, dir)`、`setTime(h, m)`、`setMotive(id, v)`、`addMoney(n)`、`advance(min)`、`snapshot()`。
主循环在标签页隐藏时由 `setInterval` 兜底推进,可无头确定性驱动。
